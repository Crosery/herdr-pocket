# Herdr Pocket v0.2.53 更新说明

本次 **v0.2.53** 聚焦**上下文窗口液体流动视觉升级、聊天栏一体化遥测胶囊改造、即时缓存与上下文读数零延迟下发**，以及针对多模型上下文上限推断与流式刷新竞争态的全面修复。

## 更新亮点

- **GPU 合成双层正弦波动态上下文试管**：上下文详情面板左侧的 `ContextTestTube` 液柱升级为前景主液面与半透明背波错相双层波纹，配合成串上升微气泡，全部基于 2D GPU `transform` 与 `opacity` 合成器动画实现，零主线程重排与 JS 定时器开销；窗口失焦（`data-app-focused="false"`）、后台标签、节能模式（`data-idle` / `data-calm`）及 `prefers-reduced-motion` 下自动暂停释放资源。
- **聊天栏一体化遥测胶囊与结构化详情药丸**：将原本游离在 `CTX` 按钮左侧的纯文本 `缓存 XX%` 合并为圆角胶囊 `.composer-hud-pill`（左侧上下文圆环 + 百分比，发丝线分隔右侧闪电图标与迷你渐变缓存命中条及百分比；无缓存读数时自动回退显示吞吐或响应延迟），详情面板内同步替换为结构化视觉药丸（`.usage-metric-pills`），明暗双主题与窄屏布局均保持单行对齐。
- **全链路消除缓存与上下文读数延迟**：随 `Agent` 快照即时同步 `cacheHitPct`，为 `agent.usage` 增加 `lite: true` 轻量快速通道并补充内存 `cachedSessionSummary` 兜底，切换标签或模型流式输出期间即可秒显上下文占用与缓存命中率。
- **精准推断缺省上下文上限并修复流式自取消竞态**：为 `antigravity` 等仅上报已用 Token 而未上报 `context_limit` 的模型别名补齐模型家族上下文上限推断（如 Gemini 1M/2M、Claude 200k/1M、GPT-5/6/Codex 272k/1M），彻底消除“已用 475k tok 却显示 `CTX 0%`”的问题，并根治 `AgentsView` 在流式事件到达时自我取消 `agent.usage` 响应的缺陷。

## 新增功能

- **协议与守护进程即时缓存遥测（`packages/protocol` / `apps/hostd`）**：
  - `Agent` 协议模型新增 `cacheHitPct?: number` 字段，由 `hostd` 内 `computeSessionCacheHitPct` 直接随会话列表快照同步下发，`UnifloAdapter.sig()` 纳入上下文 Token 与 `cache_read` 变化感知。
  - `RpcMap["agent.usage"]` 参数新增可选 `lite?: boolean`：后台轻量刷新时跳过 `omp usage` 子进程拉取、跳过按模型聚合全库扫描及冷时间窗请求；当上游 `sessionUsage` 超时或异常时，自动回落至内存 `UnifloAdapter.cachedSessionSummary` 保留已索引的缓存读取与输入/输出计数。
- **上下文上限智能推断与格式化（`turnTelemetry`）**：
  - 新增 `inferFallbackContextLimit` 与 `contextLimitInferred` 状态标记，在显式上限缺省时按模型/适配器家族给出保守上下文窗容并标注 `~` 估算前缀；新增 `fmtLatencyClean` 统一响应延迟格式（毫秒/秒自适应）。

## 交互与体验优化

- **桌面端与 Web H5 聊天输入栏遥测融合（`AgentsView` / `app.css`）**：
  - 统一 `.composer-hud-pill` 视觉语言，悬停提示完整汇总上下文占用比例与 Token 数值、缓存命中率、首字响应延迟（TTFT）与生成吞吐（`tok/s`）。
  - 在 `<= 560px` 视口隐藏迷你进度条仅保留闪电图标与百分比、在 `<= 400px` 视口收起副段，避免挤压模型切换与发送按钮；PWA Service Worker 缓存版本同步递增至 `herdr-pocket-shell-v12`。
- **会话切换零闪烁与去重轮询**：
  - `AgentsView` 引入上限 80 条的模块级 LRU 缓存 `usageReportByAgentKey` 与 `mergeUsageReport` 合并逻辑，切换会话标签即时保留历史额度与模型分布；后台 `lite` 刷新按在途请求与 2.5s 节流去重（状态由 `working` 离开或切换会话时 150ms 内优先刷新）。
- **移动端体验对齐（`apps/mobile`）**：
  - 手机端详情页输入栏同步升级为 `CTX% | ⚡ 缓存%` 一体化胶囊，上下文面板与信息页同步接入上限回退推断、`agent.cacheHitPct` 即时回退及迷你缓存进度条药丸。

## 问题修复

- **修复未上报 `context_limit` 的模型（如 `gemini-flash-worker-agy`）显示 `CTX 0%` 与重复 Token 文本**：接入模型上限推断并在真正无法推断上限时展示实测已用 Token 与“窗口上限未知”，不再误显 `0%` 或左右重复显示同一 Token 数值；同时修复 `UnifloAdapter` 读取可空 `cost_usd: null` 与 `context_limit: null` 时的类型收敛问题。
- **修复流式输出阶段 `displayedEvents.length` 频繁变更导致 `agent.usage` 回调被 `alive = false` 丢弃及定时器饿死**：将定时器清理与在途响应提交解耦，仅在切换或卸载当前 Agent 时取消待发定时器，在途响应只要当前仍停留于同一 Agent 即正常合并入态。

## 多端与升级说明

- **支持平台**：中转服务端与电脑端 `hostd`（`herdr-pocket update`）、桌面端（macOS `arm64`/`x64`、Windows `x64`、Linux `x64`）、Android（`.apk`）、iOS（`.ipa`）、HarmonyOS NEXT（`.hap`）以及网页 H5（`/app/`）与管理后台（`/admin`）。
- **升级建议**：建议中转服务端、各台电脑上的 `hostd` 与桌面/移动端客户端一并升级至 **v0.2.53**，以完整获得快照级 `cacheHitPct` 即时下发、`lite` 轻量增量遥测、动态上下文试管及统一聊天栏遥测胶囊体验。
