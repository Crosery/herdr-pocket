# Herdr Pocket v0.2.48 更新说明

本次 **v0.2.48** 在 **v0.2.46**（60 FPS 多路直连小窗与动态叠牌露头）及 **v0.2.47**（小羊 7 态主动通知谱系）的基础上，彻底重构应用内更新探测与弹窗同步机制——当连续发布新版本时，客户端会实时感知并通过最新标签直连热替换更新弹窗与下载地址，不再需要「先装完上一版才看到最新版」。

## 更新亮点

- **中转端实时推新 & 弹窗原地热替换（`release_update` / `updates.ts` / `UpdatePrompt.tsx`）**：中转服务器新增主动版本巡检，每当有更高版本发布即通过 WebSocket 实时推送至所有在线客户端；桌面端与手机端即使此前已弹出、收起、忽略甚至下载好前一版本，也会立刻清除旧态并切换为最新版本的更新卡片（副标题明确提示已跳过旧版）。
- **突破镜像 `/releases/latest` 缓存滞后（`bridge.ts` / Mobile `update.ts`）**：客户端在检测更新时并行询问中转端 `/v1/releases/latest` 与 GitHub API；只要发现任何通道已出现更高版本，立即切换拉取显式 `vX.Y.Z` 标签下的 `RELEASE-MANIFEST.json` 与 `SHA256SUMS`，不再被镜像站短时缓存的 `/releases/latest` 重定向拖回旧版。
- **点击更新前二次验新 & 下载中途无缝切新（`updater.rs` / `updates.ts`）**：用户点击「立即更新」前会先执行 3 秒限时新鲜度校验，若按钮停留期间刚好发了新版则直接下载最新版；原生桌面更新器同步引入代际取消令牌 `update_cancel_download`，支持在旧版下载中途无感中止并立即转入最新版下载。

## 新增功能

- **协议层版本推送契约（`packages/protocol/src/index.ts`）**：
  - `ServerFrame` 的 `welcome` 握手消息新增可选 `serverVersion` 与 `latestRelease` 字段，断线重连后立即获知最新版号。
  - 新增 `{ type: "release_update", version, ts }` 服务端推送帧。
- **中转端权威最新版本巡检（`apps/relay/src/releases.ts` / `server.ts`）**：
  - 新增公开接口 `GET /v1/releases/latest`（支持 `?refresh=1` 强刷，返回最新版本、多端清单 `manifest` 与中文更新摘要 `notes`）。
  - `ReleaseCache` 启动后定期无缓存轮询 GitHub Releases API 与镜像清单，一旦捕获更高版本号立刻向全网在线设备广播 `release_update`。
- **桌面原生无缓存头与下载中止命令（`apps/desktop/src-tauri`）**：
  - 为 `commands.rs`（`update_fetch_sums`）及 `updater.rs`（`update_fetch_github_latest`）统一补充 `Cache-Control: no-cache` / `Pragma: no-cache` 请求头。
  - 新增并注册 `update_cancel_download` 与 `DOWNLOAD_EPOCH` 代际原子变量，实现并发分片与单流下载的中途抢占清理，且被新版取代时不会误报下载错误。
- **Android 移动端同步热替换（`apps/mobile/src/lib/update.ts` / `relay.ts`）**：
  - 接入 `welcome` / `release_update` 版本通知与 `/v1/releases/latest` 绕过缓存校验，新增 `downloadedVersion` 追踪，若期间发布新版 APK 则自动淘汰旧就绪包并重弹新版提示。

## 交互与体验优化

- **有更新时缩短巡检周期**：检测到可用更新后，桌面端后台重检自动切换为每 60 秒轮询，切回窗口焦点防抖缩短为 15 秒，确保长期打开的工作台卡片始终显示当下最新版本。
- **跳过旧版清晰提示**：当更新弹窗直接从旧候选版本切换至新版时，卡片副标题补充 `· 已直接切换至新版（跳过 vX.Y.Z）`，交互更直观。

## 问题修复

- **修复新版弹窗误沿用旧版更新摘要**：修正 `updates.ts` 中 `fetchReleaseNotes` 无条件返回内存缓存摘要的问题，确保仅当缓存版本号与目标版本号一致时才复用。
- **修复下载或就绪旧版期间新版无法顶替提示**：统一放开 `minimized`、`dismissedVersion` 与 `ready` 状态在检测到更高版本时的重置逻辑。

## 多端与升级说明

- **完整继承 v0.2.46 与 v0.2.47 全部特性**：包含本机直连 60 FPS 多路并发小窗、零弹开 OS 鼠标、默认收起胶囊与动态 `1·2·3·4` 叠牌露头交互，以及小羊 7 态主动汇报谱系与多端分色徽章。
- **涵盖平台与升级建议**：覆盖 **macOS（`arm64` / `x64` `.dmg`）、Windows（`x64` `-setup.exe` / `.msi`）、Linux（`x64` `.AppImage` / `.deb`）、Android（`arm64` `.apk`）、HarmonyOS NEXT（`arm64` `.hap`）、iOS（`arm64` `.ipa`）**、网页 H5（`/app/`）与电脑守护进程 `herdr-pocket`。
- **关于本次原地升级说明**：这是最后一次以旧版检测逻辑拉取新版的升级——完成本次桌面端 **「设置 › 更新」**（以及 Android 端更新、电脑端 `herdr-pocket update`）升级至 **v0.2.48** 后，后续所有连续发版都会自动实时切换为最新版弹窗。
