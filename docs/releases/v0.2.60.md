# Herdr Pocket v0.2.60 发布说明

本次 **v0.2.60** 带来**全平台内置 AI 浏览器（完整对标 Ego 操作流与网络抓包）、Agent「已完成 / 需要你」状态机与 Herdr ↔ Herdr Core 双向空间+Agent 同步、标准文件夹插件规范与极简插件中心、Chat UI 解析与 `/btw` 体验修复，以及 macOS / iOS / Android 全三端语音串音隔离与硬件/硬件加速升级**。

## 更新亮点

- **全平台内置 AI 浏览器（macOS / Windows / Linux 通用，零抢焦）**：内置独立 Chromium CDP 引擎与主 Tab 栏实时工作台，支持语义快照、多标签页弹窗接管、粉色虚拟光标、「我来接管 / 已完成，交还 AI」协作条与可折叠网络抓包抽屉（含 Fetch/XHR 过滤与完整 JSON 响应体读取）；优先调用 `chrome-headless-shell` 后台无感运行，彻底不再弹出或抢占本地 Chrome 焦点，并修复旧浏览器窗口误劫持问题。
- **修复「已完成」状态消失与「需要你」跨端误判**：纠正 `hostd` 在降级假运行/假阻塞状态时直接落成 `idle` 的问题，未读完成轮次严格归入 **「已完成」** 并支持点击查看后准确同步 `herdr.seen`；将「需要你」活屏复核扩展至全 harness（Antigravity / Claude Code / Codex / OMP / Gemini），硬否决保护所有真实提问、选项菜单与授权确认，不再误报。
- **Herdr ↔ Herdr Core 双向同步补齐 Agent 镜像与同步**：除空间双向同步与 CAS 冲突重试外，`spaces.sync` 现默认同步双向 Agent——将 `herdr-core` 在线 Agent 通过 `hc attach --history 200` 无缝挂载到对应 `herdr` TUI 工作空间标签页并回写元数据与状态，同时自动去重避免双份显示；并在「电脑与中继」给旧版主机增加一键 **「升级 hostd」** 按钮。
- **全三端语音多声源串音隔离 + 硬件与推理加速升级**：
  - **三端统一修复管线顺序与门控死锁**（macOS Rust `voice_ai.rs`、iOS `VoiceFilter.swift`、Android `VoiceFilter.kt`）：先执行 `DPDFNet → VoxLock TSE` 再将分离后音频送入 `Silero VAD + ERes2NetV2` 声纹判别；解除 `-9.0 dB` 残留门死锁（`-2.5 dB / -1.2 dB` 滞回 + 连续非主人高置信关门）；人声增强严格仅对已验证主人开启，缩短起音泄露窗口并增加平滑起音衰减与 6 ms 快恢复。
  - **硬件与推理加速**：macOS 新增原生 AudioToolbox `VoiceProcessingIO` 硬件回声消除与多麦波束成形采集（失败自动回退 `cpal`），macOS 与 iOS 为 `ERes2NetV2` / `VoxLock` 接入 CoreML ANE 执行提供程序（失败自动回退 CPU），iOS 15+ 上报系统麦克风隔离模式并提供模式选择器桥接，Android 接入 ONNX Runtime XNNPACK 加速。
- **标准化一插件一文件夹规范与极简插件中心**：建立 `plugins/_template/`、`plugins/assistant/*`、`plugins/pocket/ai-browser/` 统一清单规范与自动化契约测试；桌面端与移动端插件中心精简冗余文案，清晰分为 **小羊助理插件**（`Herdr`、`Uniflo` 默认开启且关闭即真实屏蔽工具，以及 `AI 浏览器操作`、`代码与 Git`、`网页阅读`、`Webhook`）与 **Herdr Pocket 插件**（`AI 浏览器 · 操作流` + 快捷「打开标签」）。

## 新增功能

- **内置 AI 浏览器工作台与 CLI（`herdr-pocket browser`）**：
  - 协议与主机侧新增 `browser.run`（编排脚本）、`browser.net`（`list / body / wait / clear` 抓包接口）与完整 35 项页面操作，支持 Open Shadow DOM 语义快照与登录/验证码自动交接提示。
  - 桌面端主标签栏新增 `+ → 新建 AI 浏览器` 入口与专属 `AiBrowserTabPane` 视图，内置子标签栏、地址栏、分屏、独立弹窗打开、截图、协作接管条与网络抓包抽屉。
  - 小羊助理新增 `browser_run` 与 `browser_net` 工具，开启「AI 浏览器操作」插件即可直接执行多步网页操作与接口响应分析。
- **Herdr ↔ Herdr Core 双向 Agent 同步与主机一键升级**：
  - `spaces.sync` 支持双向同步空间与 Agent（`herdr-core → herdr` 实时 `hc attach` 镜像 + `herdr → herdr-core` Uniflo 续跑迁移），完全幂等不重复创建标签，绝不关闭已有终端。
  - 「设置 → 电脑与中继」为落后版本的在线主机提供一键 **「升级 hostd」** 操作。
- **标准化插件目录结构与契约校验（`docs/plugins.md`、`plugins/`）**：
  - 每个插件以独立目录组织（`manifest.json` + `README.md` + `index.ts`），由 `plugins/registry.ts` 与 `apps/relay/test/plugins.test.ts` 保持协议、注册表与工具门控一致。
- **macOS 原生 `VoiceProcessingIO` 采集与三端 ORT 硬件加速**：
  - macOS 语音通话优先启用 `kAudioUnitSubType_VoiceProcessingIO` 硬件降噪/AEC，macOS/iOS 启用 CoreML ANE EP（`0x004`），Android 启用 XNNPACK EP，均具备纯 CPU 安全兜底。

## 交互与体验优化

- **极简插件中心（桌面端 + 移动端）**：移除冗长宣传卡片与重复说明，统一图标语义、工具标签与浅色/深色主题视觉层级。
- **旁路提问 `/btw` 面板重排与快速追问**：面板收进居中的输入框容器，与聊天主列和底部输入框左/右边缘像素级对齐；标题栏新增一键「继续追问」按钮并优化纵向高度，不再挤压「回到底部」悬浮按钮。
- **Chat UI 文件点击直达与智能路径解析**：聊天气泡中的本地文件路径支持左键直接打开预览；主机端新增 5 级智能路径定位（自动清洗引号/截断路径并回溯工作区与产物目录，保留严格越权边界与 30 秒缓存）。
- **「已完成」状态防误清**：查看已完成会话时增加 600 ms 有效停留确认，避免短暂焦点切换或标签挂载时瞬间清除绿点标记。

## 问题修复

- **修复「已完成」状态缺失**：`hostd` 在降级 Antigravity 假 `working` 或跨 harness 假 `blocked` 时，若 `herdr.seen < turn` 现正确转为 `done` 而非 `idle`，同时修复 `agent.seen` 对此类终端写回 `herdr.seen` 的逻辑，并为 `done` 状态事件增加防饿死快速重同步。
- **修复「需要你」误报与正则边界缺陷**：补齐 `[y/n]` / `(y/n)` 匹配边界，跨全 harness 校验空闲输入框状态，杜绝已完成轮次或审核尾巴误触发阻塞告警。
- **修复 Chat UI 用户消息偶发重复显示两次**：`foldMessageText` 清洗零宽/BOM 不可见字符，乐观发送气泡增加上传图片路径唯一匹配、±15 秒已认领副本清理、800 ms 防连击保护与相邻重复 `user_message` 合并。
- **修复 `/btw` 状态错位与历史工具行永久显示「正在调用」**：`/btw` 的「主线运行中」徽标改为绑定 `isTurnBusy` 与输入框状态完全同步；`chatFold` 在后续思考、回复或新批次到达后自动收口前序无回执孤立工具，不再永久转圈。
- **修复 Chat UI Markdown 复杂格式解析错乱**：支持硬换行链接自动拼接、粗体/删除线嵌套链接、Unicode 圆点列表，并过滤泄露的 `/swarm board` 页脚文本。
- **修复桌面窗口回传误抓旧浏览器窗口**：`egoSpace` 窗口匹配不再盲目回退到首个无关浏览器窗口，严格限定目标空间标题与新开窗口基线。
- **修复 `spaceBridge` 并发写入冲突与空空间污染**：增加 3 次 CAS 冲突重试，跳过无名且无目录的空空间镜像。
- **更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v19`）**：确保网页端与 PWA 升级后即时加载最新资源。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.60.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.60`）。
- **兼容与升级**：无破坏性协议变更，现有已录入声纹与中继配置无缝保留。升级后建议各执行电脑通过桌面端「设置 → 电脑与中继 → 升级 hostd」或运行 `herdr-pocket update` 同步更新主机服务，服务端运行 `sudo herdr-pocket-relay update` 或拉取最新镜像。
