# Herdr Pocket v0.2.21 更新公告

## 更新亮点

- **桌面端窗格右上角操作栏默认常驻显示**：调整工作区窗格顶栏工具区（`.v3-pane-actions`）默认展示策略，取消必须悬停鼠标才显现的隐藏限制，打开任意终端、对话或文件分屏后即可直接看到并使用**视图切换、终端搜索、向右/向下分屏、最大化与关闭分屏**等操作按钮。
- **延续 `v0.2.20` 的 Herdr App 布局同步、终端引擎与多端一致性改进**：保留完整 `"herdr-app"` 双向同步、双主题（Graphite / Paper）对比度优化、`local-term://size` 双端网格重排同步与工作区裸文件名跳转能力。

## 新增功能

1. **窗格操作栏默认可见与单测回归守卫**：
   - 保持 `apps/desktop/src/shell/ShellWork.tsx` 窗格顶栏动作组（`切换到对话/终端视图`、`在终端中搜索`、`在文件管理器显示`、`复制路径`、`向右分屏`、`向下分屏`、`最大化`、`关闭分屏`）常驻显示，不再被 `opacity: 0` 与 `pointer-events: none` 遮蔽。
   - 在桌面端测试套件新增针对 `.v3-pane-actions` 样式的静态回归断言，确保后续迭代不会重新默认隐藏工具按钮。

## 交互与体验优化

- **一瞥即得的分屏与视图切换入口**：无需先将指针悬停到 30px 窗格顶栏再寻找按钮，触控板快速点按或跨屏定位即可直接触发分屏拆分、模式切换与终端搜索。
- **全窗格聚焦一致性**：非聚焦分屏与聚焦分屏同样清晰可读，操作栏状态直观统一，避免分屏多开时误以为部分工具按钮丢失。

## 问题修复

- **修复桌面端工作区窗格右上角动作按钮默认隐藏导致难以发现和误触的问题**：移除 `apps/desktop/src/styles/shell.css` 中 `.v3-pane-actions` 的默认 `opacity: 0` / `pointer-events: none` 及悬停显隐切换规则，保证所有分屏与单窗格顶栏工具区即开即用。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并过苹果公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像（可搭配公开部署占位域名 `pocket.example.com` 使用）。
- **升级方式**：桌面端可在应用设置中直接检查更新并一键安装，电脑守护进程执行 `herdr-pocket update`，服务端执行 `sudo herdr-pocket-relay update`。
