# Herdr Pocket v0.2.34 更新说明

Herdr Pocket `v0.2.34` 针对真实生产环境日志暴露的核心问题进行了根因级修复，同步开放全链路前后端与用户交互操作全量日志上报，并修复 `v0.2.33` Linux 桌面端构建编译问题。

## 更新亮点

- **全链路全量日志上报与排查可观测性**：放开中转服务、电脑守护进程（`hostd`）、桌面端 Rust 原生层与 Web/H5 前端的全级别（`debug`/`info`/`warn`/`error`）上报与 5 秒高速 flush；新增全局交互点击、IME/语音输入法组词溢出检测（`overflowX`）、拖拽与未捕获异常埋点，所有动作与异常均脱敏后实时汇总到服务端，彻底杜绝问题无据可查。
- **终端与输入框语音组词彻底稳定**：
  - 终端内通过 `!important` CSS 变量锁定 `.composition-view` 与 1px 宽 `.xterm-helper-textarea`，彻底消除 `xterm.js` 内部 `setTimeout(0)` 覆盖样式导致的组词右挤、窗口横向滚动撑爆与逐字闪烁。
  - 对话框与「小羊」助理输入框在语音/拼音组合输入期间切换为非受控缓冲模式，零 React 重渲染打断 WebKit `NSTextInputClient` `markedTextRange`，在框内已有文字时使用语音输入法不再挤开或错乱原有文本。
- **连接稳定性与零闪烁切标签体验**：
  - 中转 WebSocket 最大帧上限提升至 32 MiB，`hostd` 出站主动拦截超限响应并返回明确错误提示，避免触发 `1009` 断连；守护进程增加未捕获异常/Promise 保护，不再因子进程信号意外退出。
  - 修复 `DirectLink` 客户端在 `onmessage` 异步微任务中解密导致的 ChaCha20 nonce 乱序断流，将 `Pong` 等待提升至 15 秒并在 WebView 冻结恢复后自动探测续命而非误杀连接。
  - 修复重连及直连切换（`rehome`）重复请求 `history: 600` 导致的 600 行历史重放闪烁，并在初次挂载期间等待首批缓冲完结再一次性滚动到底部显示。

## 新增功能

- **全局前端用户操作 telemetry（`actionTelemetry.ts`）**：自动脱敏记录关键控件点击、组合输入耗时与水平溢出诊断、文件拖放统计及前后端上传/直连/Portal/消息队列全周期状态，实时上送中转服务。
- **守护进程直连与分片直传细粒度审计（`hostd` / `DirectServer` / `ChunkedPutManager`）**：记录每个非高频只读/写入 RPC 耗时、直连点对点建连/断开、流订阅生命周期与 P2P HTTP `direct-put` 字节统计。

## 交互与体验优化

- **取消默认长按 `Command` 悬浮快捷键提示**：新老用户默认关闭 `showModifierHoldHints`（需主动在快捷键设置中开启），同时 macOS 检测合并 `NSEvent` 与 `CGEventSourceKeyState(CombinedSessionState)` 且鼠标悬停终端区时不触发，彻底消除未按或仅点按链接时弹出幽灵角标/提示条的问题。
- **工具版本更新状态轮询防并发风暴**：`ToolVersions` 轮询增加单一在途请求互斥锁，并在 `hostd` 自更新重启期间容忍最多 5 次短暂超时重连，避免刷屏产生大量 `8000ms` 超时失败噪音。

## 问题修复

- 修复 `voice_ai.rs` 中 `enroll_collected_speech` 定义在 `#[cfg(any(target_os = "macos", windows))]` 模块内部导致 Linux 发布构建失败的编译错误，以及 `notch.rs` 在非 macOS 平台的未使用导入警告。
- 修复 WebSocket `DirectLink` 偶发 `bad frame` 断开及切换标签/网络波动时终端画面从头滚动重放的问题。

## 多端与升级说明

- **服务端（Relay）**：日志吞吐上限提升（单次 500 条、每设备 10 分钟 50,000 条、2 MiB 请求体、32 MiB WebSocket 帧上限），保留 `v0.2.33` H5 移动端 UI 与安装包缓存加速路由。
- **电脑守护进程（hostd）**：建议所有受管主机升级至 `v0.2.34` 以获得防 `1009` 断连保护、异常守护、`45s` 直连保活与 5 秒实时全量日志回传。
- **桌面端与移动端**：覆盖 Linux（`.AppImage` / `.deb`）、macOS（`arm64` / `x64` `.dmg`）、Windows（`-setup.exe` / `.msi`）、Android（`.apk`）、HarmonyOS NEXT（`.hap`）及 iOS（`.ipa`）。
