# Herdr Pocket v0.2.28 更新说明

Herdr Pocket `v0.2.28` 围绕高频桌面与移动交互痛点进行全面视觉与工程升级：参考 GitHub 高星开源灵动岛方案重构「小羊提醒」灵动岛形态与展开队列；修复语音输入法长句超限与终端错位故障；清理按住 `Command` 键时的快捷键遮挡及侧栏/状态栏错位；重做 H5 网页端手机触控布局并支持作为独立桌面应用添加到主屏幕；同时升级 GitHub Release `Latest` 机制，统一随版附带并汇总全平台最新客户端安装包。

## 更新亮点

- **「小羊提醒」灵动岛全面重构**：借鉴开源社区 `boring.notch` 的 `NotchShape` 内凹耳廓贝塞尔轮廓与双翼顶栏设计及 `vibe-notch` 的暗色无缝贴合风格，贴合屏幕顶部无留白融入系统刘海与外接屏顶部菜单栏，融入樱粉柔光描边与小羊形象；展开态自动按条目与分类数精确匹配窗口尺寸，列表零裁切。
- **语音输入法长句与超限输入修复**：根治长段语音听写文本横向撑破终端画布、粘贴或失焦后 `.composition-view` 组词浮层残留卡死的问题，并对超长文本 commit/paste 按 `<= 512` 字节 UTF-8 字符边界自动分片与 Bracketed Paste 分步写入，保护底层 PTY 输入缓冲。
- **按住 `Command` 快捷键提示与桌面框架防遮挡**：重构 `ModifierChordHud` 为顶部单行预览条并隐藏多余堆叠徽章，将终端状态栏与窗格右上角操作提示迁至安全象限；同步修复桌面侧栏「Herdr Pocket」标题与右侧图标重叠及状态栏「提醒」图文换行问题。
- **H5 网页端移动端适配与桌面应用化（PWA）**：修复 H5 手机页面多重底部安全区叠加导致导航栏被裁切、登录卡片不可滚动及按钮挤压错位的问题，补齐 `manifest.webmanifest`、PWA 图标与 `sw.js`，支持直接安装为无地址栏全屏手机桌面应用，并在网页端隐藏仅限桌面原生端的无效设置项。
- **`Latest` 发布页全平台安装包自动结转汇总**：升级发版流水线，跨端差异化构建时自动将上一版未变动的端（如 Android `.apk`、iOS `.ipa` 等）已签名安装包一并结转至最新 `Latest` Release，并在说明页顶部下方提供全平台最新版本下载汇总表。

## 新增功能

- **H5 手机桌面应用（PWA）支持**（`apps/desktop`、`apps/relay`）：
  - 新增 `pwa-192.png`、`pwa-512.png`、`pwa-maskable-512.png` 应用图标、`manifest.webmanifest` 及离线外壳 `sw.js`（由 Relay 在 `/app/` 与 `/h5/` 下提供 `Service-Worker-Allowed: ./` 与 `no-cache` 更新策略）。
  - 在网页登录页底部与「设置 -> 通用」内提供「装成手机桌面应用 / 添加到主屏幕」卡片：Android Chrome 等支持 `beforeinstallprompt` 的浏览器可直接唤起原生安装确认，iOS Safari 等浏览器则弹出分步主屏幕添加指南；主题色 `<meta name="theme-color">` 随浅色/暗色外观实时同步。
- **灵动岛 SVG `NotchShape` 双翼架构**（`apps/desktop/public/notch-hud.html`、`apps/desktop/public/notch-hud.js`、`apps/desktop/src-tauri/src/notch.rs`）：
  - 在紧凑、窥视、展开三种状态下实时计算内凹上耳角与底部圆角路径，支持仅单分类时自动隐藏多余筛选栏，展开条目标识清晰展示审批、提问、异常与完成分类图标及「审批 / 跳转」快捷胶囊。
- **`Latest` 跨版本资产结转与清单生成脚本**（`scripts/sync-carried-release-assets.mjs`、`.github/workflows/release.yml`）：
  - 保留 `RELEASE-MANIFEST.json` 中每条未变动渠道的真实源码构建 tag 以便增量触发判断，同时自动将全平台 `10` 类发行资产（`android-arm64`、`ios-arm64`、`harmonyos-arm64`、`macos-arm64`、`macos-x64`、`windows-x64-setup`、`windows-x64-msi`、`linux-x64-appimage`、`linux-x64-deb`、`bundle`）汇总写入每个 `Latest` Release。

## 交互与体验优化

- **H5 移动端设置与连接流精简**（`apps/desktop/src/App.tsx`、`apps/desktop/src/views/SettingsView.tsx`、`apps/desktop/src/views/settings/Panes.tsx`、`apps/desktop/src/components/ConnectRelayPanel.tsx`）：
  - 网页端自动隐藏需依赖本地桌面的「语音唤醒与声纹」「浏览器与文件」「性能与资源」以及 `config.json`、新手引导、macOS 灵动岛与本地 `.dmg` 下载更新面板，改为提供网页版一键刷新升级入口与文件显示过滤开关；移动端设置首页新增设备状态概览卡片，手动输码区在首次进入时默认折叠以便优先扫码或通行密钥恢复身份。
  - 修复触控设备输入框字体小于 `16px` 触发 iOS Safari 自动放大界面的问题，并为隐藏底栏的对话/终端详情页补充底部输入栏安全区留白。
- **按住 `Command` 键提示排布**（`apps/desktop/src/shell/ShellWork.tsx`、`apps/desktop/src/views/AgentsView.tsx`、`apps/desktop/src/styles/shell.css`）：
  - 底部状态栏中的 `⌘/` 与 `⌘K` 直接采用内联高亮代替额外角标叠压；模型与思考等级选择器徽章改放正上方，分屏窗格右上角操作提示统一锚定底部并拉开按键间距。

## 问题修复

- 修复 macOS 灵动岛展开时因未调用原子级 `setFrame_display` 更新位置与宽高而沿用紧凑宽度（约 `236px`）导致标题换行、卡片底部截断的问题，以及资源路径错误引起的吉祥物图标失效。
- 修复终端语音听写文本过长时 `.composition-view` 不换行横向溢出的缺陷，并补充 `paste`、`blur` 事件清理残留 `active` 状态与浮层文本；超长文本发送自动切分并通过 `4ms` 节流写入，防止大段输入在系统终端缓冲中截断错位。
- 修复桌面端标准侧栏宽度（`236px`）下 macOS 红绿灯右侧「Herdr Pocket」与搜索/折叠按钮文字重叠截断，以及底部状态栏图标与「提醒」文字竖向折行显示的问题。
- 修复 H5 样式中 `@media (max-width: 859.98px)` 与 `@media (max-width: 1099.98px)` 断点顺序颠倒导致的媒体查询覆盖失效、弹窗遮罩未考虑安全区高度及登录表单溢出无法滑动的布局错误。
- 修复 `releaseFromSums` 在 `SHA256SUMS` 混入旧版本号移动安装包（如按字母序排列在前的 `.apk`）时误取首个文件版本号而非最高版本号的问题。

## 多端与升级说明

- **服务端（Relay）**：携带最新 `WEB_APP_CSP` 策略、PWA 资源头（`Service-Worker-Allowed: ./`、`Cache-Control: no-cache`）与 H5 静态构建产物；使用包更新命令 `sudo herdr-pocket-relay update` 或从源码标签同步并重启服务即可生效。
- **电脑守护进程（hostd）**：在已部署的电脑上执行 `herdr-pocket update` 或重启本地服务即可升级至 `v0.2.28`。
- **桌面端（macOS / Windows / Linux）**：可在应用内「设置 -> 更新」自动检测升级，或在 GitHub Release `Latest` 页面下载对应系统安装包（macOS `arm64`/`x64` `.dmg`、Windows `.exe`/`.msi`、Linux `.AppImage`/`.deb`）覆盖安装。
- **移动端与网页端（Android / iOS / HarmonyOS / H5）**：访问中转服务器的 `/app/` 页面即可体验新版 H5 与一键添加到主屏幕功能；Android、iOS 与鸿蒙安装包统一在 GitHub `Latest` Release 页面按表直达下载。
