# Herdr Pocket v0.2.56 发布说明

本次 **v0.2.56** 围绕**实例级运行态聚合视图（端口 + 子 Agent）**、**小羊模型全量扫描与紧凑列表升级**、**音频增强实时试听台**、**桌面与手机端设置架构微调**以及**非图片附件发送后重复聊天气泡根治**完成了全端升级，同时保持桌面端、H5/鸿蒙 NEXT 与 Android / iOS 原生端的视觉与交互一致性。

## 更新亮点

- **按 Agent 实例聚合「端口 + 子 Agent」，图标语义全面升级**：桌面端窗格顶栏将监听端口与子 Agent 收敛为同一实例级浮层（单行切换 `端口` 与 `子 Agent`，支持终端视图直接访问），子 Agent 图标由分支符号统一升级为 Agent 机器人图标，监听端口由小圆点升级为信号波图标；桌面侧栏、H5/鸿蒙与原生移动端 Agent 列表及详情页同步上线 `实例` 聚合视图。
- **服务商模型全量扫描与复选框勾选（零截断）**：中转服务端模型枚举升级为自动分页拉取（支持 Anthropic `after_id`、Gemini `nextPageToken` 与 OpenAI `after` 游标分页，上限提升至 5000 个），支持 Anthropic `x-api-key → Bearer` 自动回退与带前缀路径 `/v1/models` 探测；全端取消 30/36 条显示截断，并改用标准复选框选择模型。
- **音频降噪与声纹「效果试听台」**：新增原生 Rust `voice_ai_preview_process` 推理命令（复用真实通话 `LiveCallProcessor` 链路，Web/H5 端提供 DSP 回退），支持**戴耳机实时耳返**（外放防啸叫自动锁定）与**5 秒原声 / 增强后 A/B 对比试听**，切换降噪或人声增强开关后自动即时重算对比结果。
- **彻底修复附带非图片文件发送出现双聊天气泡的问题**：根治发送 `.txt` / `.md` / `.pdf` 等非图片文件或跨主机相对路径附件时，客户端乐观气泡与服务端回显事件匹配失败导致长时间显示两个聊天框的缺陷，并将回显附件路径同步收纳为可点击的文件标签。

## 新增功能

- **实例级运行态浮层与移动端「实例」页签**：
  - 桌面端窗格顶栏与 Peek 预览顶栏统一采用 `InstanceRuntimePopover`：点击端口触发器或子 Agent 触发器打开紧凑单栏浮层，一键切换 `端口`（内置/远端预览、分屏预览、复制地址、停止服务、重新扫描）与 `子 Agent`（搜索、仅看进行中、树状钻取、侧栏查看）。
  - 桌面侧栏、H5/鸿蒙与 Android / iOS 原生端 Agent 列表新增 `:port` 监听端口胶囊；手机端 Agent 详情页将「子任务 / 子 agent」升级为「实例(N)」，同屏展示运行中端口与子 Agent 列表。
- **小羊助理音频「效果试听台」**：
  - 桌面端「设置 → 语音唤醒与声纹」与手机 H5/鸿蒙「设置 → 降噪、声纹与试听」内置 `VoicePreviewStudio`。
  - **模式 A（戴耳机实时耳返）**：外放扬声器默认锁定防啸叫，勾选「我已戴耳机」后可实时监听本地降噪与人声增强效果。
  - **模式 B（录 5 秒 A/B 对比）**：录制 5 秒语音样本，自由切换「听原声」与「听增强后」，并实时展示处理耗时与输入/输出电平指标。
- **中转服务端全量模型分页扫描与协议兼容**：
  - `apps/relay` 模型拉取上限从 500 提升至 5000，内置最多 20 页游标自动翻页；新增 Anthropic 鉴权头回退、`/models` 与前缀路径 `/v1/models` 探测回退。
  - 当填写 `127.0.0.1` / `localhost` 地址经远端中转探测失败时，界面给出明确原因提示，避免误判。
- **桌面端设置导航检索与移动端「显示与排版」独立子页**：
  - 桌面 `SettingsFrame` 左侧栏新增「搜索设置…」实时过滤、三段分组标题（基础 / 小羊与扩展 / 系统）、更紧凑的导航行高、顶部副标题及底部双列「引导 | 诊断」快捷入口。
  - 手机 H5/鸿蒙与 Android / iOS 原生端将字号、对话展示模式、跨端小窗默认显示与显示普通终端收纳进「显示与排版」独立子页，设置首页保留小羊信息卡、主题切换与实时摘要，大幅缩短首屏滚动高度。

## 交互与体验优化

- **小羊文本模型列表紧凑化**：桌面端与原生移动端移除占空间的大号竖向编号轨道，改为类 Agent 模型选择器的单行紧凑样式（`主 / 2 / 3` 序号徽章 + 厂商图标 + 等宽模型名 + 点击测速胶囊 + 设为主按钮），并把 `+ 添加模型` / `+ 添加服务商` 统一收进分区顶栏。
- **模型扫描列表改用标准复选框**：桌面端统一使用 `PocketCheckbox`，原生移动端改用标准勾选框图标并支持触控行高与「展开全部 N 个模型」平滑分页，彻底移除旧版「选」文字标签。
- **子 Agent 元信息降噪**：将原本每条子 Agent 下方 4 个独立边框胶囊收敛为单行轻量 `·` 分隔摘要（模型 · 步数 · 耗时 · 费用），并精简浮层顶栏重复筛选条。
- **手机端语音页去除桌面快捷键冗余**：H5/鸿蒙手机端进入「降噪、声纹与试听」时直接呈现效果试听台与本地降噪/声纹开关，隐藏仅适用于桌面端的全局快捷键说明。

## 问题修复

- **修复 Chat UI 发送附带非图片文件时显示两个聊天气泡的问题**：
  - 扩展 `@herdr-pocket/protocol` 中 `splitFiles` 对非图片文件路径（绝对路径、`~/...`、Windows 路径、含空格与括号的文件名、`@` 前缀及引号路径）的识别，同时严格保护 `/compact`、`/model provider/name` 等斜杠命令与带参数 Shell 命令行不被误拆。
  - 在 `chatQueueLogic` 对账逻辑中补充 `uploadedPaths` 与 `textWithFiles` 原文比对（兼容跨主机拖拽相对路径与 Shell 转义字符）及 `ts === 0` 时间戳容错，并在 `terminal.send` 发出前预先写入 `uploadedPaths` 消除 SSE 抢跑竞态。
  - 修复 `ChatTimeline` 对含空格文件名附件路径的可点击解析，并将原生移动端与 `hostd` 排队预览中的非图片附件文案从「图片」修正为文件名/「附件」。
- **修复终端视图下隐藏实例子 Agent 入口的问题**：桌面端窗格处于终端视图（`subHead` 未挂载）时，只要实例存在子 Agent 仍正常展示 `Bot` 触发器与浮层列表，点击可直接侧栏打开查看。
- **更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v15`）**：确保网页端与 PWA 升级后自动切换至最新前端构建产物。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.56.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.56`）。
- **兼容与升级**：无破坏性协议变更；电脑端运行 `herdr-pocket update`，服务端运行 `sudo herdr-pocket-relay update` 或拉取最新容器镜像，桌面端与移动端可直接在设置中检查更新或从 GitHub Releases 下载安装包。
