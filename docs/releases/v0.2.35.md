# Herdr Pocket v0.2.35 更新说明

Herdr Pocket `v0.2.35` 彻底解决 H5 多标签页每秒互踢断连问题，正式接入标准 WebRTC `RTCDataChannel` 端到端 P2P（支持 NAT STUN 打洞与 `https://` 浏览器直连）以及 P2P 二进制文件收发通道，并修复跨端直连隧道误判和后台假超时断连。

## 更新亮点

- **彻底消除 H5 多开标签页互踢断连**：
  - 中继服务与主机直连服务端分离桌面主控（`host`）与查看端（`viewer`）会话模型，同一查看设备支持最多 8 个并发标签页/窗口同时在线并按连接隔离流 ID，不再出现旧会话与新会话每 1 秒互相 `code 4000 (replaced)` 踢下线、画面闪断的问题。
  - 当隐藏在后台的旧标签页收到 `4000` 替换关闭时主动暂停重连，仅在切回前台可见时恢复，避免后台争抢连接。
- **标准 WebRTC P2P 直连（`RTCDataChannel` + STUN NAT 穿透）**：
  - `hostd` 与前端桌面端、Web/H5 端全面接入标准 WebRTC `RTCDataChannel`（通过已鉴权中继完成 SDP/ICE 交换，使用内置 STUN 服务探测公网映射地址），即使在 `https://` 浏览器安全上下文（禁止明文 `ws://`）以及无 Tailscale VPN 的跨网 NAT 环境下也能直接建立 P2P 连接。
  - 在 Tauri 桌面端或同局域网环境下自动与 HTTP 探活验证后的原生 TCP 隧道竞速，优先走低延迟局域网/VPN 直连，跨网场景无缝走 WebRTC STUN P2P。
- **文件上传与下载全链路优先走 P2P 二进制通道**：
  - 新增专用有序二进制 DataChannel `hp-put` 与 `hp-get`（带 `bufferedAmount` 背压流控与 `32 KiB` 分片传输），Web/H5 与桌面端在发送大文件及中等体积音视频/文档、预览远程音视频与 PDF/Office 文档以及点击「下载到本地」时，优先通过 WebRTC P2P 或直连 HTTP P2P 流式传输。
  - 修复工作台远程文件「下载到本地」在中继回退路径下只读取前 2 MB 的截断问题，改为全量分片拉取完整文件。

## 新增功能

- **协议层 WebRTC 信令与直连探测契约（`@herdr-pocket/protocol`）**：新增 `webrtc.offer` RPC 与 `DIRECT_PING_PATH`（`/v1/direct-ping`）、`hp-rpc` / `hp-put` / `hp-get` 通道及 STUN 配置常量。
- **多端文件流式 P2P 判定优化**：对大于 `512 KiB` 的非光栅图片文件（如音视频、PDF、压缩包等）在 Web 端或 P2P 已直连时直接走 `uploadRemoteFile` 二进制流通道，减少 base64 编码开销与内存占用。

## 交互与体验优化

- **直连保活抗后台休眠误杀（桌面端 & 移动端）**：桌面端与 iOS/Android `DirectLink` 将心跳间隔调整为 `25s`、`Pong` 超时提升至 `20s`，并引入最近收包时间戳校验、唤醒 `250ms` 排空宽限及连续 2 次失联判定；页面/App 切入后台期间不触发破坏性超时断开，彻底消除 WKWebView/iOS 休眠唤醒时反复误报 `direct pong timeout`。
- **Service Worker 壳缓存升级**：更新 H5 `sw.js` 缓存版本号至 `herdr-pocket-shell-v2`，确保移动端浏览器及时加载最新直连与多会话逻辑。

## 问题修复

- **修复代理 TUN 假连通抢跑导致 1200ms 握手超时**：Rust 原生直连隧道 `open_direct_tunnel` 在 TCP 建连后新增 HTTP `GET /v1/direct-ping` 探活与 `X-Pocket-Host` 身份校验，屏蔽虚拟代理网卡的静默 fake-SYN 抢跑响应，确保直接连通真实的 Tailscale 或局域网主机。
- **修复 WebRTC 大块 JSON 响应超长风险**：`hp-rpc` 通道发送大尺寸终端/对话载荷时按字符数与 UTF-8 字节上限双重切分并通过 `__chunk` 自动重组，防止多字节中文文本超出 SCTP 单帧限制。

## 多端与升级说明

- **服务端（Relay）**：需要同步升级至 `v0.2.35` 以启用查看端多标签页并存、流 ID 隔离与 WebRTC `webrtc.offer` 信令转发。
- **电脑守护进程（hostd）**：建议所有受管主机升级至 `v0.2.35` 以启用 WebRTC P2P 数据通道、`/v1/direct-ping` 校验与 `hp-put`/`hp-get` 文件流服务端。
- **全端同步**：包含 macOS（`arm64` / `x64` `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、HarmonyOS NEXT（`.hap`）、iOS（`.ipa`）及 Web/H5 静态产物。
