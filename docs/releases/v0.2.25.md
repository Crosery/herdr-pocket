# Herdr Pocket v0.2.25 更新说明

Herdr Pocket `v0.2.25` 带来 X11 风格的跨设备 P2P 窗口、浏览器与文件回传浮窗以及全平台组件一键直连更新能力，同时包含 macOS 灵动岛联动、Ovis 四级分类提醒中心、120fps ProMotion 分屏挤压动画与文本实时重排、多键递进快捷键引导、全局字体替换以及 Chat UI 与终端稳定性深度修复。

## 更新亮点

- X11 风格跨端 P2P 窗口、浏览器与文件回传浮窗（桌面端 + 移动端同步）：远端电脑 Agent 触发 `open`、`open -R`、`xdg-open`、`gio open`、`explorer /select`、`BROWSER` 浏览器授权或 OAuth 本地回调时，自动在对应会话窗格右下角弹出可缩放浮窗（`SessionPortalPiP` / 移动端悬浮横幅），优先走 P2P 直连（ChaCha20-Poly1305 DirectLink 与直连 HTTP `/v1/portal-fs` 能力令牌通道，断线自动降级 Relay 分片与内联打包传输）。点击浮窗即可放大进入交互式视图（`PortalViewerModal`）：实时操作远端 headless Chrome/Edge/Chromium CDP 浏览器或原生系统窗口的点击/滚轮/键盘与文字输入、浏览 `open -R` 定位目录与高亮文件、直接预览含相对静态资源的 HTML 报告、PDF、Office 文档、图片及支持 HTTP Range 拖拽的音视频媒体。
- 全平台 Linux / Windows / macOS 电脑端组件直连检查与一键更新：在桌面端「设置 › 更新」以及移动端「设备 › 更多操作 / 设置 › 电脑端组件更新」中，支持按设备在线检查并一键更新 `hc`、`Herdr 桌面版`、`Herdr 终端`、`uniflo` 与 `Pocket 守护进程 (hostd)`，自动执行安装包 SHA-256 校验与原子替换（macOS、Windows、Linux 全平台适配）。
- macOS 灵动岛（Dynamic Island）联动与 Ovis 四级分类提醒中心：后台 Agent 状态变化按「需要审批」「提问待答」「异常报错」「任务完成」四级优先级自动聚合，窗口未聚焦时在屏幕顶部硬件刘海或菜单栏中央以灵动岛胶囊形式实时弹出；悬停展开全量待处理队列，点击一键激活主窗口并精准跳转到对应空间、标签与分屏窗格。
- 120fps ProMotion 解锁、丝滑分屏挤压动画与终端文本实时自适应重排：在 macOS 非低电量模式下解除 `WKWebView` 60fps 渲染帧率限制；分屏新建与关闭改为同帧 `requestAnimationFrame` 驱动 `0 -> 目标尺寸` 连续挤压过渡，拖动分割线按帧合并重绘，终端窗口尺寸变化时直接按单元格重算行列并实时重排已有文本，消除原有重渲染闪烁与卡顿。
- 递进式组合快捷键实时指引：按住 `⌘`（Windows/Linux 为 `Ctrl`）显示基础角标与底部快捷引导条；保持按住的同时继续按下 `⇧` 或 `⌥`，角标与引导条即时切换为 `⌘⇧`、`⌘⌥` 或 `⌘⌥⇧` 对应指令并在邻居分屏中央展示方向聚焦/交换提示，松开后级键平滑退回上一层。
- 恢复标准/精简折叠语义与恒定发送按钮，彻底消除 Chat UI 发消息误切终端模式：修复「标准」模式退化为「精简」的问题；右下角发送按钮在空闲与运行中始终保持稳定发送图标与形态（桌面端与移动端同步）；从底层切断 `Ctrl+O` 反向切换与历史滚动回溯误判，确保 Chat UI 发送文本或斜杠命令后终端稳妥停留在可输入状态。

## 新增功能

- 跨设备会话级回传系统（`portal.*` 协议与 `hostd/portal` 模块）：
  - 全平台窗口抓取与键鼠注入驱动：支持 macOS（CoreGraphics Swift Helper / JXA / `screencapture`）、Windows（Win32 `EnumWindows` / `PrintWindow` / GDI+ 抓帧与键鼠事件注入）以及 Linux 多桌面环境自动识别与 systemd GUI 环境变量发现（X11：`wmctrl`/`xwininfo`/`maim`/`import`/`scrot`/`ffmpeg`/`xdotool`；Wayland wlroots Hyprland/Sway：`hyprctl`/`swaymsg`/`grim`/`ydotool`；KDE Plasma：`spectacle`/`ydotool`；GNOME：`gdbus`/`gnome-screenshot`/`ydotool`；无界面服务器模式自动降级 CDP 浏览器与文件/目录/HTML 回传）。
  - 协议直连文件通道与中继兜底：DirectServer 挂载 `/v1/portal-fs/<token>/...`（支持 CORS、HEAD、RFC 7233 `206` 字节 Range、相对资源加载与 `.env`/越界目录严格 `403` 拦截），并补充 `files.readChunk` 与 `portal.bundleHtml` 作为 Relay 兜底路径。
  - CLI 手动命令与拦截钩子：新增 `herdr-pocket open` 命令及受控 `portal-shims`（`open`、`xdg-open`、`gio`、`sensible-browser`、`wslview`），配合终端 OAuth/localhost URL 屏幕感知实现零配置自动回传。
- 全平台组件直连更新服务（`tools.check` / `tools.update` / `tools.updateStatus`）：支持桌面端与移动端按设备独立触发或批量升级 `hc`、`Herdr 桌面版`、`Herdr 终端`、`uniflo` 与 `hostd`。
- 新增 `general.fontFamily` 全局界面字体替换配置：可在「设置 › 外观」中从本机已安装字体挑选并实时预览，同步覆盖 `--font-body` 与 `--font-cute`。
- 新增 Ovis 待处理提醒中心（`attentionCenter`）、状态栏待处理弹窗面板及 `general.dynamicIsland` 开关：支持在「设置 › 提醒」中随时预览灵动岛与窗口内提醒效果。
- 侧栏工作空间图标改版：将原本彩色单字母方块升级为与主题自适应一致的线性矢量图标系统，支持空间右键菜单自由更换图标并持久保存。

## 交互与体验优化

- 跨端文档预览扩展：新增 `.doc` / `.docx` / `.rtf` / `.odt` / `.xls` / `.xlsx` / `.ods` / `.pptx` 等扩展名识别与回传直览支持；支持从跨端文件查看器一键下载到本地。
- 终端分屏局部优先路径优化：在本机未启动桌面伴生程序时快速跳过超时等待并短暂缓存状态，本地分屏与标签开启即时响应。
- 渲染热路径优化：`useAgent` 与 `TabChip` 改为按宿主键值 O(1) 索引查找，去除 `background-attachment: fixed` 整页固定重绘，对话列表滚动测量合并至 `requestAnimationFrame`，分屏容器启用 `contain: layout paint style` 隔离重排边界。
- 消除 `.agent-run-card` 与当前运行工具卡之间「正在执行」的重复文本展示；将移动端运行中断按钮集成至对话底部「正在干活」卡片，桌面与移动端发送区布局统一对齐。

## 问题修复

- 修复远程 Agent 打开绝对路径文件时因未判断本机归属 (`!localHostId`) 而误触发本机打开逻辑的问题，确保跨机器文件严格通过 P2P / Relay 协议打开与下载。
- 修复 macOS 端下载离线语音降噪引擎（ONNX Runtime `libonnxruntime.dylib`）后，因 Hardened Runtime 团队签名校验导致 `dlopen` 报错无法加载的问题，补充 `disable-library-validation` 授权、SHA-256 侧车摘要校验与隔离属性清理。
- 修复 `chatFold` 在「标准」模式下将思考块并入单一折叠组的问题，恢复思考块独立默认折叠、工具调用连续分组、连续错误重试自动合并的清晰层次。
- 修复 `hostd` 在 Chat UI 发送消息或执行 `/config`、`/usage`、`/status` 等命令时意外让终端停留在非输入模式的问题：改用幂等 `Esc` 代替可能反向切入详细记录视图的 `\x0f` (`Ctrl+O`)，将面板检测限制在当前可见视口（`history = 0`）并尊重活跃输入提示符保护，安全关闭弹窗型斜杠命令并在粘贴流中过滤冗余控制字符。
- 修复 HarmonyOS 与移动端构建及直连传输类型一致性，确保多端交互与协议同步。

## 多端与升级说明

- 本次发布构建并交付桌面端（macOS `arm64`/`x64` 已签名并经 Apple 公证的 `.dmg`、Windows 安装包、Linux `.AppImage`/`.deb`）、中转服务 `relay`、电脑守护进程 `hostd`、移动端及 HarmonyOS 产物。
- macOS 用户从 GitHub Release 下载 `v0.2.25` 公证 `.dmg` 或通过新版应用内更新即可体验灵动岛联动、120fps 分屏动画、P2P 跨端回传浮窗与组件直连更新；Linux 与 Windows 电脑执行 `herdr-pocket update` 或直接在桌面/移动端触发升级后即可获得完整的 X11/Wayland/Win32 跨端回传与直连更新能力。
