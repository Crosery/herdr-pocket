# Herdr Pocket v0.2.52 更新说明

本次 **v0.2.52** 聚焦**iOS 添加到主屏幕（Standalone PWA）底部空白与软键盘挤压修复、手机端 H5 小羊助理卡片排版优化**，以及**线上 H5（`/app/`）、管理后台（`/admin`）与中转服务端静态前端包的无弹窗静默自动更新闭环**。

## 更新亮点

- **彻底修复 iOS 主屏幕 PWA 底部大块留白与挤压问题**：针对 iOS Standalone WebKit 将安全区从 `100dvh` 中扣减导致壳层短截的顽疾，切换为固定物理视口边界（`position: fixed; inset: 0;`）与首绘前 `data-standalone` 识别，并补充冷启动状态栏/灵动岛安全区兜底，让底部导航栏严丝合缝贴合屏幕底缘、上方标题不再被状态栏遮挡。
- **中转服务端静态前端包热同步（`/app/` 与 `/admin`）**：`ReleaseCache` 在检测到新版本发布并广播 `release_update` 前，先下载经 SHA-256 校验的 `.tar.gz` 发布包提取最新 `web/dist` 与 `admin/dist` 写入可写状态目录并热切换服务目录（兼容 systemd 只读保护并在重启后自动恢复），线上无需等待重启即可对外提供最新版 H5 与管理台。
- **管理后台（`/admin`）与全宽度 H5 无弹窗静默自动更新**：`/admin` 新增入口资源签名对比与状态感知静默刷新，在未编辑表单与无弹窗开启时自动重载同步新版（保留当前会话登录令牌），全端 H5 统一屏蔽桌面式更新弹窗与红点提示。
- **手机端 H5 小羊助理通知卡片与输入栏视觉对齐**：通知卡片与确认动作卡铺满移动端卡片宽度（左右对齐底部输入框），超长设备/Agent 标题自动单行省略，消除右侧留白与时间标签挤压。

## 新增功能

- **中转静态前端包热同步引擎（`apps/relay/src/releases.ts` / `web` / `admin`）**：
  - `ReleaseCache` 新增 `autoSyncUiBundles`、`syncUiBundleForVersion()` 与 `ui-bundles/` 持久化恢复机制，支持从 `herdr-pocket-<version>.tar.gz` 安全解压新版 H5 与 Admin 静态资源并自动清理旧缓存（保留最近 2 个版本）。
  - `/v1/admin/overview` 新增 `uiVersion` 字段，反映中转当前热加载的界面版本。
- **管理后台静默更新监听器（`apps/admin/src/lib/autoUpdate.ts`）**：
  - 支持在启动后、标签页切回前台、网络恢复及 `/v1/admin/overview` 版本变化时静默对比 `admin-assets` 入口哈希；若正在输入文本或弹窗处于打开状态则延后至失焦或关窗后平滑重载。
  - 将 `apps/admin/package.json` 与 `apps/admin/` 纳入 `scripts/set-version.mjs` 版本号同步及 `scripts/detect-release-channels.mjs` 发布通道检测。

## 交互与体验优化

- **iOS 软键盘弹起自适应高度（`visualViewport`）**：监听 `visualViewport` 与输入焦点进入 `data-kb-open="true"` 模式，将可视化高度注入 `--h5-vv-height`，临时隐藏底部 4 标签栏并将 `--safe-bottom` 归零，消除键盘上方多余底栏与空白占高，同时防止 WebKit 整页上顶偏移。
- **小羊助理移动端卡片全宽排版（`AssistantView` / `mobile-parity.css`）**：
  - 通知卡与动作确认卡（`.bubble-row.assistant.is-card > .pk-card`）扩展至与输入栏一致的 `12px` 边距圆角白底卡片，长标题徽章（`PocketBadge`）在窄屏下优先省略自身文本。
  - 调整 `.mp-shell .t3-composer-shell` 内外边距，去除移动端详情页底部双倍安全区留白。
- **全视口 H5 更新弹窗静默守卫**：在 `App`、`ShellSidebar`、`SettingsView` 与 `SettingsFrame` 统一通过 `!isH5Web()` 屏蔽更新提示角标；Service Worker 升级至 `herdr-pocket-shell-v11` 并直接放行 `__pocket_check` 探活请求，避免本地缓存遮挡上游 HTML 检查。

## 问题修复

- **修复 `.mp-shell` 与 `.h5-auth-screen` 使用 `100dvh` 在 iOS 主屏幕模式高度塌缩**：`data-standalone="true"` 与 `@media all and (display-mode: standalone)` 下根容器统一铺满物理视口，并为 `html` 设置主题背景底色防止露白。
- **修复 `data-kb-open="true"` 时 `-webkit-fill-available` 阻塞 `#root` 高度收缩**：在软键盘打开态显式清零 `min-height`，确保输入栏紧贴键盘上沿。
- **修复存在顶部横幅时 `.assistant-pane-header` 与 `.mp-top-banners` 叠加双倍安全区高度**：在 `.mp-shell.has-top-banner` 下固定收口为 `min-height: 54px`。

## 多端与升级说明

- **支持平台**：中转服务端与电脑端 `hostd`（`herdr-pocket update`）、桌面端（macOS `arm64`/`x64`、Windows `x64`、Linux `x64`）、Android（`.apk`）、iOS（`.ipa`）、HarmonyOS NEXT（`.hap`）以及网页 H5（`/app/`）与管理后台（`/admin`）。
- **升级建议**：建议尽快将中转服务端更新至 **v0.2.52**；更新完成后，手机端已添加到主屏幕的 H5 与浏览器管理后台将在后台静默刷新同步本次 iOS 布局修复与无弹窗自动更新能力。
