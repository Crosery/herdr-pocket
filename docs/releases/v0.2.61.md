# Herdr Pocket v0.2.61 发布说明

本次 **v0.2.61** 是一次面向日常重度使用的**深度稳定性、状态机一致性、全 Harness Chat UI 提问接管与性能能耗专项修复版本**，彻底解决终端切换空白、Chat UI 与终端会话串话、「已完成 ↔ 空闲」状态来回跳动、全 Harness Ask 无法在聊天页响应、空 `~` 工作空间反复复活，以及主机 CPU 与桌面高刷空闲唤醒偏高等核心痛点。

## 更新亮点

- **全 Harness Chat UI 统一接管 Ask 提问（桌面端 + 移动端同步）**：不再只依赖 `hc` 上报 `blocked` 才能弹出提问卡片——协议层新增 `AgentInteraction` 结构化交互状态，主机端结合终端屏幕正向识别与 Uniflo 实时提问工具事件，将 Antigravity、Claude Code、Codex、Oh My Pi、Pi、Gemini CLI、OpenCode 的单选、多选与自定义输入提问直接同步到 Chat UI 卡片，并严格保持授权审批（`permission` / `auth`）最高优先级、绝不降级。
- **彻底修复「已完成 ↔ 空闲」状态乱跳**：重构 `hc` 列表拉取与合并管线（单飞合并 + 代次拦截 + `turn` / `herdr.seen` 单调水位不回退）、为异步屏幕复核补齐 CAS 签名校验、移除桌面与移动端在 `agent.seen` 返回前的乐观状态覆盖并增加 `turn` 轮次守卫；同时修正 `turn <= 0` 的新终端降级语义，不再误卡「已完成」或误报完成提醒。
- **根治终端切回空白与 120Hz 空闲高唤醒**：重构桌面端 `TerminalSurface` 激活与 WebGL 生命周期——修复隐藏后 WebGL 清空未重绘、移除冷启动同步挂载卡顿、分屏切焦点不再整屏重刷、`webglcontextlost` 立即回退 DOM 渲染并安全释放上下文、隐藏期保留 VT 控制序列防丢帧，并增加启动异常兜底与 1.2 秒零字节自动恢复；引入 `data-blurred` 与 `data-user-idle`（45 秒无操作）自动暂停常驻动画，显著压低高刷屏空闲唤醒频率。
- **修复 Chat UI 与终端会话串话及 Uniflo 错配**：修复 `t1fs` 等终端切换新会话（经过瞬时 `undefined`）时旧会话高偏移消息混入底部的问题，全链路增加 `sessionEpoch` 代次与 `res.sessionKey` 校验，丢弃晚到的旧会话响应；优化主机端 Uniflo 匹配（PID 择优、Antigravity 交互续跑支持、`is:root` / `is:sub` 查询分离与 SSE 原地更新），大幅降低 `hostd` 稳态 CPU 占用。
- **消除空 `~` 工作空间反复复活与加固本地凭据边界**：过滤 `herdr` TUI 默认内置的空 `~` 占位工作区（仅在无标签、无窗格、无 Agent 时过滤，真实工作空间不受影响），删除后不再被周期性同步复活；文件系统层按路径段无条件拦截 `.agents/**/credentials`（含软链接目录），全面保护本地凭据安全。

## 新增功能

- **跨进程 `AgentInteraction` 协议契约**：`packages/protocol` 新增可选 `Agent.interaction`（支持 `permission` / `question` / `auth`、选项列表、多选标记与来源标识）及 `agent.seen` 可选 `turn` 参数，向下兼容旧版主机与客户端。
- **跨 Harness 提问选项解析增强**：`askQuestion` 协议工具补充 `ask_human` / `user_input` / `clarify` 工具名识别，并将终端选项解析升级为剥离完整 ANSI CSI / OSC 转义序列。
- **移动端 `WaitingCard` 全面对齐桌面端 Ask 体验**：支持 `agent.interaction` 即时展示、结构化工具兜底、多选勾选（`space` + 提交所选）、自定义回答行内输入与「推荐」徽章，并与桌面端共享未同步多选防光标漂移保护。
- **主机事件循环延迟遥测**：`sys.host_pulse` 补充事件循环延迟统计（`elMeanMs` / `elP99Ms` / `elMaxMs`），便于定位主机侧卡顿。

## 交互与体验优化

- **桌面与主机资源占用全面瘦身**：
  - 主机端拉宽非关键扫描周期（屏幕复核 `5s`、端口扫描 `15s` + 终端 PID 变化防抖、命名同步 `10s`）、对 `usage` 额度查询增加并发去重与失败缓存，并去掉冗余全量 Uniflo 列表刷新。
  - 桌面端按空间拓扑签名节流 `spaces.list`、在已有可用更新时停止 60 秒轮询风暴、无 `sessionKey` 时不再空转会话流，并仅在标签可见且存在待处理提问时按需轮询终端选项。
  - 终端光标闪烁仅在标签激活、窗格聚焦且窗口聚焦时启用，减少后台重绘。
- **macOS iCloud 云端占位文件友好提示**：读取未下载到本地的 iCloud `dataless` 文件（`errno -11` / `EDEADLK`）时自动静默触发 `brctl download` 并返回可读中文提示，不再抛出晦涩系统错误。
- **演示模式（Mock）对齐**：为演示数据补充结构化 `interaction` 样例，便于离线预览与回归验证。

## 问题修复

- **修复终端空白与黑屏**：修复隐藏标签切回时 WebGL 清模型后跳过重绘、启动 `Promise` 异常导致界面永久停留在透明未就绪态、隐藏期超过 256 KB 丢弃头部切屏序列、以及 `history: 0` 参数被 `|| 2000` 误改回 2000 行的问题。
- **修复 Chat UI 显示旧会话内容**：修复 `sessionKey` 瞬时丢失后再切入新会话未清空旧消息、`reopened` / `poll` / `recovery` 未核对返回 `sessionKey`、以及慢速初始页晚到覆盖新会话的竞态问题。
- **修复「已完成」与「空闲」闪烁及误标**：修复并发 `hc.list()` 乱序覆盖、旧快照覆盖新 `herdr.seen`、异步读屏跨状态写入、`herdr.seen` 非字符串值导致 `list()` 异常毒化后续队列、以及原生 `herdr` TUI 终端已读标记失效问题。
- **修复授权提示被误判为普通提问与历史输入误报**：完善 Codex / Claude 授权文案识别与选项行上方多行扫描（跳过 `$ command` 优先提取提问句），避免覆盖 `permission` / `auth` 提醒等级；同时排除开放式 `Which/How ... would you like to run?` 误判、旧版 Claude 圆角草稿框与旧版 Codex `▌` 光标误触发。
- **修复桌面与移动端流订阅恢复**：修复桌面端终端流把心跳/元帧误计为已送达输出、移动端因 `offline` / `timeout` 临时错误误删订阅导致重连后停止更新的问题。
- **更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v20`）**：确保网页端与 PWA 升级后即时加载最新资源。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.61.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.61`）。
- **兼容与升级**：全量向下兼容，无需重新配对或迁移配置。建议同步更新中继服务、各主机 `hostd`（桌面端「设置 → 电脑与中继 → 升级 hostd」或执行 `herdr-pocket update`）以及桌面/移动端客户端以获得完整的状态机与跨 Harness Ask 体验。
