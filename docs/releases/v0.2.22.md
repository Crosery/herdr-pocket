# Herdr Pocket v0.2.22 更新说明

Herdr Pocket `v0.2.22` 全面对齐桌面 Herdr 应用的空间标签、分屏、文件打开与窗格交互体验，消除点击文件或缩放窗口时的终端重渲染闪烁，并重点优化手机端实时语音连线与说话人过滤的响应速度与稳定性。

## 更新亮点

- 修复分屏失败与布局回退问题：桌面端点击分屏按钮、快捷键、右键菜单或从侧栏/标签栏/文件树拖入窗格，均可在当前标签页内稳定分屏，并与本机及远端电脑的 `herdr-app` 共享布局文档双向同步。
- 标签命名、宽度自适应与空间归属全面对齐 `Herdr.app`：未自定义名称的标签优先展示当前 Agent 任务标题与程序名（如 `Claude Code`、`Codex`、`Antigravity`、`Terminal`），不再只显示纯数字编号 `1..N`；标签卡随窗口宽度平滑收缩，非当前且未悬停的标签自动隐藏关闭按钮；文件、差异对比与内置网页标签严格随所属空间归档，切换空间自动恢复该空间记忆的活动标签与右侧栏面板。
- 点击文件或调整窗口大小时零终端重渲染：引入已访问 Agent 标签保活缓存，调整内嵌文件点击、窗口聚焦与宿主尺寸同步路径，并对终端尺寸自适应加入防抖收敛，彻底避免切到文件再切回或拖动窗口时重新连接、清屏与回放闪烁；窄窗口下桌面端维持精简图标导航布局而不整壳卸载重建。
- 本地文件全面打通内置打开、系统默认应用与访达定位：无论是可直接预览的文档/HTML/音视频/代码，还是安装包/归档等二进制文件，均支持用内置浏览器预览（本地 HTML 自动签发目录作用域能力令牌以正确加载相对路径图片与样式）、调用系统默认应用打开，以及常驻可点击的「在访达中定位」入口与文件树右键菜单。
- 手机端语音通话连接与响应提速：中转服务加入并行探测与握手前 1.6 秒语音预缓冲重放、放宽静默门限与 VAD 灵敏度并抢占后台唤醒任务；iOS 与 Android 端扩充人声分离预缓冲、加入单步超时与欠载快速旁路及扬声器声纹适配，同时修复 Android 端未下载可选声纹/人声分离模型时直接拒接挂断的问题。

## 新增功能

- 新增本地 HTML 与富媒体能力令牌预览机制（`pocket-local://localhost/cap/...`）：桌面端在内置浏览器与文件预览窗格打开本地 HTML 时，同目录下的相对路径图片、脚本与样式均可正常加载，且严格限制在所属父目录及非敏感路径内访问。
- 新增 `ShellTabs` 按空间筛选与 `panelBySpace` 记忆状态，支持点击全球侧栏中的任意 Agent 时跨空间、跨电脑自动跟随切换并还原对应工作布局。
- 新增中转实时语音服务并行对冲建连（Hedged Dial）与后台唤醒抢占机制，实语音轮次下立即中止低优先级巡检并约束单次后台查询超时，避免慢请求阻塞语音问答。

## 交互与体验优化

- 标签栏（`.v3-tab`）改为自适应弹性收缩（`78px..210px`），窗口缩放时自动保持当前激活标签在可视区域内滚动对齐。
- 工作区窗格顶栏右侧容器（`.v3-pane-right`）保持右对齐：窗格次要操作按悬停状态按需展开，而本地文件窗格的「内置浏览器」「系统打开」「访达」按钮常驻可见，在独立预览头、二进制回退视图及文件树文件/目录右键菜单中保持一致操作。
- 统一 macOS 本地文件目录操作文案为「在访达中定位」/「在访达中显示」。

## 问题修复

- 修复本地与远端分屏在并发同步或缺失显式空间时被退回为独立标签页的问题，以及拖放侧栏条目或标签时子图标吞没事件与拖拽动画残留偏移的问题。
- 修复终端窗格在点击应用内文件标签或文件树丧失 textarea 焦点后误触发 `reattachLocal` 重新挂载导致闪屏重绘的问题，以及桌面端宽度低于 `860px` 时切换成移动端外壳导致整个工作区终端销毁重建的问题。
- 修复 `FilesPanel` 打开文件缺少 `absPath`、部分启动阶段 `localHostId` 尚未就绪或 `local` 设备文件未开放本地访达定位的问题。
- 修复 Android 端缺少可选声纹或人声分离模型时直接中断通话、以及移动端外放扬声器场景下 VoxLock 多次超时欠载导致 `server_vad` 无法识别用户说话的问题。

## 多端与升级说明

- 本次发布包含桌面端（macOS / Windows / Linux）、中转服务 `relay`、电脑守护进程 `hostd`、Android / iOS 客户端及 HarmonyOS Web 产物。
- 请先更新中转服务 `relay` 与各接入电脑的 `hostd` 守护进程；macOS 桌面端提供带签名与 Apple 公证的 `arm64` / `x64` DMG，可直接通过应用内更新或安装包升级，现有空间、标签布局与运行中会话完整保留。
