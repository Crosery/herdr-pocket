# Herdr Pocket v0.2.24 更新说明

Herdr Pocket `v0.2.24` 带来终端图像协议对齐、渐进式对话工作流折叠与不打断插队交互、非输入型子面板极速脱困以及按渠道独立发布的 OTA 升级体系，同时补齐分屏丝滑过渡、`cmux` 风格按住快捷键提示与多 Harness 命令捕获体验。

## 更新亮点

- 本机终端原生图像预览对齐桌面主程序体验：本机 PTY 会话完整补齐 `TERM_PROGRAM=herdr`、`t=s` 共享内存与 `o=z` zlib 解压、Rust 端百毫秒内即时应答 Kitty 查询（`a=q`）与 `z<0` 终端底层叠加渲染，`yazi`、`kitten icat`、`chafa`、`viu` 等工具在本机终端内即可直接高清出图。
- 渐进式单步工作流与消息折叠升级（桌面端与移动端同步）：标准模式与紧凑模式下不再将长回合拆碎为数十条孤立思考卡与单步工具条，而是按真实发生顺序渐进收敛为单一紧凑工作流块，并在回答到达后自动收起；同步彻底过滤 `<SYSTEM_MESSAGE>`、`<session_context>`、`system_message`、`developer` 等 Harness 内部注入噪声。
- 排队与不打断插队交互全面重构：忙碌时 `Enter` 加入排队，新增 `⌘Enter` / `Alt+Enter` 与「插队」按钮执行**不打断当前轮**的软插队发送，保留「打断」作为显式终止并发送操作；发送气泡与排队架全程保留附件图片缩略图与路径直至对话流确认回显。
- 突破终端 `/usage`、`/status`、Transcript 与 `less` 分页卡死困局：`hostd` 通过直连底层流极速识别并安全关闭只读面板、标签页信息框、Transcript 与 `less`/`man` 分页器（严格跳过权限审批、选择题与运行中 `(esc to cancel)` 状态），并在面板未关闭时于「终端」切换键展示微弱提示圆点。
- 按渠道维护独立版本号的 OTA 更新清单：引入 `RELEASE-MANIFEST.json` 与渠道变更检测脚本，后续仅发布某一端或某几个渠道时，未发生变更的渠道自动沿用上一版本的成品包信息与 SHA-256 校验和，避免移动端在仅更新桌面端或服务端时误报新版提示。

## 新增功能

- 新增 `RELEASE-MANIFEST.json` 多渠道发布清单与 `scripts/detect-release-channels.mjs` / `scripts/build-release-manifest.mjs`：按 `desktop`、`android`、`ios`、`harmony` 与 `bundle`/`image` 独立记录版本号、产物文件名与校验和；桌面端与移动端检查更新优先解析清单并在非自身渠道单独发版时静默跳过。
- 桌面端全局快捷键与帮助系统全面升级：新增 `cmux` 风格按住 `⌘`（macOS）实时展示页签编号与窗格/操作角标，新增居中弹窗式的 `⌘/` 快捷键指南（支持按分组筛选与关键词检索），并支持 `⌘W` 优先关闭当前聚焦分屏窗格。
- 协议层新增 `Agent.statusKind`、`Agent.subscreen` 与 `terminal.send` 的 `delivery: "auto" | "steer"` 字段；工作台聊天栏、排队架、状态栏与分屏操作面板均同步支持软插队、排队防抖（`600ms` 连续空闲确认）及终端排队气泡置底保序。
- 新增前端关键操作遥测日志（包含带图片启动或发送各 Agent Harness 时的前置参数、工作目录与错误细节）以及无 UI 噪声的纯图标提示体系。

## 交互与体验优化

- 对话与终端模式零卸载瞬时切换：保持 `.chat-scroll-wrap` 与终端实例双视图挂载并在空闲 `180ms` 后预热本机终端，切出再切回对话时完整保留滚动位置并自动恢复输入框焦点，移动端同步改用隐藏保活切换 `对话` / `终端`。
- 优化分屏切换与尺寸过渡动画：左右/上下分屏引入平滑过渡动画，避免邻居窗格在分屏瞬间因布局突变发生视觉闪屏。
- 按时间轴交叉穿插斜杠命令结果卡片，避免 `/cost`、`/status` 等历史命令卡片长期堆叠在最新回复之后；同时清理对话气泡内已渲染图片缩略图下方的重复 `[Image #n]` 文本芯片。
- 将 `hcscreen.paste` 粘贴文本后发送 `\r` 的默认等待从 `30ms` 提高至 `140ms`，显著改善 Ink / Bubble Tea / Rust TUI 长文本与多行提示词吞回车问题。

## 问题修复

- 修复本机终端中 `yazi` 等图像程序因 `a=q` 未在窗口内应答回退到缺失命令报错、Alt Screen 下背景图被擦除及 `a=d` 清理时序竞态的问题。
- 修复带图片消息触发新建不同 Agent Harness 时的状态传递与异常定位问题，补齐多 Harness（Claude Code、Codex、OMP、Pi、OpenCode、Gemini 等）的斜杠命令与模型切换适配。
- 修复忙碌状态闪烁导致的误排空排队、等待回复卡片与运行中工具条重叠显示，以及发送完成后提前释放本地图片缩略图的问题。
- 修复工作期终端误将 `(esc to cancel)` 当作弹窗面板退出，或在权限审批提示框前错误发送按键的风险。

## 多端与升级说明

- 本次发布涵盖桌面端（macOS `arm64`/`x64` 已签名并经 Apple 公证的 `.dmg`、Windows 安装包、Linux `.AppImage`/`.deb`）、中转服务 `relay`、电脑守护进程 `hostd`、Android `.apk`、iOS `.ipa` 与 HarmonyOS NEXT `.hap`。
- 推荐按「中转服务 `relay` -> 各电脑 `hostd` 守护进程 -> 桌面端与移动端客户端」顺序升级至 `v0.2.24`；升级后桌面与移动端即可无缝使用按渠道独立校验的新版 OTA 更新机制。
