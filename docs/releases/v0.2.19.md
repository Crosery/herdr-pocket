# Herdr Pocket v0.2.19 更新公告

## 更新亮点

- **紧急修复桌面端终端恢复/打开时的白屏崩溃（TDZ）**：修正 `v0.2.18` 中 `TerminalSurface` 在 `useEffect` 顶部同步挂载 `WebglAddon` 时提前读取后置 `let alive = true` 引发的 `ReferenceError: Cannot access uninitialized variable` 致命异常，彻底恢复桌面端冷启动还原终端标签页及切换终端模式时的正常渲染。
- **新增视图与标签页错误边界隔离（`PocketErrorBoundary`）**：为根界面、终端视图以及工作区 `AgentPane` / `FilePane` / `DiffPane` 统一加上 React 错误边界与友好恢复卡片，防止单个子视图或工作区异常波及整窗白屏。
- **自动化 AST 暂时性死区（TDZ）守卫**：在桌面端测试套件中引入基于 TypeScript 语法树的静态检测，自动扫描并拦截块级 `let` / `const` 声明前引用风险。

## 新增功能

1. **全链路视图故障隔离与日志上报（`PocketErrorBoundary`）**：
   - 在 `apps/desktop/src/components/PocketUI.tsx` 新增通用 `PocketErrorBoundary` 组件，当子组件树抛出渲染错误时自动记录带组件栈定位的 `app.boundary` 错误日志，并展示包含「重新加载视图」按钮的优雅恢复界面。
   - 同步接入桌面工作台（`AgentPane`、`FilePane`、`DiffPane`）、终端容器与根应用壳层，并在 `resetKey`（如切换标签或模式）变化时自动清除旧错误状态。
2. **TypeScript AST 前置声明静态防线**：
   - 桌面端单测新增面向 `TerminalSurface` 的词法作用域前向引用扫描，持续守卫 `let` / `const` 初始化顺序。

## 交互与体验优化

- **单标签异常局部可恢复**：即使某个文件预览、差异对比或终端渲染出现异常，侧栏、其余标签页与顶栏仍保持可用，用户可直接切换其他标签或点击「重新加载视图」快速恢复。

## 问题修复

- **修复 `v0.2.18` 桌面端启动或切换终端视图时全窗白屏**：
  - 将 `TerminalSurface` `useEffect` 中的 `alive`、`sawRaw`、`fallbackLines`、`splitter`、`placeholderRewriter`、`textDecoder`、`pendingBytes`、`flushRaf` 及 `isAlt` / `numParam` 上移至初始化逻辑与闭包定义之前；
  - 将框选拖拽处理器中的 `cleanup` 提前以 `let cleanup` 声明并在监听器挂载前完成赋值，消除同文件内全部 `let` / `const` 暂时性死区前向引用。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并过苹果公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **强烈建议所有 macOS / Windows / Linux 桌面端用户立即升级至 `v0.2.19`**：本版本修复了 `v0.2.18` 启动还原 `mode: "term"` 标签页或切入终端视图时的必现白屏问题；若本地配置已保存终端活跃标签导致 `v0.2.18` 启动即空白，直接覆盖安装 `v0.2.19` 启动即可恢复正常。
