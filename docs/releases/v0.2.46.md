# Herdr Pocket v0.2.46 更新说明

本次 **v0.2.46** 围绕 **「本机直连 60 FPS 低延迟画面流、彻底消除被动鼠标弹开、跨端小窗默认收起与动态叠牌露头交互」** 全面重构多窗口跨端回传管线，借鉴 VNC 脏帧静默与 RustDesk 滑动信用窗口模型，让多窗口并行观察与实时接管兼具流畅度与零打扰体验。

## 更新亮点

- **本机直连多窗并发与 60 FPS 极速管线（`osCapture.ts` / `portal_bridge.rs` / `portalClient.ts`）**：
  - **多路持久捕获池（`maxConcurrentStreams = 6`）**：彻底淘汰旧版单流频繁启停 `SCStream` 与逐帧冷启动子进程的模式，多窗并开不再互相抢占帧率，告别 `1 FPS` 卡顿。
  - **桌面端进程内零 Base64 二进制通道（`local_portal_capture_frame` + `HPB1`）**：macOS Tauri 桌面端新增进程内零 Base64 二进制 IPC 与持续驻留 `serve-bin` 协议（`bridgeVersion: 3`），并兼容回落旧版 `serve` 协议。
  - **VNC / RustDesk 式脏帧短回路与滑动流控**：静态画面返回零字节 `unchanged` 标记不重复传帧；流控升级为 6 帧滑动 ACK 信用窗口与 `512 KB` 二进制队列上限，并彻底剔除 JSON `"portal.frame"` 冗余 `rawBytes` 序列化。
  - **Chromium CDP 前台保活**：引入 `Emulation.setFocusEmulationEnabled` 与 `Page.bringToFront`，防止系统浏览器后台失焦后被降帧。
- **彻底解决小窗悬停/点击弹开 OS 鼠标**：桌面浮窗（`SessionPortalPiP`）与同机窗口查看弹窗（`PortalViewerModal`）默认锁定纯观察模式，被动移动光标不再触发系统指针回放；同时在原生捕获辅助进程加入 `isLocalPocketFrontmost()` 与 `blockedOwners` 防护，避免 `CGWarpMouseCursorPosition` 将本机鼠标瞬移拉走。
- **跨端小窗默认收起与多布局切换（`general.portalDisplayMode`）**：桌面端、H5、HarmonyOS NEXT 与 Android/iOS 设置页统一支持「默认收起 / 叠牌露头 / 平铺展开 / 纵向叠列」四种模式，出厂默认 **「默认收起」**，仅在右上角保留精简胶囊，彻底避免遮挡终端日志与对话正文。
- **动态 `1·2·3·4` 叠牌露头与 `2×2` 平铺展开**：叠牌态在右上角自然叠放露头标题（`<= 4` 个窗口自动收起冗余副标题胶囊），鼠标悬停 `65ms` 意图防抖后下方卡牌优雅让位展开当前悬停窗口的实时画面，单击即置顶切换，配合 `2×2` 平铺模式一屏同时盯防 4 个窗口。

## 新增功能

- **全局配置契约扩展（`packages/protocol/src/index.ts` / `docs/config.md`）**：
  - 新增 `PortalDisplayMode = "collapsed" | "fan" | "tile" | "cascade"`（默认值 `"collapsed"`）。
  - 桌面端、H5、HarmonyOS NEXT（`FramePanes.tsx` / `Panes.tsx` / `MobileSettingsTab.tsx`）与 Expo 移动端（`settings.tsx` / `MobilePortalModal.tsx`）全部同步接入并实时联动。
- **macOS Tauri 原生二进制桥接命令（`apps/desktop/src-tauri/src/portal_bridge.rs`）**：
  - 新增并注册 `local_portal_capture_frame`（支持状态码 `frame / unchanged / denied / error` 与 `HPB1` 帧头协议），客户端自动探测支持情况并优先走进程内直连高速通道。

## 交互与体验优化

- **叠牌露头微交互与纯 GPU 合成动效（`SessionPortalPiP.tsx` / `app.css`）**：
  - 为后台叠牌加入 `is-hovered` 提亮聚焦与 `is-parted` 向下让位动画，仅保留高帧率（`60 FPS`）予顶层主卡，悬停后台卡瞬时切换至 `24 FPS` 实时预览，其余静止后台卡零功耗静默。
  - 优化桌面端 4 窗演示数据集与 HTML 架构预览卡片（`mock.ts`），清晰展现本地直连与中继转发的多窗分工效果。
- **静默帧率显示降噪**：当流处于空闲零帧心跳保活状态（`heartbeat.idle && fps <= 1`）时，隐藏易造成误解的 `· 1fps` 徽标，仅在真实活跃采样流（`fps >= 2`）期间显示实时帧率。

## 问题修复

- **修复多窗口并行回传互相抢流导致的 `1 FPS` 劣化**：消除 `osCapture.ts` 单例捕获切换抖动、旧版双次 Base64 与 JSON `Buffer.toJSON()` 序列化瓶颈。
- **修复被动悬停小窗触发本机光标跳跃**：将浮窗 `directControl` 与同机弹窗 `controlMode` 默认设为纯查看，用户显式切换接管操控后才转发指针事件，且本地客户端在前台焦点态时跳过同机指针回放。
- **修复窗口隐藏或静音切换时 CSS 过渡未即时归位**：为 `:root[data-idle]` 与 `:root[data-calm]` 补充 `transition-duration: 0.01ms !important`（对齐 `prefers-reduced-motion`），避免后台恢复时动画卡在半程。

## 多端与升级说明

- **涵盖平台与 Harness**：支持 Claude Code、Codex、OpenCode、Gemini CLI、OMP、Kimi、Qwen、Droid 等在 `herdr` 中运行的终端工具与通用 Shell；全平台安装包覆盖 **macOS（`arm64` / `x64` `.dmg`）、Windows（`x64` `-setup.exe` / `.msi`）、Linux（`x64` `.AppImage` / `.deb`）、Android（`arm64` `.apk`）、HarmonyOS NEXT（`arm64` `.hap`）、iOS（`arm64` `.ipa`）** 以及网页 H5（`/app/`）。
- **升级建议**：
  - **桌面应用用户请在更新完中转服务器与主机守护进程后，点击桌面端左下角「设置 › 更新」完成客户端原地升级**，以启用全新的 Rust 进程内 60 FPS 捕获桥接与默认收起/动态叠牌小窗体验。
  - 电脑守护进程执行 `herdr-pocket update` 即可同步升级主机端多流捕获组件并重编本地原生辅助程序；升级后跨端小窗默认以右上角精简胶囊收起呈现，可在「设置 › 外观 › 跨端小窗默认显示」随时调整偏好。
