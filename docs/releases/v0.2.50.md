# Herdr Pocket v0.2.50 更新说明

本次 **v0.2.50** 围绕**品牌视觉焕新、AI 模型与上下文监控体系重构、`ask_question` 结构化交互升级、工作区 Space / 分屏拓扑导航、H5 PWA 静默更新与安全区适配**，以及 **Tauri / WebKit 内存、CPU、耗电与按键延迟深度优化**进行全面发布，带来更直观、更丝滑的多端协同体验。

## 更新亮点

- **全新二次元小羊口袋品牌图标**：统一更换桌面端（macOS / Windows / Linux）、iOS、Android、HarmonyOS NEXT、Web PWA、官网与中英文 `README` 为日系赛璐璐二头身二次元小羊口袋形象，同时保留亮/暗双模式自适应展示预览图。
- **AI 厂商官方商标图标全覆盖**：接入 41 家主流 AI 厂商与模型家族官方几何 SVG（基于 `@lobehub/icons` MIT 协议），自动剥离网关前缀并通过词边界匹配，覆盖模型切换下拉框、设置模型列表、待切换提示横幅、用量卡片及移动端对话面板，告别统一的通用芯片图标。
- **上下文「实体试管」与多厂商额度监控面板**：输入框底栏实时展示当前 `TPS`、缓存命中率与上下文环形百分比；点击打开双栏控制卡，左侧提供带刻度线的 `CTX` 液位「实体试管」（可随时切换开关），右侧集中呈现分段 Token 分布、`TTFT · TPS` 性能摘要，以及 `[Gemini | Claude]` 多提供商 5h / 周额度剩余健康状态。
- **工作区 Space 分页与同窗分屏关系一目了然**：侧边栏每个 Space 新增可点击的 `N页` 气泡，一键展开 `P1..PN` 标签页与分屏子窗格芯片，点击直达对应 Space 的目标页或具体分屏格；Agent 列表新增 `状态 | 空间 | 最近` 三段分组切换、同窗分屏左侧连续竖轨及悬停兄弟联动高光。

## 新增功能

- **多端 AI 品牌图标解析模块（`packages/protocol/src/modelIcons.ts`）**：
  - 支持 Anthropic / Claude、Google / Gemini、OpenAI / GPT、DeepSeek、Qwen、Meta Llama、Mistral、xAI Grok、Zhipu GLM、Moonshot Kimi、MiniMax、ByteDance Doubao、StepFun、Ollama 等 41 个品牌标识。
  - 桌面端与移动端分别实现组件级 `useId()` 渐变 ID 隔离与主题色适配。
- **`ask_question` 结构化提问卡与双层 JSON 解包**：
  - 协议层与客户端自动解包双层 JSON 字符串编码的 `questions` 字段，消除工具卡片与活动状态栏中的原始 JSON 文本。
  - 在输入框上方居中呈现结构化 `AskQuestionDeck` 提问卡，支持 `推荐` 徽章、选项副标题及 `自定义输入…`（`Write-in...`）内联输入与回车提交；即使终端屏幕尚未完成抓取，也能直接从结构化工具事件生成交互选项。
- **侧边栏空间拓扑与 UI/UX 对比设置**：
  - 新增纯函数拓扑索引引擎，统一计算每个 Space 下的标签页序号（`P1..PN`）、分屏数（`P1 · 2分屏`）、分屏槽位（`1/2`）及未挂载后台状态（`后台`）。
  - 在「设置 › 外观 / 通用」新增 **「侧边栏 Agent 分组」** 与 **「显示空间分页与分屏关系」** 开关，方便用户自由切换与对比体验。
- **原生本地终端按键直通快路径（`local_term_keys` / `local_term_interrupt`）**：
  - 本地终端通道已建立时直接向 PTY 数据帧写入 VT 按键序列并统计 `perf.key` 上屏延迟，显著降低常规按键与确认选择的交互卡顿。

## 交互与体验优化

- **H5 添加到桌面（iOS PWA）静默更新与安全区适配**：
  - H5 / PWA 端取消桌面端式升级弹窗提醒，改为借助新版 Service Worker（`herdr-pocket-shell-v9`）与入口资源哈希比对在冷启动、切回前台、重连及中转广播新版本时静默重载同步上游（语音通话期间自动避让）。
  - 修复 iOS `standalone` 全屏模式下 `.assistant-pane-header`、顶部断线横幅、通话浮层及无底栏详情页被灵动岛/状态栏遮挡及底部手势区留白异常问题。
- **Tauri / WebKit 内存、CPU 与耗电全面瘦身（不杀后台 Agent）**：
  - 对全量快照同步实施 Agent 对象浅比较结构共享，隔绝后台标签对 `overlayStore`、`shellStore` 与窗口焦点状态的无效订阅；后台面板隐藏 2.5s 后休眠时间线 DOM（保留 `hc` 进程持续工作）。
  - 非活跃终端 WebGL 实例闲置 45s 后渐进回收至轻量驻留数量（保留上限 14）；暂停窗口失焦及隐藏标签下的 CSS 无限动画，并将高频背景位移重绘切换为 GPU 合成层动画；空闲 35s 或窗口失焦时停止周期 `rAF` 采样；为 `portal.list` 能力探测增加 60s 缓存与并发请求合并。
- **修复 Space 标题在页数气泡旁被挤压截断**：将 `.v3-space` 悬停动作按钮由占宽隐藏改为非悬停态不占位显示，完整保留空间名称可读性。

## 问题修复

- **修复跨标签页与跨分屏拖拽串选文字问题**：为隐藏标签图层、隐藏终端子层标记 `inert` 与 `user-select: none`，侧栏及手柄拖拽期间锁定全局选区并清理残留选区，分屏内部划选时锁定相邻窗格避免跨屏选中。
- **修复 `AgentDetailPanel` 前向引用 TDZ 隐患**：调整桌面端组件声明顺序并通过 AST TDZ 门禁检查。
- **修复 `ask_question` 在无终端捕获行时不显示确认面板**：支持无终端 `choices` 时回退渲染工具事件选项，并在收到用户新回复后自动收起已过期的未闭合提问。

## 多端与升级说明

- **支持平台**：覆盖中转服务端与电脑端 `hostd`（`herdr-pocket update`）、桌面端（macOS `arm64`/`x64`、Windows `x64`、Linux `x64`）、Android（`.apk`）、iOS（`.ipa`）、HarmonyOS NEXT（`.hap`）以及网页 H5 / PWA（`/app/`）。
- **升级建议**：建议将受控电脑 `herdr-pocket` 守护进程与常用客户端统一更新至 **v0.2.50**，以同时获得本地按键直通加速、`portal.list` 低开销探测、H5 静默同步以及完整的新版模型图标与工作区拓扑体验。
