# Herdr Pocket v0.2.47 更新说明

本次 **v0.2.47** 在 **v0.2.46**（本机直连 60 FPS 多路回传与动态叠牌露头小窗）的基础上，重塑小羊主动巡检通知的状态谱系——将原有 4 态判定细化为 **7 种语义状态与多端分色徽章**，彻底告别「后台还在跑或阶段完成却误报红色 `没跑成`」带来的心理落差与误判焦虑。

## 更新亮点

- **小羊主动叫醒 7 态精细谱系**：围绕真实工作流将主动汇报拆分为 **跑完了（`ok`）/ 还在跑（`running`）/ 有进展（`progress`）/ 等你（`decide`）/ 等恢复（`paused`）/ 已停下（`stopped`）/ 出错了（`failed`）** 7 种清晰结论。
- **废除「拿不准就报失败」兜底规则（`woken.md`）**：明确规定只要后台构建、测试、CI、发布流水线仍在推进，或单步改动正常通过只是上下文较早被截断，均应判为 **`还在跑`** 或 **`有进展`**，**只有编译/测试持续失败或关键命令报错卡死才允许判为 `没成`**。
- **多端 7 色分级徽章与专属图标（Android / iOS / 桌面 / H5 / HarmonyOS NEXT）**：告警红图标与底色严格收敛至「真正出错（`failed`）」；后台持续构建亮起天蓝呼吸点，`有进展` 亮樱花粉旗帜，`等你` 采用暖琥珀抬手提醒，`等恢复` 亮淡紫月牙，一眼分清优先级、不再每次都像跑失败。

## 新增功能

- **协议契约扩展（`packages/protocol/src/index.ts`）**：
  - `NoticeVerdict` 扩展为 `"ok" | "running" | "progress" | "decide" | "paused" | "stopped" | "failed"`。
- **中转端叫醒解析与汇总标题升级（`apps/relay/src/assistant/`）**：
  - `speech.ts` 的 `parseWake` 支持 `还在跑 / 运行中 / 构建中`、`有进展 / 阶段完成 / 推进中`、`等恢复 / 暂歇 / 额度用完`、`停下了 / 已停下`、`没成 / 出错了 / 受阻` 等多组首行及行内前缀别名解析。
  - `assistant.ts` 更新 `VERDICT_TITLE` 映射并将多 Agent 批量暂停通知标题细化为 `${agents.length} 个 · ${VERDICT_TITLE[verdict]}`（如额度重置场景输出 `4 个 · 等恢复`）。
- **多端视觉表现与调色盘升级**：
  - **桌面端 / H5 / 鸿蒙**：`tokens.css` 新增 `--sky-text` / `--sky-soft` 亮暗双套令牌，`PocketUI.tsx` 扩展 `PocketBadge tone="sky"`，`AssistantView.tsx` 导出 `noticeBadgeVisual` 为 7 态配齐语义图标与呼吸动画。
  - **Android / iOS（Expo React Native）**：`tokens.ts` 新增 `sky` / `warn` 调色令牌，`icons.tsx` 新增矢量旗帜图标 `"flag"`，`notice.tsx` 为 `noticeLook` 补全 7 态专属图标与高对比柔和色板。

## 交互与体验优化

- **语气分级，减少不必要紧张感**：`woken.md` 对 `还在跑`、`有进展`、`等恢复` 三态给出轻松平实的通知示例，并在演示模式（`mock.ts`）新增 `release · 还在跑` 实时呼吸徽章卡片。
- **状态微调不割裂旧端**：旧版客户端遇到新增 `verdict` 值时会优雅回落至柔和淡紫铃铛样式并直接显示新标题（`· 还在跑 / 有进展 / 等恢复`），升级前即可立刻受益。

## 问题修复

- **修复后台构建尚在运行却被标红 `没跑成` 的高频误报**：解决上一版提示词仅 4 态且将不确定情形默认归入 `failed` 导致的误报问题。
- **修复手机端 `等你` 与 `没跑成` 红色撞色**：`decide` 独立迁移至暖琥珀 `warn` 语义色板，与真正报错红 `error` 清晰区隔。

## 多端与升级说明

- **完整继承 v0.2.46 全部能力**：同时包含本机直连 `maxConcurrentStreams = 6` 多路并发 60 FPS 小窗、被动悬停零弹开 OS 鼠标、默认收起右上角胶囊、动态 `1·2·3·4` 悬停露头叠牌及 `2×2` 平铺展开。
- **覆盖平台与 Harness**：支持 Claude Code、Codex、OpenCode、Gemini CLI、OMP、Kimi、Qwen、Droid 等终端工具；发布产物覆盖 **macOS（`arm64` / `x64` `.dmg`）、Windows（`x64` `-setup.exe` / `.msi`）、Linux（`x64` `.AppImage` / `.deb`）、Android（`arm64` `.apk`）、HarmonyOS NEXT（`arm64` `.hap`）、iOS（`arm64` `.ipa`）** 与网页 H5（`/app/`）。
- **升级建议**：
  - 中转端升级并重启后新策略即刻生效；桌面端用户请点击左下角 **「设置 › 更新」**、Android 用户点击检查更新，电脑端运行 `herdr-pocket update` 一并升级至 **v0.2.47** 以获得完整的 7 色呼吸图标与 60 FPS 小窗体验。
