# Herdr Pocket v0.2.15 更新公告

## 更新亮点

- **全局「快速说话」与悬浮胶囊重构为纯正的小羊实时语音通话**：全面移除旧版光标听写（`/v1/transcribe`）与光标粘贴流程，将全局快捷键与工作台右下角「快速说话」入口统一为小羊实时语音通话一键唤醒与挂断，做到「一按即通、再按即挂、挂断即清」。
- **16 kHz 流式实时降噪与声纹过滤（`LiveCallProcessor`）**：桌面端原生麦克风采集新增 `LiveCallProcessor` 与 `LiveMicStream` 流式处理链路，通话开启即以 20 ms（320 采样点）帧节奏实时执行 80 Hz 高通滤波、DPDFNet 降噪或纯 Rust DSP 增强、人声清晰度优化以及 1–1.5 秒滚动声纹 / 首讲人锁定过滤。
- **修复语音模型 `SHA-256 校验未通过` 问题**：修正桌面端 `DPDF_SHA256` 摘要拼写错误，同步校准桌面、Android、iOS 三端 ERes2NetV2 声纹模型体积与 SHA-256 校验值，并调整国内 HuggingFace 镜像优先级与 HTML 错误页快速拦截，彻底解决「只认我的声音」声纹模型下载校验失败。
- **设置页与权限清单精简为「语音唤醒与声纹」**：移除所有听写专属设置项与 macOS「辅助功能」权限依赖，桌面与引导文案全面聚焦小羊实时语音通话唤醒、个人声纹录入及麦克风 / 输入监控权限。

## 新增功能

1. **按一下一键唤醒 / 挂断小羊实时语音通话**：
   - 全局快捷键支持单键轻按（`RightOption` / `RightControl` / `RightCommand` / `RightShift` / `Fn`，650 ms 内干净抬起且无组合键干扰）与组合快捷键（如 `⌘⇧Space`），按一下立即唤起悬浮玻璃胶囊并建立小羊实时语音通话；再按一下或点击胶囊「挂断」立即挂断并关闭麦克风。
   - 新增桌面端原生实时通话桥接命令（`voice_call_mic_start`、`voice_call_mic_stop`、`voice_call_mic_set_muted`、`voice_hud_sync`、`voice_hud_hide`），在 macOS 14+ 通话期间自动切换主窗口 `WKInactiveSchedulingPolicy::None` 防止隐藏/遮挡时 WebSocket 与音频节流，挂断后即时恢复 `Throttle` 并释放 `LiveMicStream`（立即熄灭系统橙色麦克风指示灯）。
2. **纯小羊实时通话悬浮玻璃胶囊（`voice-hud`）**：
   - 全新 `540×84` 透明玻璃胶囊（适配浅色与深色主题），集中呈现小羊动态光球、实时引擎角标（如 `VoxLock + DPDFNet` / `DPDFNet + 声纹` / `DPDFNet 降噪` / `本地 DSP 降噪`）、当前任务或滚动双语字幕、12 柱实时音频波形、`mm:ss` 通话计时器、即时静音按钮与粉红警示「挂断」按钮。
   - 新增浏览器与 HarmonyOS NEXT 端侧轻量紧凑型通话浮条兜底，全端保持同一套通话状态与静音同步。
3. **16 kHz 流式通话降噪与声纹门控（`LiveCallProcessor`）**：
   - 支持 DPDFNet 流式降噪、VoxLock v2 目标人声分离、ERes2NetV2 声纹校验与未录声纹首讲人锁定（256 采样点余弦平滑衰减，避免切音爆音），无 ONNX Runtime 时自动以状态化纯 Rust DSP（80 Hz 高通 + 频谱门限 + 2.5 kHz 人声增强 + 软限幅）保障清晰度。

## 交互与体验优化

- **不打扰主工作区的通话入口**：点击状态栏右下角「快速说话」或触发全局唤醒快捷键时，直接进入小羊实时语音通话而不再强行切换当前工作区或强行展开右侧小羊抽屉；状态栏按钮实时同步为「小羊通话中 · 点此挂断」。
- **零残留挂断体验**：正常挂断或通话结束时立即以 `0 ms` 隐藏悬浮胶囊并清空状态，不再弹出多余的「挂断了」或「通话结束了」气泡提示。
- **输入框与设置页减负**：移除 Agent 对话框与小羊抽屉输入框内冗余的听写麦克风按钮；设置侧栏、键盘速览与首次引导统一调整为「语音唤醒与声纹」，并在设置内新增「立即唤起小羊 / 挂断通话」直接试呼按钮与实时状态同步。
- **文案与协议同步收敛**：同步清理桌面端导航、权限引导弹窗、声纹设置弹窗与系统麦克风权限描述中的旧版「语音输入」和「辅助功能粘贴」措辞，更新 `voiceInput.*` 协议配置说明标签（保留配置键名向后兼容）。

## 问题修复

- **修复本地语音模型下载 `SHA-256 校验未通过`**：
  - 修正桌面端 `voice_ai.rs` 中 `DPDF_SHA256` 缺失字符导致的校验必败问题（`8_791_035` 字节）。
  - 同步更新桌面端（`voice_ai.rs`）、Android（`VoiceModelManager.kt`）与 iOS（`VoiceEnroll.swift`）的 `3dspeaker_speech_eres2netv2_sv_zh-cn_16k-common.onnx` 文件大小（`71_441_527` 字节）与真实 SHA-256 摘要，并补齐打包模型摘要与长度的单元测试守护。
  - 优化 `SV_SPEC` 与中国区 GitHub 镜像排序，优先直连 `hf-mirror.com` / `huggingface.co`，并在下载阶段拦截 `text/html` 或 HTML 错误响应页，避免代理错误页写坏本地缓存。
- **修复多入口静音与麦克风生命周期同步**：统一桌面端原生 `LiveMicStream` 静音标志与悬浮胶囊 `muted` 状态即时联动，加入启动竞态防护防止快速取消时残留麦克风采集流，确保挂断或出错后系统麦克风权限指示立即关闭。
- **修复全局热键干扰其他应用**：移除通话期间对全局 `Escape` 按键的拦截，避免在终端或编辑器操作时意外劫持按键。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：建议桌面端（macOS / Windows）与移动端同步更新至 `v0.2.15`，即可在「设置 › 语音唤醒与声纹 › 只认我的声音」顺利完成语音模型下载与校验，并体验一键唤醒小羊实时语音通话与流式降噪；此前若在桌面端因校验失败残留过损坏的模型临时文件，升级后重新触发下载即可自动覆盖修复。
