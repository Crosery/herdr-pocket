# Herdr Pocket v0.2.39 更新说明

本次 **v0.2.39** 彻底解决 macOS 桌面端每次更新版本后需要重新授予**麦克风、辅助功能、输入监控与屏幕录制**等系统权限的问题，引入正式的 Apple `Developer ID Application` 代码签名、Apple 官方公证（Notarization & Stapling）与原子化 `ditto` 替换更新机制；同时彻底修复多分屏宽表格排版重排、切页唤醒或渲染器切换后终端视口被错误吸住顶部、底部 `>` 输入框消失的严重交互缺陷，并修复 Windows 环境下 `hostd` 浏览器测试桩启动兼容性问题。

## 更新亮点

- **macOS 正式 Developer ID 签名与 Apple 公证上线**：发布流水线已启用正式 Apple Developer ID 代码签名（开启 Hardened Runtime 与权威时间戳）及 `notarytool` + `stapler` 装订公证。macOS 系统隐私数据库（TCC）从此锚定到长期稳定的开发者证书要求（Designated Requirement），不再绑定到单次构建二进制的 `CDHash`。
- **更新应用免去重复授权弹窗**：从 **v0.2.39** 起在 macOS 上授予麦克风、辅助功能、输入监控或屏幕录制权限后，后续任意版本热更新或覆写安装都会自动继承既有系统授权，无需每次前往"系统设置 -> 隐私与安全性"重复勾选。
- **彻底修复终端视口意外置顶、底部 `>` 输入框消失问题**：重塑终端底部粘性滚动与视口重排策略，严格区分用户主动滚轮/滚动条上翻与窗口重排、隐藏标签重置或 WebGL 切换带来的被动事件，确保多分屏、窗口切换与窄列排版下始终稳稳停留在最新底部输入行。
- **应用内更新器采用原子 `ditto` 整包替换**：淘汰会剥离签名扩展属性与公证票据的 `rsync` 目录覆盖策略，改为同卷 `ditto` 暂存整包后原子切换，完整保留签名印章、公证装订票据及全部 Hardened Runtime 权限声明。

## 新增功能

- **macOS 本地回退签名自动识别与权限保真**：在自编译或无正式签名包场景下，`updater` 自动优先检索本机 Keychain 中有效的 `Developer ID Application` / `Apple Development` 身份（忽略未受信任的失效条目），使用系统 `/usr/bin/openssl` 生成规范代码签名证书，并在重签时强制保留 `entitlements.plist`（音频采集、JIT、第三方库加载）。
- **macOS Portal 截屏助手固定签名身份**：`hostd` 为 macOS 生成 `hp-mac-portal-v3` 辅助程序时，若本机存在有效签名身份则自动为其绑定固定 Bundle ID 与证书签名，防止助手重编后触发 TCC 重复判定。

## 交互与体验优化

- **完善中文更新引导与平滑升级过渡**：由于早期未公证版本（v0.2.38 及更早）此前使用临时 `ad-hoc` 签名（TCC 记录绑定于旧版 `CDHash`），升级至首个正式签名版 **v0.2.39** 时需最后一次确认系统权限；自本次授权完成后，后续升级 `v0.2.40+` 将保持免重新授权体验。

## 问题修复

- **修复终端视口卡在历史顶部、底部 `>` 输入提示符及状态栏消失的问题**：此前被动 `onScroll` 监听与底层平滑滚动逻辑会在分屏重排、隐藏层归零或渲染器切换时错误清除跟随底部状态并锁定滚动位置，导致切换分屏或标签后一直停在历史顶部、看不到底部 `>` 输入框。现改用仅响应显式用户滚轮/拖拽意图的 `reconcileTerminalBottomSticky` 状态协调，并在未就绪状态下直接同步底层缓冲区偏移，彻底根治误置顶。
- **修复 macOS 更新后麦克风、辅助功能与输入监控权限全部失效的问题**：根治 CI 默认 `ad-hoc` 签名、本地自签使用不兼容 OpenSSL 参数导致失败、本地重签丢失 `--entitlements`，以及 `rsync` 覆盖破坏签名封缄的四重叠加缺陷。
- **修复 Windows CI 中 `CdpBrowserPool` 多标签测试触发 `spawn EINVAL` 的问题**：Node 24 在 Windows 下直接 `spawn` `.cmd` 批处理桩脚本会因安全策略返回 `EINVAL`，改为直接通过 `process.execPath` 拉起跨平台 JS 桩脚本并在清理阶段容错重试文件句柄释放。

## 多端与升级说明

- **涵盖平台与 Harness**：本次更新覆盖 macOS（正式 Developer ID 签名与公证 `arm64`/`x64` `.dmg`）、Windows、Linux 桌面端（Tauri v2）、`hostd` 主机守护进程、Relay 服务端、H5 网页端与 HarmonyOS NEXT 端；全面兼容 OpenClaw、Claude Code、Codex、omp、OpenCode、Gemini CLI 与 Antigravity 会话。
- **H5 缓存升级**：H5 Service Worker 缓存版本已升级至 `herdr-pocket-shell-v6`，访问或刷新后将自动清理旧版离线壳层缓存。
- **升级建议**：建议 macOS 桌面端用户尽快升级到 **v0.2.39** 完成正式签名体系切换；服务端与其余主机同步升级至 **v0.2.39** 即可保持全链路版本一致。
