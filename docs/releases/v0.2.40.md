# Herdr Pocket v0.2.40 更新说明

本次 **v0.2.40** 彻底重构 macOS 系统权限与本机/跨端窗口回传体验：将 macOS「屏幕录制」捕获与快捷键/语音权限统一收口至经过 Apple Developer ID 正式签名与公证的 `Herdr Pocket.app` 本体执行，彻底告别升级或重启后反复掉权与被误判给终端/`node` 的问题；同时推出紧贴macOS「系统设置」并排停靠的**并排拖拽悬浮窗**、取消繁琐多步引导弹窗，并在受限的「本机浮窗」与窗口回传视图内提供一键直达授权与授权后自动恢复画面。

## 更新亮点

- **macOS 权限全收口至正式签名 `Herdr Pocket.app`**：桌面端新增轻量本地 Portal 桥接（`desktop-portal.sock`），由已正式签名并公证的 `Herdr Pocket.app` 直接孵化与执行屏幕/窗口画面捕获和输入指令，`hostd` 守护进程优先经由该桥接联动。macOS 隐私数据库（TCC）从此将「屏幕录制」「麦克风」「输入监控」统一归因并永久持久化到 `Herdr Pocket.app`，更新版本或重启应用均免重新授权，启动时仅做无弹窗预检。
- **并排拖拽悬浮窗取代繁琐引导**：点击「去授权」或开启系统权限时，自动在 macOS「系统设置 › 隐私与安全性」左右紧邻一侧打开轻量置顶拖拽助手（`perm-companion`），可直接开启列表开关或短距按住 `Herdr Pocket.app` 一拖即入；授权生效瞬间自动切绿并在约 0.9 秒内收起，取消居中多步教学弹窗与初始化权限打扰。
- **「本机浮窗 / 跨端窗口回传」屏幕录制缺权一键修复**：在「设置 › 隐私 › 系统权限」正式补全并统一管理「屏幕录制」「麦克风」「输入监控」三项核心权限；当 `本机浮窗`（如内嵌浏览器或桌面窗口）提示画面捕获受限时，卡片与窗口回传视图内直接提供**「去授权屏幕录制」**主按钮并自动监听权限变化即时恢复实时画面帧。

## 新增功能

- **macOS 屏幕录制状态感知与原生登记（`perms.rs` / `Info.plist`）**：接入 `CGPreflightScreenCaptureAccess`（静默状态查询）与 `CGRequestScreenCaptureAccess`（点击授权时登记到系统设置列表）、补充 `NSScreenCaptureUsageDescription` 与 `Privacy_ScreenCapture` 直达路由，并在应用内实时推送 `app://permissions` 状态变更事件。
- **桌面端本地 Portal 安全桥接（`portal_bridge.rs`）**：仅对 `check`、`list`、`capture`、`click`、`scroll`、`text`、`key` 白名单子命令开放同用户 `0600` 本地 Unix 套接字代理，并在 `hostd`（`OsCaptureDriver`）不可达时无缝回退既有本地执行路径。
- **系统设置并排停靠定位算法（`perm_companion.rs`）**：基于零权限弹窗的 `CGWindowListCopyWindowInfo` 实时识别系统设置窗口区域并紧贴其右侧（或左侧/安全边缘）不重叠停靠，支持原生 AppKit `NSDraggingSession` 跨窗拖入 `Herdr Pocket.app`。

## 交互与体验优化

- **全面精简权限界面与去除初始化弹窗打扰**：移除 `PermissionCards` 中多余的「引导与修复」按钮与三步模态引导弹窗；精简版新手向导（`OnboardingView` 中的语音设置面板）不再弹出系统权限提示列表；导入 Safari Cookie 需要「完全磁盘访问权限」时直接唤起系统设置与并排拖拽助手并监听恢复列表。
- **「本机浮窗」受限文案完整折行与高对比按钮**：解除受限报错文案单行截断限制，在窄屏或小浮窗下完整展示原因说明与「去授权屏幕录制」按钮；`perm-companion` 同步适配浅色/深色主题并在已授权状态下切换绿色就绪反馈。
- **延续并强化零闪屏切页与底部粘性终端**：保留高容量 WebGL 热池、Phase 0 同步挂载、64 标签保活与后台预热，以及隔离浏览器实例恢复策略，确保多分屏/大工作区切换零白屏闪动且底部 `>` 输入提示符始终可见。

## 问题修复

- **修复仅显示「麦克风」「输入监控」导致「屏幕录制」缺权无入口可配的问题**：此前设置页未列出「屏幕录制」权限且 `hostd` 后台以 `node` 子进程直接抓屏，导致「本机浮窗」弹出受限提示后难以一次修复；现已将「屏幕录制」纳入隐私设置统一管理并在 `Herdr Pocket.app` 签名链路下统一执行。
- **修复 `OsCaptureDriver` 短期缓存失败帧与 `SessionPortalPiP` Hook 顺序异常**：避免抓屏失败返回的空帧被短暂缓存 45ms 导致授权后首次重试命中空结果，并修复 `SessionPortalPiP` 在存在条件权限监听时的 React Hook 顺序问题。

## 多端与升级说明

- **涵盖平台与 Harness**：本次更新覆盖 macOS（正式 Developer ID 签名与 Apple 公证 `arm64`/`x64` `.dmg`）、Windows、Linux 桌面端（Tauri v2）、`hostd` 主机守护进程、Relay 服务端、H5 网页端与 HarmonyOS NEXT 端；全面兼容 OpenClaw、Claude Code、Codex、omp、OpenCode、Gemini CLI 与 Antigravity 会话。
- **H5 缓存升级**：H5 Service Worker 缓存版本已升级至 `herdr-pocket-shell-v7`，访问或刷新页面后自动清理旧版离线壳层缓存。
- **升级建议**：macOS 用户升级至 **v0.2.40** 后，如需在本机浮窗中截取其他桌面应用窗口画面，只需按浮窗或「设置 › 隐私」内的**「去授权」**开关一次即可；后续所有版本更新均自动保留全部系统权限。请同步更新 Relay 与各主机 `hostd` 至 **v0.2.40**。
