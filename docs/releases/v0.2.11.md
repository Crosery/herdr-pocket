# Herdr Pocket v0.2.11 更新公告

## 更新亮点

- **修复「需要你」状态下 ChatUI 输入无响应 / 延迟问题**：当终端被 Herdr 判定为 `blocked`（「需要你」，包括误判场景）时，桌面端与移动端 ChatUI 发送消息改为优先直连终端输入流即时投递（自动适配 `?2004h` bracketed paste 并附带 Enter），彻底跳过 `hc send` 对 `blocked` 的拦截以及最长 60 秒的草稿静默等待，响应速度与终端模式完全一致。
- **「更新 › 镜像源」下拉框原生展示 `ms` 延迟徽章**：采用 `PocketSelect` 内置等宽 `ms` 徽章同时呈现在收起选择器与展开下拉列表右侧（`3660 ms` / `时区推荐` / `最快` / `不通`），彻底告别多枚并排胶囊与文本截断。
- **设置全量文案精简重构**：大幅删减「通用 / 连接 / 语音输入 / 通知 / 更新 / 隐私 / 小羊助理 / 浏览器 / 性能 / 日志」中的冗长说明，并将语音输入中的并排推荐模型卡片收拢为单行下拉选择器，界面更清爽、重点更直观。
- **继承并发布 `v0.2.10` 全套新特性**：包含 `/btw` 不打断主线的旁路提问抽屉、`/skill` 与 `/command` 输入框内嵌胶囊、OMP 模型目录与实时思考等级自动检测、右下角唤醒小羊语音助理与 SOTA 语音预设、跨重启排队与工作区状态原子持久化、毫秒级本机终端 Kitty 图片渲染、`Shift+Enter` 换行区分与 Finder 文件夹零报错拖放。

## 新增功能

1. **Hostd 即时流式粘贴投递（`HcScreens.paste`）**：
   - 在与终端的 framed 输入流通道中跟踪 DEC `?2004h` / `?2004l` 状态，对多行文本自动使用 bracketed paste 包裹并紧跟 `\r` 送达；在不可直连或旧版通道下回退至 `hc send --force --`（兼容旧版 `hc` 参数）。
2. **`ms` 延迟徽章下拉选择器（`UpdatesPane` & `VoiceInputSetup`）**：
   - 「镜像源」选择器将延迟（`ms`）与可用状态拆分至右侧等宽徽章，视觉对齐更清晰。
   - 「推荐语音与识别模型」卡片改为单行 `PocketSelect` + `去配置` 快捷入口，消除设置页并排堆叠卡片。

## 交互与体验优化

- **「需要你」状态下 ChatUI 即时反馈与打断策略优化**：
  - 点击排队消息的「立即发送」时，仅当 Agent 确处于 `working`（运行中）状态才先发送中断信号，处于 `blocked` 状态时直接送入终端；聊天框占位符提示清晰标注「直接输入回复或指令（Enter 立即送入终端）」。
  - `chatQueue` 发送失败时立即弹出 Toast 报错提示，且刚发出的消息在 15 秒窗口内即时显示「等待响应」状态。
- **设置面板极简信息密度**：精简全部分类页副标题与 `about` 描述至一行关键信息，保留功能引导并降低阅读负担。

## 问题修复

- **修复 `HcAdapter` 自定义 `hcBin` 未透传到 `HcScreens` 的问题**：统一在构造函数中初始化 `HcScreens(hcBin)`，确保屏幕读写与流式粘贴通道始终绑定同一 `hc` 可执行路径。
- **修复「需要你」（含误判场景）ChatUI 无法及时将输入送入终端的故障**：跳过 `hc send` 的 `blocked` 拒绝与静默等待机制，并在回退路径补充 `--force`。
- **修复设置页与更新来源区域文本过长、并排徽章杂乱的问题**。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：请同时更新电脑端 **Herdr Pocket Hostd** 与桌面/移动客户端，以获得「需要你」状态下 ChatUI 秒级终端投递修复与精简版设置界面；若之前因 `0.2.9` 至 `0.2.10` 本地覆盖未及时完成仍停留在旧版界面，安装 `v0.2.11` 并重启后台服务即可生效。
