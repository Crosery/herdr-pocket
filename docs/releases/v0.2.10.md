# Herdr Pocket v0.2.10 更新公告

## 更新亮点

- **旁路提问 `/btw` 与内嵌斜杠胶囊**：聊天输入框支持原生 `/btw` 旁路快问，主 Agent 正在执行任务（`working`）时也能在只读上下文下独立响应，不排队、不打断、不污染主会话；输入 `/skill` 或 `/command` 后自动融合为带语义图标与功能色彩的胶囊标签（`ComposerSlashChip`），支持 Backspace 自然解包编辑。
- **OMP 模型目录完善与思考等级自动检测**：全面解析 OMP 模型配置（`models.yml` 与 `omp models --json`）及多厂商变体模型，打开或切换 Agent 会话时自动识别实时思考等级并直接点亮「思考 · 等级」按钮；本机直连新增原生模型发现，兼容旧版宿主机并彻底消除 `unknown method agent.models` 报错。
- **更新镜像源智能推荐与高频检查**：`设置 › 更新` 的「首选镜像源」升级为 `PocketSelect` 下拉选择，默认按系统时区推荐顺序并全量并发测速，自动锁定最低 `ms` 延迟可用源；自动检查频率默认提升至 `30 分钟`，并新增 `15 分钟` 高频档位。
- **排队消息与工作区状态跨重启保留**：通过原生的原子持久化文件（`workspace-state.json`）与多端存储，完整保存排队发送列表（`排队中`）、发送失败/待重试消息、输入框草稿与附件、已打开的标签页与空间切换状态，更新重启或退出重开后不丢失。
- **右下角状态栏一键唤醒小羊语音助理与 SOTA 模型预设**：点击右下角「唤醒小羊语音」直接唤起小羊实时语音对话面板，并在桌面端、中继与移动端同步扩充新一代旗舰实时语音、ASR 与对话模型预设。
- **原生级本机终端体验、毫秒级 Kitty 图片渲染与 Finder 文件夹拖放**：本机直连优先绑定 `hc` + `herdr` 原始 PTY，区分 Shell（`ESC + Enter`）与交互式 Agent TUI（`CSI 13;2u`）的 `Shift+Enter` 换行；本机终端 Kitty 图片通过 64 字节文件头轻量嗅探与零拷贝 `pocket-local://` 流实现毫秒级首帧渲染；支持从系统访达（Finder）直接拖入文件夹与多文件到聊天框或终端，不再抛出 `EISDIR` / 读取报错。

## 新增功能

1. **旁路提问抽屉与多端降级链路（`agent.btw`）**：
   - 新增只读 `agent.btw` RPC：服务端通过 Uniflo 读取近期会话上下文（无写入、不干扰主 CLI 进程），优先调用对应 Harness 的离线/轻量命令行完成旁路问答，在低配或旧版宿主机上可优雅降级至小羊文字助理或空闲会话原生 `/btw`。
   - 对话框上方新增可折叠 `BtwSideDrawer` 旁路问答面板，展示「主线运行中」标识、使用模型、耗时（`ms`）、Markdown 渲染、一键复制以及文内文件路径直达跳转。
2. **输入框斜杠指令融合胶囊（`ComposerSlashChip`）**：
   - 自动识别前导 `/btw`、`/skill`（如 `/skills:*`）与 `/command`（如 `/dev`、`/commit`、`/review`），将功能图标与分类角标优雅融入对话框左侧，彻底告别生硬的悬浮或独立图标框。
3. **跨重启全量工作区持久化（`workspace_state` / AsyncStorage / localStorage）**：
   - 桌面端由 Rust 原生原子写入 `workspace-state.json`，结合网页端 `localStorage` 与移动端 `AsyncStorage` 协同持久化和启动恢复排队消息、`outbox` 待发/失败消息、草稿附件及标签/空间视图。
4. **SOTA 语音与对话模型预设矩阵**：
   - 桌面端与中继服务对齐并扩展主流前沿模型预设（覆盖 OpenAI Realtime / GPT-5 系列、Gemini Live、Qwen Omni / DashScope、Doubao Realtime、StepFun、MiniMax、Zhipu GLM 以及本地 Apple Silicon MLX 等推荐配置）。

## 交互与体验优化

- **真本机终端沉浸交互**：
  - 本机普通 Shell 会话默认以终端模式打开，与 Agent 会话并排切换更自然；补齐 `KIND_FOCUS`（终端焦点事件同步）与 `KIND_AUTOMATIC_INPUT`（区分手动键入与编程自动注入），适配交互式 TUI 与 tmux 快捷键习惯。
  - 修复多种 TUI（Claude Code / OMP / Codex / Gemini 等）与标准 Shell 下 `Shift+Enter` 无法换行的问题：Shell 下发送 `ESC + CR`，开启 Kitty 键盘协议的 Agent TUI 自动发送 `CSI 13;2u`。
- **更新镜像测速卡片与频率选择器**：
  - 「下载线路」与「首选镜像源」均为零原生控件的粉红主题 `PocketSelect`，列表实时显示各镜像站毫秒延迟、`时区推荐` 与 `最快` 角标，支持随时一键「重新测速」。
- **Finder 外部文件夹/文件拖放与附件卡片**：
  - 桌面端按需读取系统拖拽粘贴板真实路径，直接将文件夹作为折叠角标卡片或按媒体流式预览卡片（零拷贝 `pocket-local://`）添加到待发栏；远程/浏览器模式下自动遍历 `webkitGetAsEntry` 可读文件并安全跳过空目录或受限目录。

## 问题修复

- **修复 OMP 思考等级按钮进入会话时不自动显示的问题**：挂载或切换会话时立即从本地日志事件（`thinking_level_change`、`model_change`）、Harness 配置与模型 ID 推断并缓存思考等级，无需再手动发送一次 `/model` 后才激活。
- **修复连接旧版宿主或离线状态切换模型偶发 `unknown method agent.models` 的问题**：新增桌面端原生 `local_agent_models` 与前端模型目录合成回退，确保不同版本 Hostd 均可正常打开模型与思考等级菜单。
- **修复应用升级重启后正在排队中的提示词消失的问题**：持久化 `chatQueue` 排队列表，重启重连后自动恢复展示与续发队列，并在 `working` 状态下对 `/btw` 绕过排队直接旁路发送。
- **修复部分环境下测速提前中断导致未能选中真实最低延迟镜像源的问题**：并行探测所有可用镜像源后统一比较真实延迟，在接近阈值内优先同区节点。
- **修复直接拖拽本地文件夹到聊天框或终端时报错失败的问题**：同步捕获 `DataTransfer` 快照，避开直接读取目录流引发的权限与类型错误。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：
  - 若从 `v0.2.9` 或更早版本升级：建议同时更新电脑端 **Herdr Pocket Hostd**，以启用只读 `/btw` 离线旁路能力与完整 OMP 模型/思考等级发现（旧版 Hostd 仍可通过前端自动合成与小羊助理降级兼容）。
  - macOS 用户可在「设置 › 更新」中选择推荐镜像源实现一键更新，或在 GitHub Release 下载已公证安装包覆盖 `/Applications/Herdr Pocket.app`。
