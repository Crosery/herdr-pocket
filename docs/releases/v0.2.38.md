# Herdr Pocket v0.2.38 更新说明

本次 **v0.2.38** 重点解决运行中终端标签页切入白屏闪烁、远端浏览器/窗口 Portal 黑屏卡在建立画面流、以及长按 `Command` 键快捷键提示缺失的问题，并完善 macOS / Linux / Windows 跨平台窗口回传与本机浮窗体验。

## 更新亮点

- **多人/多分屏终端列宽强一致锁定**：消除多分屏未获焦点窗格或跨窗口附着期间 `xterm.js` 与底层 PTY 列宽差 1–2 列引起的软折行与 Spinner / 提示区逐行重复堆叠错位，确保 `Antigravity` / `Claude Code` / `Codex` 行内重绘与实时输出始终对齐。
- **运行中终端标签切入零白屏首帧直出**：激活已挂载或后台流式输出中的终端标签时，在首帧绘制前同步唤醒暂停的终端渲染器、刷新并发几何调整并直接绘制可见行；从回退 DOM 渲染升格到 WebGL2 后立即同步重绘缓冲，消除中间 1 帧白屏闪烁。
- **冷启动与持续输出首屏提速至毫秒级**：将初始突发聚合上限压缩至 `80 ms` 且不再被高速 Spinner/Token 输出无限延后，同时避免远端流模式切换时重新隐藏画布，进入运行中 Agent 标签即刻可见实时进度。
- **多标签共享 headless CDP 浏览器并发架构**：修复多浏览器页面复用同一用户目录触发 `SingletonLock` 冲突的问题，改为单进程多 `Target`（`Target.createTarget` / `Target.closeTarget`）隔离复用，并在建连与加载完成时主动推送首帧画面。
- **恢复按住 `Command` 键空间快捷键提示并移除 macOS 灵动岛**：默认开启按住修饰键浮窗与 `cmux` 风格空间角标，借助底层 HID 状态精准同步 OS 修饰键；正式下线独立的 macOS 灵动岛悬浮窗，统一保留应用内轻量胶囊浮窗 `PocketDroplet`。

## 新增功能

- **跨平台窗口与 X-Server 画面回传驱动**：
  - **macOS**：支持 macOS 15 `ScreenCaptureKit` 原生窗口枚举与捕获，新增 10 秒权限状态缓存与短超时降级机制。
  - **Linux / X11 / Wayland / WSLg**：支持 `wmctrl` / `xdotool` / `kdotool` / `xwininfo` 枚举，支持本地及 TCP `DISPLAY` X-Server 捕获并补充 `xwd -> convert -> ffmpeg` 自动回退链，自动探测 WSLg / WSL2 桌面环境。
  - **Windows**：支持 Win32 `PrintWindow` 配合黑帧/X-Server `CopyFromScreen` 回退、高 DPI 感知、隐身（`DWMWA_CLOAKED`）窗口过滤，以及 WSLg、VcXsrv、X410 桌面识别。
- **同设备会话小浮窗（`SessionPortalPiP`）**：在本机终端内执行拉起浏览器或 GUI 窗口的命令时，自动检测并快速回传可控小浮窗到当前会话右上角，支持实时画面预览与一键放大。
- **Portal 流错误透传与一键重试**：新增协议字段 `PortalItem.streamError` 与前端"重试捕获"动作；当远端回环地址（`127.0.0.1` / `localhost`）无法在本机直接打开时，自动隐藏误导性的本地打开按钮并保留完整内嵌画面流与引导提示。
- **首帧显现耗时可观测告警**：新增 `term.reveal.slow` 遥测事件（超过 `220 ms` 记录精简脱敏告警），配合全量日志链路持续追踪切窗显现延迟。

## 交互与体验优化

- **跨视口分屏同步尺寸即时生效**：在多端或不同尺寸窗口间切换已挂载且持有焦点的分屏窗格时，在首次绘制前完成尺寸重算与 PTY 同步，避免首帧旧尺寸错位后再触发 `SIGWINCH` 二次清屏重绘。
- **`Command` 键提示状态自愈**：修复旧版配置迁移时修饰键提示默认关闭的问题，并在失去焦点时通过 `CGEventSourceFlagsState` 等系统级 HID 状态校验消除粘滞假按下或提示不出现的情况。
- **统一桌面提醒视觉样式**：移除独立灵动岛窗口及相关配置开关后，所有桌面待命与完成提醒集中于主界面内圆润胶囊浮窗展示，保持无 emoji 粉色视觉规范并减少额外窗口焦点干扰。

## 问题修复

- **修复多分屏窗格与跨窗口并发附着导致的终端折行堆叠与内容重复错位**：修正非键盘焦点分屏窗格无法回收尺寸、`local-term://size` 在部分激活态下被丢弃、预缓冲快照用错目标列宽解析，以及本地附着尚在握手期间提前触发远端 Relay `terminal.resize` 与 `HcScreens.watchRaw` 上报旧维度的问题，从根源消除 Spinner/状态行重复堆叠与末字符折行截断。
- **修复切入运行中标签页白屏并闪烁再渲染的问题**：消除隐藏标签 `_renderService._isPaused` 延迟到绘制后解除、初始 `data-ready="false"` 被持续输出拖延至 `650 ms`、Relay fallback 转原始流二次隐身，以及 WebGL2 升格瞬间空帧导致的白屏闪烁。
- **修复多浏览器 Portal 卡在"正在建立画面流..."黑屏问题**：解决并发打开多个网页 Portal 时的 Chromium `SingletonLock` 竞争崩溃、扩充多平台浏览器二进制路径发现，并在无首帧时显式展示错误信息而非无限转圈。
- **修复 Homebrew 等环境下 `convert` 缺少 XWD 委托导致 X11 截屏返回空字节的问题**：`convert` 非零退出时自动切换 `ffmpeg` 管线解码并输出标准 JPEG。
- **修复权限拒绝后窗口探测反复阻塞重试的问题**：macOS 录屏权限未授予时短路无效探测并记录清晰原因，避免拖慢正常会话响应。

## 多端与升级说明

- **涵盖平台与 Harness**：本次更新覆盖 macOS / Windows / Linux 桌面客户端（Tauri v2）、`hostd` 主机守护进程、Relay 服务端、H5 网页端与 HarmonyOS NEXT 端；完全兼容 OpenClaw、Claude Code、Codex、omp、OpenCode、Gemini CLI 与 Antigravity 会话。
- **H5 缓存升级**：H5 Service Worker 缓存版本已升级至 `herdr-pocket-shell-v5`，访问或刷新后将自动清理旧版离线壳层缓存。
- **升级建议**：建议 Relay、各台桌面主机（`hostd`）及桌面客户端同步升级至 **v0.2.38**，以同时获得零白屏切窗体验与跨平台 Portal 画面流修复。
