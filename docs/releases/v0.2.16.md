# Herdr Pocket v0.2.16 更新公告

## 更新亮点

- **小羊语音通话全面防回声与动态形象升级**：桌面端打通 WebRTC 系统级回声消除（`webrtc-aec`）与扬声器 260 ms 尾音防护，消除自问自答回声循环，大幅降低 UI 与悬浮胶囊刷新卡顿；语音悬浮胶囊（`voice-hud`）与状态栏同步换装全状态小羊动态 WebP 形象。
- **全 Harness 通用只读旁路提问 `/btw`**：`claude`、`codex`、`omp`（Bun SDK）、`pi` 均支持原生只读不落盘会话分叉，同时为 `Antigravity`、`Gemini`、`OpenCode`、`Hermes`、`Aider` 等及历史/远端会话提供高达 60,000 字符的通用会话转录只读旁路兜底，彻底告别 `/btw` 排队卡死或超时。
- **本机终端视觉体验对齐 `Herdr.app`**：自动读取本机 `Herdr.app`（`config-gpui.local.toml` / `config-gpui.toml`）字体家族、字号与行高配置；浅色模式提供纯净 `#ffffff` 画布与高对比度调色板（4.5:1 自动对比度保护），并按主屏/备用屏作用域隔离 Kitty 图像擦除指令。
- **iPhone 16 Pro / iOS 26 及全分辨率移动端适配**：以自定义 `PocketStackHeader` 替代系统导航栏胶囊容器，解决 iOS 26 液态玻璃左上角双层胶囊返回键；重构聊天输入框底部工具栏为自适应弹性布局，彻底修复窄屏右侧「停止 / 发送」按钮裁切溢出及键盘弹起后的底部安全区多余留白。

## 新增功能

1. **小羊全状态动态形象与高精度声学回声控制**：
   - 新增接通中（`connecting.webp`）、思考中（`thinking.webp`）、静音中（`muted.webp`）等 6 态动态小羊 WebP 形象，桌面悬浮胶囊放大至 `548×88` 并配 `44×44` 圆形动态小羊徽章，状态切换稳态防抖，工作台右下角状态按钮同步升级为 `18×18` 动态小羊图标。
   - 新增 Tauri 主窗口麦克风权限自动放行与 Rust 原生 `voice_call_dsp_open / process / close` 通道，协同 65 ms WebAudio 尾帧等待（`createPlayoutTracker`）与 260 ms 扬声器尾音门控（`createEchoGate`），只在 `-18 dBFS` 以上连续 3 帧人声才触发真实打断。
2. **全 Harness 通用 `/btw` 只读旁路问答引擎**：
   - `apps/hostd` 与桌面端本地直连命令 `local_agent_btw` 均采用 `stdin` 隔离投递与随机围栏防注入提示词，支持 `claude`（`--fork-session --no-session-persistence --tools ""`）、`codex`、`omp`（`@oh-my-pi/pi-coding-agent` SDK）及 `pi` 原生无副作用分叉；当原生命令不可用或属于其他 Harness 时，自动采集 Uniflo / JSONL 转录（含 `Antigravity` `.system_generated/logs/transcript.jsonl`）/ `hc read` 终端尾部按优先级多引擎流式兜底回答，并在超时或取消时递归清理整个进程树。
   - 移动端同步支持输入框 `/btw` 指令拦截、`agent.btw` 优先直连及主题化可折叠/可复制旁路结果卡片。
3. **本机文件「在 Finder 中打开所在目录」**：
   - 在桌面端工作台、文件详情页及链接操作栏支持一键调用操作系统原生文件管理器高亮定位本地文件（macOS 为 `在 Finder 中打开所在目录`），并补齐 `.ipa`、`.dmg`、`.apk`、`.hap` 等安装包与归档文件的原生打开能力（`local_open_file` / `local_reveal_in_folder`）。
4. **Uniflo 与终端双路精准识别模型与思考等级**：
   - Uniflo 会话适配器、`local_models` 与协议层共享解析器协同读取 JSONL 会话尾部（含 `Antigravity` 与非思考模型识别），当旧版节点未上报模型或思考等级时自动从 `terminal.read` 状态栏补全。

## 交互与体验优化

- **侧边栏更清爽**：移除无用且无法删除的空白「未分空间」占位分组，移除 Agent 列表行悬浮显示、占位的眼睛预览按钮（`<Eye />`）。
- **本机终端细节打磨**：浅色模式下终端默认字号提升至 `14px` / 行高 `132%`、`customGlyphs` 与重叠字形自适应缩放生效，动态同步终端主题前景色并在窗口尺寸与外观切换时即时重绘；桌面端及 HarmonyOS 窄屏输入栏同步增加模型按钮弹性收缩保护。
- **移动端多分辨率（`320pt`–`430pt`+ / 横竖屏灵动岛）一致体验**：
  - `Agent` 详情页顶部状态行、`Agents` 首页三态统计卡片、`小羊助理` 操作卡、通话控制栏、`设置` 行内子控件、工作簿标签页（`PocketSegmented`）及 `/btw` 卡片标签均加入 `minWidth: 0`、窄屏字号/间距档位与灵动岛水平安全区适配。
  - 消除弹窗与底栏中的系统原生 `Alert.alert`，统一由 Pocket 轻提示承载。

## 问题修复

- **修复语音唤醒自回声循环与高 CPU 卡顿**：通过桌面 `AssistantView` 精细状态订阅选择器、音频资产与 HUD 角标内存缓存，以及 `80–85 ms` 电平与胶囊节流，消除原本 `80–100 Hz` React 全组件重渲染导致的语音卡顿与漏字；修复语音与音频播放完成事件过早释放导致的自我唤醒循环。
- **修复浅色/深色模式下终端底部黑边与 `/btw` 胶囊裁剪**：覆盖 `.xterm-viewport` 默认 `#000` 背景色，使其与当前主题画布色严格一致；修复移动端及窄屏模式下 `/btw` 抽屉头部模型名胶囊缺少省略号与耗时标签被挤压贴边的问题。
- **修复 iOS 26 顶部返回键双层胶囊与聊天框右侧按钮溢出**：使用自定义 `PocketStackHeader` 避免系统 `UINavigationBar` 液态玻璃包裹圆形返回图标产生双重胶囊；移除输入框工具栏多余撑开占位并收窄弹窗最大高度，确保任何屏幕尺寸下「停止 / 排队 / 发送」按钮始终完整落在输入卡片内，且键盘弹起后自动收起底部多余安全区空白。
- **修复 Kitty 图片误删正常屏内容**：`a=d` 擦除指令现严格限定在当前激活缓冲屏（主屏或备用屏），从 `yazi` 等全屏 TUI 退出备用屏时不再误删正常终端滚动历史中的 `fastfetch` 等图片。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：建议本机 Hostd、桌面端与移动端同步升级至 `v0.2.16`：本机通过桌面客户端或 `launchctl` 重启 Hostd 后即可立即生效新版 `/btw` 全 Harness 旁路发动机与模型/思考等级识别；iPhone 16 Pro 用户安装 `v0.2.16` `.ipa` 后即可体验修复后的单层返回导航与全分辨率自适应聊天输入框。
