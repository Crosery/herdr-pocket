# Herdr Pocket v0.2.26 更新说明

Herdr Pocket `v0.2.26` 重点修复 macOS 灵动岛主线程崩溃问题，新增全功能自适应 H5 网页端（含设备识别与防身份漂移认证体系），并以 Ghostty 级性能标准重构分屏拖拽、窗口缩放、中文输入法标点提交与终端图像/图文队列对齐，同时完善全端脱敏性能遥测上报与无桌面伴生程序时的 `hc` 无头兼容链路。

## 更新亮点

- 修复 macOS 灵动岛主线程空指针崩溃（`EXC_BAD_ACCESS`）：彻底解决 `notch::macos::configure_window` 在部分 macOS 窗口/屏幕切换时因 KVC/ObjC 状态异常导致的客户端反复闪退，并增强启动时上一次原生 `.ips` 崩溃摘要脱敏收集与上报能力。
- 全新自适应 H5 网页端（`/app/` 与 `/h5/`）：直接通过中转服务器打开响应式网页端（完整兼容如 `https://pocket.example.com/pocket/app/` 等反向代理子路径），扫码落地页新增「直接打开网页版 (H5)」入口。自动识别 iPhone / iPadOS（含桌面 UA 平板）/ Android（含微信、飞书内置浏览器）/ HarmonyOS / macOS / Windows / Linux 设备形态并适配手机触控或桌面多窗格视图，同时支持在「设置」中手动固定界面形态。
- H5 浏览器防身份漂移与零重复设备锁：内置不可导出的 WebCrypto `ECDSA P-256` 本机密钥对、`HttpOnly` HMAC `hp_anchor` 锚点 Cookie、WebAuthn 硬件通行密钥（Face ID / Touch ID / 指纹）与多存储保险箱，即使清理页面缓存或重新扫码也能精准沿用原有设备 ID，不再在设备列表中反复产生冗余节点。
- Ghostty 级分屏与窗口高帧率丝滑引擎：恢复桌面端窗口四边鼠标自由缩放；分屏分割线（`.v3-split-sash`）与侧栏宽度拖动手柄改为零 React 重渲染的直写 DOM 通道并合帧同步 `ResizeObserver`，分屏状态与非激活分屏均支持平滑尺寸响应、右下角 `cols × rows` 规格浮标提示、受控 WebGL 渲染池（`MAX_ACTIVE_WEBGL = 6`）与 DEC `?2026` 同步输出帧缓冲，同时支持跨设备浮窗自由拖动与八向缩放。
- 修复内置终端中文输入法与中文标点丢失（`。，？` 等）：针对 macOS `WKWebView` + `@xterm/xterm` 中独立中文标点与 `SCIM` XPC 异步提交被丢弃的问题，引入输入法事件保护与零重复协调桥接（`terminalIme`），在保护活跃拼音预编辑免被快捷键或 Kitty `CSI u` 误截获的同时，完整送达 `。，？、：；“”（）【】——……` 并高亮显示预编辑悬浮层。

## 新增功能

- H5 网页客户端交付与认证体系（`packages/protocol`、`apps/relay`、`apps/desktop`）：
  - 中转服务内置并托管静态 H5 产物（`/app/`、`/h5/` 含 SPA 回退与严格 CSP/Referrer 策略），支持 `?pair=` 扫码直登并自动清理地址栏参数、支持 `?approve=` 授权确认弹窗。
  - 新增 `/v1/identity/hint`、`/v1/identity/challenge`、`/v1/identity/reconfirm` 及 `/v1/identity/passkey/{options,register}` 接口，实现挑战签名免重登、通行密钥绑定与配对防重放去重。
  - 网页登录面板新增已识别设备徽章、一键身份/通行密钥恢复卡片以及反向扫码申请加入（`/v1/join` + 实时轮询）能力。
  - 「设置 › 外观 / 通用」新增「网页端界面形态」（自动跟随设备 / 固定手机触控界面 / 固定桌面多窗格界面），「连接 / 电脑与中继」新增「本机唯一身份锁」与硬件通行密钥绑定入口。
- 递进式组合键实时角标引导：按住 `⌘`（Windows/Linux 为 `Ctrl`）时展示全部包含 `⌘` 的快捷操作（涵盖 `⌘+…` 与 `⌘⇧+…`）；继续按住 `⇧` 升级为 `⌘⇧` 后，仅需 `⌘` 的基础角标自动隐去，页面并排收窄展示 `⌘⇧+…` 目标并自动剥离已按住的修饰键前缀，松开 `⇧` 平滑退回。
- 双端全量系统与帧率遥测上报（桌面端 JS/Rust、H5、移动端、电脑守护进程 `hostd`）：自动采样桌面/网页/移动端帧率（FPS 与帧耗时分位数）、分屏切换帧率、RPC 延迟分布、硬件与操作系统画像、进程资源心跳及桌面端历史崩溃摘要，所有敏感字段与路径均经严格脱敏后统一上报至中转服务器日志流。

## 交互与体验优化

- 终端图文与对话图文队列对齐：
  - 优化窄分屏下 Kitty 图形协议（如 `fastfetch` / `nf` 图标与配图）缩放与布局对齐，与本地客户端视觉表现保持一致。
  - 桌面端对话界面中，「终端排队中」队列条目与刚发出的乐观发送气泡同步渲染 `<InlineImageStrip>` 图片缩略图及图片计数标记，消除了图片发送瞬间的视觉断层。
- 跨设备 P2P 浮窗交互增强：`SessionPortalPiP` 浮窗支持视口内自由拖动与八方向边框/角落实时缩放（`220×150` 至 `880×680`）。
- 无桌面伴生程序降级平滑化：当远端电脑仅运行 `hc` 终端命令行而桌面端 `Herdr.app` 未开启时，`hostd` 自动从 `hc` 会话与标签推导空间与项目目录，避免因误判「桌面 herdr 没有打开」而阻断终端与工作区操作。

## 问题修复

- 修复 macOS `WKWebView` 全屏/安全区外拖区域覆盖窗口边缘导致四边无法直接鼠标拖动调整窗口大小的问题。
- 修复 `SessionPortalPiP` 跨端浮窗偶发不可拖动缩放以及侧栏分割线拖拽卡顿的问题。
- 修复中转服务与 `hostd` 在长日志上报与严格类型收敛中的边界截断及类型隐患，确保日志上下文完整且不含私钥/令牌信息。
- 修复 `uiGuardrails` 与端到端渲染分层核验中的测试覆盖，保证全端浅色与暗色主题统一遵循 Pocket 视觉组件规范且无原生 OS 控件及 Emoji 混入。

## 多端与升级说明

- 本次发布同步交付中转服务 `relay`（内嵌最新版 H5 网页端 `/app/`）、电脑守护进程 `hostd`、桌面端（macOS `arm64`/`x64` 已签名公证 `.dmg`、Windows 安装包、Linux `.AppImage`/`.deb`）、移动端与 HarmonyOS 产物。
- 中转服务升级至 `v0.2.26` 后，浏览器直接访问中转地址下的 `/app/`（例如 `https://pocket.example.com/pocket/app/`）即可免安装使用 H5 网页端；电脑端运行 `herdr-pocket update` 或在客户端「设置 › 更新」即可升级至 `v0.2.26`。
