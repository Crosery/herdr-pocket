# Herdr Pocket v0.2.54 更新说明

本次 **v0.2.54** 带来**每会话监听端口发现与预览、固定紧凑小浮窗与实例级自适应收纳标签页、聚焦当天的会话及子 Agent 花费/步骤/Token 看板、Ego 风格浏览空间联动、`herdr` ↔ `herdr-core` 无感双向空间同步、游戏式首次进入互动教程、子 Agent 卡片化重设计、远程预览弹窗重构与黑屏链路修复，以及多语言代码语法高亮**。

## 更新亮点

- **游戏式首次进入互动沙盒教程（服务端持久记录）**：首次进入应用时自动进入完全隔离的模拟练习工作台，通过 SVG 聚光灯高亮与 5 步零术语引导快速上手状态识别、一键拍板、实时成果浮窗、对话/终端翻面与小羊全局汇总；通关后自动跳回真实工作台，完成状态（`0 / 1 / 2`）由中转服务端 SQLite 持久化并跨端单调同步，随时可在「设置 → 重温互动教程」再次体验。
- **每会话监听端口自动发现与快捷预览**：`hostd` 按终端进程树精准归因 TCP `LISTEN` 监听端口并探测 HTTP 页面标题，在窗格标题栏展示绿色动态服务胶囊（如 `:5173 +1`），支持一键在内置浏览器、右侧分屏或远端 P2P 小窗预览、复制地址及安全停止对应子进程。
- **实例级自适应小浮窗与统一时间序收纳标签页**：浮窗严格跟随所属终端/Agent 实例，折叠态锁定紧凑固定宽度（`<= 256px`）并压缩长 OAuth URL 为 `host · 登录授权`；当窗格空间不足或浮窗堆积时，自动收敛为超紧凑胶囊并支持一键收纳到按时间排序的统一预览标签页（`PortalTab`），彻底告别画面遮挡。
- **聚焦「当前会话当天 + 子 Agent 汇总」用量面板**：桌面端与移动端移除冗余的 24h / 7d 全机汇总，聚焦 4 格核心 KPI：今日花费（含子 Agent）、会话累计（含子 Agent）、轮次与步骤、Token 消耗（入·出·缓存），由 `hostd` 递归汇总后代子 Agent 真实账单与当日步数。
- **远程预览弹窗彻底重构与代码预览多语言语法高亮**：合并远程预览弹窗为单行顶栏与单行地址栏、默认收起快捷抽屉、画面区占比提升至 86% 以上并根治 7 处首帧/流订阅/解码黑屏问题；文件预览、Markdown 代码块与 Git Diff 全面新增浅/暗双主题语法高亮。

## 新增功能

- **协议与后端能力（`packages/protocol` / `apps/hostd` / `apps/relay`）**：
  - 新增 `AgentListeningPort`、`Agent.listeningPorts` 及 `"agent.ports"` RPC，跨 macOS (`lsof`) / Linux (`ss`/`lsof`) / Windows (`netstat`) 归因终端进程树内监听服务并校验归属后安全停止。
  - 新增 `UsageTokenBreakdown` 及当日/子 Agent 递归聚合字段（`todayCostUsd`、`todaySteps`、`todayTokens`、`subagentCount`、`subagentCostUsd`、`subagentSteps`、`subagentTokens` 等），支持跨天子 Agent 按步骤时间戳精准拆算今日开销。
  - 新增 `herdr` TUI ↔ `herdr-core` 无感双向空间桥接与 `"spaces.sync"` RPC（自动解析真实工作区名并去重合并，支持一键双向同步及将 `herdr` 会话续跑迁移至 `herdr-core`），在「设置 → 电脑与中继」提供操作入口。
  - 新增 `"portal.egoSpaces"` RPC 与主动发现能力，实时同步 Ego 任务空间并一键唤起小浮窗。
  - 中转服务端新增 `GET / PUT / POST /v1/tutorial` 与 `tutorial_state` 广播帧，在 `welcome` / 配对响应中下发服务端教程状态并单调合并，清除客户端缓存亦不会重复弹窗。
- **桌面端与鸿蒙端新组件（`apps/desktop` / `apps/harmony`）**：
  - 新增 `TutorialSandboxStage` 交互式沙盒教程、`AgentPortsPopover` 服务端口浮层、`PortalTabPane` 统一时间序预览标签页，以及零依赖多语言状态机代码高亮器 `syntaxHighlight`（支持 TS/JS/JSX/TSX/Python/Rust/Go/C/C++/Java/Kotlin/Swift/JSON/HTML/CSS/Shell/YAML/TOML/SQL/Markdown）。

## 交互与体验优化

- **子 Agent 列表卡片化重设计**：将 `research` / `explore` / `review` 等泛化标识转为语义角色色标（调研/探索/审核/编码/测试等），优先提取真实任务摘要作为主标题，新增状态筛选胶囊（全部 / 进行中 / 已完成）、关键词检索与模型品牌图标。
- **Ego 风格浏览空间面板**：`BrowserPanel` 重构为空间胶囊切换栏与实时 Ego 任务空间条，一键拉起小浮窗，并移除重复的「放入标签栏」文字按钮。
- **窄分屏输入栏与标题栏全面容器查询化**：采用 `@container composer`、`@container panehead` 与 `@container usagecard` 多档渐进降级，超窄分屏自动隐藏次要按钮至「更多」菜单，保证关闭 `×` 与底部发送栏在窄列（如 `198px`）下零重叠、零裁切；同步移除窗格标题栏在线状态冗余文案。
- **PWA 缓存升级**：Web H5 Service Worker 缓存版本更新至 `herdr-pocket-shell-v13`。

## 问题修复

- **彻底根治跨工具 Ask 确认卡片卡死与误注数字入队的 P0 缺陷（桌面端 / 移动端 / 协议层）**：
  - 修复 `findOpenQuestionToolCall` 顺序扫描遗漏 `tool_result` 的缺陷：当 `ask_question` / `AskUserQuestion` / `request_user_input` / `ask` 已返回结果，或模型已继续进入 `reasoning` / 回复 / 后续工具调用、状态不再为 `blocked` 时，确认卡片立刻消失，杜绝僵尸卡片滞留并把 `"1"` 误输入到排队消息盒的问题。
  - 修复多题提问（如 `问题 1 / 3 -> 2 / 3 -> 3 / 3 -> 提交`）点击后不重读终端屏幕的缺陷：桌面端与移动端均新增 `blocked` 态高频轮询与点击后即时双拍刷新（`180ms` / `560ms`），移动端 `refreshSoon` 同步失效 `terminal.tail` 缓存。
  - 统一升级 `parseTerminalChoices` 与 `buildChoiceSelectKeys` 跨工具适配 **Antigravity、Claude Code、Codex、Oh My Pi (`ask`)、Gemini CLI、OpenCode、DSH** 与普通终端：同时识别编号菜单、无编号单选圆点/多选复选框与 `? ` 光标菜单，统一以相对 `↑`/`↓` 逐键间隔 `55ms` + `Enter`（多选用 `Space` + 显式「提交所选」）交互，避免连发吞键、连击跳过下一题或向输入框漏打数字；卡片同步补齐「上一题 / 下一题 / 取消 (Esc) / 暂时收起」兜底按钮。
- **修复远程预览弹窗长 URL 顶飞关闭按钮与 7 处黑屏隐患**：为 `PocketModal` 标题区添加 `min-width: 0` 溢出保护；修复 `updateScreencastConfig` 重启丢帧、主控级监听未转发首帧、0 帧心跳阻断轮询兜底、`portalStore.use` 过期选择器、`createImageBitmap` 异常回退、macOS 本地采集兜底及误报屏幕录制权限提示。
- **修复已完成子 Agent 误显 `0秒`**：当缺少显式 `startedAt` 且 `statusSince === updatedAt` 时改为展示诚实的相对完成时间，不再伪造 `0秒`。
- **修复多视口实测发现的 6 项运行时与布局缺陷**：
  - 修复 `SessionPortalPiP` 条件 Hook 顺序导致首个浮窗到达时触发 `Rendered more hooks than during the previous render`。
  - 修复窗口非焦点态下全局省电规则将 `.tut-overlay` 透明入场动画冻结在 `opacity: 0` 的问题。
  - 修复多浮窗叠加 Ego 徽章时折叠胶囊标题被挤占、端口/子 Agent 浮层层级高于弹窗且切标签未自动收起，以及窄窗 `.composer-model-btn` 层叠顺序导致思考等级按钮轻微溢出的问题。
- **修复移动端用量卡片令牌对齐（`apps/mobile`）**：同步切换为 4 格聚焦会话/子 Agent 看板并对齐 `accentContainer` 视觉令牌。

## 多端与升级说明

- **支持平台**：中转服务端与电脑端 `hostd`（`herdr-pocket update`）、桌面端（macOS `arm64`/`x64`、Windows `x64`、Linux `x64`）、Android（`.apk`）、iOS（`.ipa`）、HarmonyOS NEXT（`.hap`）以及网页 H5（`/app/`）与管理后台（`/admin`）。
- **升级建议**：建议中转服务端、各电脑 `hostd` 与桌面/移动端客户端一并升级至 **v0.2.54**，以完整启用服务端教程状态同步、每会话监听端口发现、子 Agent 与当日开销精准汇总及 `herdr` ↔ `herdr-core` 无感双向空间同步。
