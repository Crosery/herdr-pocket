# Herdr Pocket v0.2.18 更新公告

## 更新亮点

- **全新自研非遮挡视频 / 音频播放器（`PocketVideoPlayer` / `PocketAudioPlayer`）**：普通窗口下控制栏固定停靠于画面下方，不再覆盖视频底部画面与字幕，全屏自动切换为无操作隐身悬浮玻璃条；支持 60/120fps `requestVideoFrameCallback` 指针拖拽进度条、悬停时间戳预览、逐帧步进（`,` / `.`）、倍速切换（`0.25x`–`2.0x`）、循环播放、画中画及完整键盘快捷键。
- **毫秒级零臃肿依赖全格式文档与表格预览引擎**：内置纯 TypeScript 解析内核（PKZIP 并行 `DecompressionStream` 解压、OLE2 Compound File / BIFF8 二进制解析、RFC 4180 自动嗅探分隔符解析与 `<colgroup>` 虚拟滚动表格），覆盖 `PDF`、`DOCX`、`DOC`、`RTF`、`ODT`、`XLSX`、`XLS`、`ODS`、`PPTX`、`CSV`、`TSV`、`PSV`、`JSONL`/`NDJSON` 及对象数组型 `JSON`，绝大多数常见文档与万行表格可在数毫秒内完成解析首屏展示。
- **修复浅色终端 Starship Powerline 提示符错位并加固 WebGL2 自动恢复**：明暗双主题统一保持 `customGlyphs: true` 确保 ``、``、`` 与框线字符 100% 撑满行高网格，同时增加 `WebglAddon` 上下文丢失后的有界自动重连恢复。

## 新增功能

1. **自研桌面端媒体播放器与拖拽预览增强**：
   - 视频快捷键全面适配：`Space` / `K` 播放暂停、`,` / `.` 前后逐帧微调、`ArrowLeft` / `ArrowRight` 快退快进 5 秒、`J` / `L` 快退快进 10 秒、`M` 静音、`R` 循环、`F` 全屏、`Home` / `End` 跳至首尾；拖拽暂存灯箱同步接入自研播放器。
2. **全格式文件与办公文档工作台预览**：
   - **电子表格与结构化数据（`PocketDataGrid`）**：支持 `.csv`、`.tsv`、`.psv`（自动识别分隔符与 BOM）、`.xlsx`（多 Sheet 切换、共享字符串、Excel 日期序列号格式转换）、`.xls`（含二进制 OLE2 BIFF8 及网页导出兼容格式）、`.ods`、`.jsonl` / `.ndjson` 及对象数组 `.json`；支持 10 万级行虚拟滚动、列点击排序、实时搜索过滤及底部单元格详情复制，支持「表格 / 源码」一键切换。
   - **Word 与富文本文档（`PocketDocViewer`）**：支持 `.docx`（标题层级、加粗/斜体/颜色/超链接、列表、嵌套表格与内嵌图片）、`.odt`、`.rtf`（含中文 Unicode/多编码转义解析与源码切换）以及 `.doc`（macOS 下结合系统 `textutil` 高保真渲染并内建跨平台二进制正文提取兜底）。
   - **演示文稿、PDF 与图片工作台工具栏**：新增 `.pptx` 幻灯片「全部滚动 / 单页切换」双模式预览；`PocketPdfViewer` 毫秒级页数统计与「适应宽度 / 整页 / 100% / 150%」视图预设；`PocketImageViewer` 新增宽高读数、滚轮/按钮缩放（25%–400%）与透明底纹网格切换。
   - **媒体与扩展名全端扩展**：Rust 本地协议新增 CORS 允许头，本地文档/表格/PDF 跳过 Base64 编解码直接零拷贝流式读取字节（1–5 ms）；宿主机与桌面端扩展支持 `.mkv`、`.avi`、`.ogv`、`.mpg`、`.aiff`、`.caf`、`.avif`、`.psv` 等媒体与办公类型，同时保持对密钥/凭据文件与设置目录的严格隔离。

## 交互与体验优化

- **视频画面零遮挡与高帧率拖拽体验**：使用 CSS 变量直接驱动已缓冲与播放进度条宽度及毫秒计时器，播放期间主界面零额外重绘；进度条支持指针捕获平滑拖动与悬停时间预览。
- **WebGL2 上下文恢复守护**：当息屏休眠或 GPU 重置触发 `webglcontextlost` 后，`TerminalSurface` 将自动尝试有界重连 `WebglAddon`，避免长驻终端标签永久退化为 DOM 回退渲染。

## 问题修复

- **修复浅色模式下 Starship 分段胶囊底边错位缺口**：修复 `v0.2.17` 仅在深色模式下开启 `customGlyphs` 导致的浅色模式 Powerline 字形退化及底部 1/4 格高错位问题，并添加回归测试防止后续误关闭。
- **修复本地大尺寸 PDF / Office 文件 Base64 中转慢的问题**：通过 `pocket-local://` 直接二进制读取与 Range 流式传输，大幅缩短大文件首屏打开延迟。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并过苹果公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：推荐将服务端、各电脑 `hostd` 与桌面端同步升级至 `v0.2.18`，以获得新版非遮挡视频播放器、全格式毫秒级文档/表格预览与浅色终端对齐修复；如需体验对远端电脑 `.doc`/`.docx`/`.xlsx`/`.pptx`/`.mkv` 等新增文件类型的阅读，请同时升级对应电脑上的 `hostd`。
