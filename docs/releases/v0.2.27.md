# Herdr Pocket v0.2.27 更新说明

Herdr Pocket `v0.2.27` 重点解决桌面端操作后主窗口无法拖动、重启后窗口位置与跨屏幕状态丢失问题，并将 H5 网页端对齐移动端的纯粹扫码与通行密钥身份体系，实现开箱即用的跨端连接与无感恢复体验。

## 更新亮点

- 修复桌面端主窗口在持续操作后无法拖动的问题：根治 macOS 下 `mouseMoved` 与异步 WebView 调用覆盖 `NSApp.currentEvent` 导致系统原生拖动静默失效的故障，并在主窗口获得焦点时自动收敛灵动岛遮挡，保障顶部标签栏全区域可稳定拖拽移动。
- 多屏幕窗口状态无感持久化与恢复：桌面端现会自动记录主窗口所在显示器、逻辑坐标、窗口尺寸、最大化与全屏状态；重启或更新后只要原屏幕仍在线且有效交叠可见，立即精准恢复到关闭前的屏幕与布局；若外接显示器已拔掉，则自动安全居中回落。
- H5 网页端移动端化扫码与通行密钥默认身份体系：H5 登录面板现像手机客户端一样直接面向摄像头扫码与图片二维码识别，移除反向扫码等待流程；连接成功后默认引导通过硬件通行密钥锁定唯一身份，换新设备或清理浏览器缓存后可用通行密钥一键回到原有身份。

## 新增功能

- H5 摄像头实时扫码与图片二维码解码（`apps/desktop`、`apps/relay`）：
  - 新增 `H5QrScannerModal` 扫码取景弹窗，调用浏览器 `BarcodeDetector` 与内嵌 `jsQR` 双引擎实时解析桌面端、命令行或已登录设备上的配对二维码，支持前后摄像头切换与透明背景截图/相册二维码图片自动补白识别。
  - 登录面板「摄像头扫码连接」卡片同步提供「打开摄像头扫码」与「选二维码图片」直达入口，支持标准 `/p/` 邀请链接、`herdrpocket://pair` 深链、`?pair=` 网页链接及裸配对码。
- H5 通行密钥优先与唯一身份防重合并（`apps/relay`、`apps/desktop`）：
  - 首次扫码或输码进入 H5 后，自动弹出「使用通行密钥确认唯一身份」引导框，可直接「创建并绑定通行密钥」，也可点「已有通行密钥？回到上一个身份」。
  - `POST /v1/identity/passkey/options` 返回完整的 `authenticatorSelection`（优先可发现通行密钥与用户验证）；当临时会话通过通行密钥切换回已有身份时，`POST /v1/identity/reconfirm` 自动合并清理冗余的临时浏览端记录，确保设备列表不产生重复节点。
- 桌面端多屏幕几何状态原子持久化（`apps/desktop/src-tauri`）：
  - 新增 `~/.config/herdr-pocket/window-state.json`（`0600` 原子写入）保存窗口坐标、逻辑尺寸、最大化与全屏状态，并在移动/缩放防抖及应用重启/退出前自动落盘。
  - 桥接原生 `window_start_dragging` 与 `window_toggle_maximize` 命令，补齐 macOS 标签栏双指点击、快速连击按拖以及专用顶部拖拽手柄区的移动与双击最大化行为。

## 交互与体验优化

- H5 连接界面聚焦优化：移除网页端「让已登录的手机或电脑扫码放行」反向生成二维码区块，并将「用通行密钥快速回到上一个身份」长期保留在登录卡片中，方便新设备直接触发硬件凭证找回原身份。
- 外接显示器顶部拖拽体验提升：当主窗口处于焦点状态且灵动岛未处于悬停窥视或演示状态时自动隐藏灵动岛悬浮窗口，避免非刘海屏外接显示器上遮挡标签栏顶部居中拖拽区；标签栏末尾同步增加 28px 专用留白拖动手柄区域。

## 问题修复

- 修复 macOS 在桌面端连续操作、切换分屏或点击交互控件后，标题栏与标签栏空白区域拖拽窗口无反应的问题（合成匹配的 `LeftMouseDown` 原生事件并校验左键按压掩码）。
- 修复桌面端在多显示器环境中重启后总是重置回主屏默认居中的问题，兼容不同 DPI 缩放倍率屏幕之间的位置与尺寸校准。
- 修复透明底色二维码 PNG 在离屏画布解码时因黑底透明区域导致无法识别的兼容性问题。

## 多端与升级说明

- 本次发布同步交付中转服务 `relay`（内嵌最新 H5 网页端 `/app/`）、电脑守护进程 `hostd`、桌面端（macOS `arm64`/`x64` 已签名公证 `.dmg`、Windows 安装包、Linux `.AppImage`/`.deb`）、移动端与 HarmonyOS 产物。
- 升级后桌面端将从当前版本起开始持久化保存您的屏幕与窗口状态（外接显示器断开时仍自动回落居中）；中转服务升级至 `v0.2.27` 后，直接访问 `/app/` 即可体验 H5 摄像头/图片扫码与通行密钥一站式身份恢复。
