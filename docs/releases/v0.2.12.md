# Herdr Pocket v0.2.12 更新公告

## 更新亮点

- **修复「需要你」（含误判场景）ChatUI 输入无响应与跨平台粘贴时序稳定性**：当终端处于 `blocked`（「需要你」）状态时，ChatUI 通过 `HcScreens.paste` 直连终端流即时投递并适配 `?2004h` bracketed paste，跳过 `hc send` 对 `blocked` 的拦截及最长 60 秒静默等待；同步修复慢速环境或跨平台子进程启动时初始帧等待计时器过早触发的竞态问题，并保留 `--force` CLI 回退链路。
- **「更新 › 镜像源」下拉框与 `ms` 延迟徽章**：`PocketSelect` 右侧原生展示等宽 `ms` 延迟徽章（例如 `3660 ms` / `时区推荐` / `最快` / `不通`），默认按系统时区推荐顺序并发全量测速并选中最低延迟节点，默认自动检查频率提升至 `30 分钟`（可选 `15 分钟`）。
- **设置文案精简与单行控件化**：全面压缩设置面板各分类的冗长描述，并将语音输入中的并排推荐模型卡片收拢为简洁的单行 `PocketSelect` 选择器。
- **完整集成近期多端核心升级**：
  - 旁路提问 `/btw`（`working` 不打断主线，独立可折叠只读抽屉）与 `/skill` / `/command` 输入框融合图标胶囊；
  - OMP 模型目录完整适配与思考等级自动检测，消除 `unknown method agent.models`；
  - 跨重启工作区状态持久化（排队列表、失败/中断重试、输入框草稿与附件、标签与空间）；
  - 状态栏一键唤醒小羊实时语音与 SOTA 语音/ASR/LLM 预设；
  - 原生级本机终端、毫秒级 Kitty 图片渲染、`Shift+Enter` 换行区分与 Finder 文件夹零报错拖入。

## 新增功能

1. **即时流式终端粘贴通道（`HcScreens.paste`）**：
   - 在与 `herdr-core` 的 framed 输入流上跟踪终端 `?2004h` / `?2004l` 模式，并在 `terminal.attach` 建连完成后再启动首帧探测窗口（100 ms），保证跨系统下稳定捕获初始状态并即时投递文本与 Enter。
   - 在不可直连场景自动回退 `hc send --force --`（兼容不含 `--force` 的旧版 `hc`）。
2. **`/btw` 旁路问答与内嵌斜杠胶囊**：
   - 新增只读 `agent.btw` RPC 与 `BtwSideDrawer`，`ComposerSlashChip` 自动识别 `/btw`、`/skills:*` 等指令，Backspace 自然解包。
3. **跨重启全量工作区持久化（`workspace_state`）**：
   - 桌面端原子持久化至 `workspace-state.json`，移动端与浏览器端同步落地排队消息、草稿与标签状态。

## 交互与体验优化

- **「需要你」状态下 ChatUI 即时反馈**：点击排队消息的「立即发送」仅在 `working` 状态才先中断当前轮，`blocked` 状态直接送入 Terminals；输入失败即时弹出 Toast 提示，刚发出的消息 15 秒内显示等待响应反馈。
- **设置页面与镜像测速精简清晰**：「镜像源」下拉选项与收起态统一使用右侧等宽 `ms` 徽章；全部分类介绍压缩至一目了然的一行短句。
- **真本机终端体验**：区分标准 Shell 与 Agent TUI 的 `Shift+Enter`，支持 Kitty 图片头 64 字节嗅探 + `pocket-local://` 零拷贝渲染，并支持系统访达（Finder）文件夹安全拖入。

## 问题修复

- **修复 `HcScreens.openInputEntry` 首帧超时计时器在子进程连接前触发导致的 bracketed paste 丢失问题**：改为在 `terminal.attach` 建连、回放早期帧并授予 flow-control credit 之后才启动首帧兜底计时器，消除 CI / 高负载主机偶发失败。
- **修复 `HcAdapter` 自定义二进制路径未同步传入 `HcScreens` 的问题**。
- **修复 `blocked`（「需要你」）状态下 ChatUI 输入被拒绝或延迟的问题**。
- **修复 OMP 思考等级按钮未在挂载时自动显示、镜像源测速提前中断、以及重启后排队消息丢失等问题**。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：请同时更新电脑端 **Herdr Pocket Hostd** 与桌面/移动客户端，以获得「需要你」状态下 ChatUI 即时终端投递、`/btw` 离线旁路与完整 OMP 思考等级自动检测能力；macOS 用户可在「设置 › 更新」选用测速最快的镜像一键升级，或下载已公证安装包覆盖 `/Applications/Herdr Pocket.app`。
