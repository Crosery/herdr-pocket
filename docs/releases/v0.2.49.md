# Herdr Pocket v0.2.49 更新说明

本次 **v0.2.49** 重点重构跨端悬浮回传窗口（`SessionPortalPiP`）的**终端命令溯源绑定、分屏格精确归位与 EG 浏览器（`ego-browser` / `ego lite`）空间状态直显**。从此只有当前终端启动的命令或浏览器任务才会触发对应悬浮窗，并严格贴合在启动它的分屏终端内；当 AI 操作 EG 浏览器时，悬浮窗直接反映该 TaskSpace 空间状态与专属窗口，彻底告别无关系统窗口串屏与错位遮挡。

## 更新亮点

- **悬浮窗严格归位至启动它的分屏终端**：移除工作区全局叠放的 `WorkspacePortalOverlay`，改为由各个终端/对话分屏面板独立承载 `SessionPortalPiP`（同会话兼开对话与终端分屏时自动优先停靠在终端格内），并通过 `ResizeObserver` 随分屏拖拽即时重算宽高与边界，多列分屏下也不会串台或挡住相邻栏文字。
- **严谨的命令溯源与进程树归属，杜绝无关窗口误弹**：清理跨终端全局推测（`lastCommandCtx` 与单工作节点猜测）以及 `!agentKey` 通配泄漏；系统窗口变化仅在匹配终端 PTY 子孙进程树或该终端明确提交的打开/预览意图时才会创建回传浮窗，聊天软件、个人网页或其他终端任务不再误入。
- **EG 浏览器（`ego-browser` / `ego lite`）空间级精准绑定与状态联动**：自动识别脚本中的 `taskSpace(...)`、`SPACE_ID`、`.page(...)`、`.goto(...)`、`handOff()` 与 `finish({ keep: [] })` 等操作并只读同步 TaskSpace 元数据，严格隔离用户个人浏览空间（`createdBy: "user"`）与 Agent 任务空间；任务调用 `finish({ keep: [] })` 后自动收起关闭对应悬浮窗。

## 新增功能

- **协议层 EG 空间状态字段（`packages/protocol/src/index.ts`）**：
  - 新增 `EgoSpacePhase`（`running` / `handoff` / `user` / `finished` / `idle`）与 `PortalEgoSpaceState` 结构，并作为可选字段 `egoSpace` 扩展至 `PortalItem`。
- **`ego-browser` 语义与空间窗口解析（`apps/hostd/src/portal/egoSpace.ts` / `shims.ts`）**：
  - 新增 `--ego-server-name`、`taskSpace` 名称与编号、`handOff()` / `finish()` 生命周期、动作描述与终端快照头解析，并跳过纯只读诊断探测（`listTaskSpaces()` 等）。
  - 新增 `selectMatchingEgoSpaceWindow`，按空间名、当前标签页标题与独占窗口标题精确匹配对应 Agent TaskSpace 的 `ego lite` 窗口，永不误抓用户个人空间画面。
- **跨端统一 EG 空间状态视觉表达（Desktop / H5 / HarmonyOS / Mobile）**：
  - 桌面端、网页 H5、鸿蒙 NEXT 与移动端同步支持「AI 操作中」「等你接管」「已移交」「空间就绪」相位徽章、空间编号与标签计数摘要条、当前页面标题与最新动作状态展示；无独立窗口画面时仍清晰呈现 EG 空间实时状态。

## 交互与体验优化

- **窄栏分屏自适应边界与排版**：分屏列变窄时，悬浮窗自动以 `offsetParent` 实际尺寸收敛最小宽度与拖拽边界；多窗「平铺」布局在窄分屏自动切为单列纵向网格，「叠列」卡片自适应可用宽度，避免横向裁切。
- **窗口句柄就绪即刻续流**：当 EG 浏览器任务空间先行建立状态、随后对应独立窗口才打开或切换标题时，前端自动感知 `windowId` 变更并无缝接通画面流。

## 问题修复

- **修复分屏内悬浮窗跨终端串显示问题**：修复 `listPortals(agentKey)`、`emitEvent`、`filterVisiblePortalItems`、`PortalViewerModal` 与移动端 `useAgentPortals` 中允许 `!agentKey` 透传的问题，保证每个终端与面板只消费归属自己的 `agentKey` 回传项。
- **修复外部浏览窗口或聊天视频窗口误触发浮窗**：移除 `pollWindowDeltas` 对未关联命令的浏览器标题变化及无进程树归属桌面窗口的无差别采集。
- **修复画面帧覆盖 EG 空间命名**：当回传项携带 `egoSpace` 元数据时，视频帧刷新不再覆写 `EG 空间 · <空间名>` 标题与阶段状态摘要。

## 多端与升级说明

- **涵盖平台与升级建议**：本次升级同步覆盖 `hostd` 电脑守护进程（`herdr-pocket update`）、桌面端（macOS / Windows / Linux，通过 **「设置 › 更新」** 或新版应用内热替换弹窗更新）、Android（`.apk`）、HarmonyOS NEXT、iOS 与网页 H5（`/app/`）。
- **版本协同建议**：为体验完整的 EG 浏览器空间状态直显与按终端分屏归位能力，建议同步升级电脑端 `herdr-pocket` 守护进程与常用桌面/移动端客户端至 **v0.2.49**。
