# Herdr Pocket v0.2.20 更新公告

## 更新亮点

- **深度对齐 Herdr App 布局文档与分屏机制**：新增基于乐观锁（CAS）的 `"herdr-app"` Shared 文档双向同步（`Space -> Tab -> Split Tree`），电脑端桌面与移动/远程端的空间、标签编号与多窗格树实时保持一致；Agent 默认在终端视图打开（保留对话视图一键切换）。
- **双端终端引擎、配色与快捷键对齐**：内置 **Graphite**（`#17191d` 暗色）与 **Paper**（`#ffffff` 深色墨迹）终极对比度配色、独立非阻塞帧写入线程与二进制本地流传输、`33ms` 输出节流加输入回显快路径、终端内搜索浮条以及与 `Herdr.app` 一致的标签与编辑快捷键。
- **修复多查看端终端尺寸失步错位、Nerd 图标粘连与裸文件名跳转误报**：同步转发 `hc` 尺寸变更并在切回焦点时重排重连，优先选用单倍等宽 `* Nerd Font Mono` 字体，并支持从终端上下文回溯工作区子目录打开仅含文件名的链接。

## 新增功能

1. **Herdr 布局文档双向同步（`herdr.doc.get` / `herdr.doc.set`）**：
   - 在 `packages/protocol`、`apps/relay`、`apps/hostd` 及桌面端本地 Rust 桥接中新增基于版本号的 CAS 文档读写与 `events.subscribe` 实时 `doc` 事件订阅；即使原生 `Herdr.app` 窗口未打开，宿主守护进程仍可通过 `herdr.layout` 兜底读写布局。
   - 在 `apps/desktop/src/shell/herdrDoc.ts`、`apps/desktop/src/shell/herdrDocSync.ts` 与 `apps/desktop/src/shell/shellStore.ts` 实现双向编解码，自动吸收连接启动阶段先打开的单窗格 Agent 标签，避免多窗格分屏同步后出现重复标签，同时无损保留 Pocket 独有的文件、Diff 与网页分屏。
2. **原生级本地终端二进制流与尺寸订阅（`local_term.rs`）**：
   - 新增独立非阻塞 `hc-framed-writer` 写入线程、基于 Tauri `Channel<ArrayBuffer>` 的零 Base64 开销二进制输出流、`localTermKill` 快速关闭通道，以及 `local-term://doc-changed`、`local-term://terminals-changed` 与 `local-term://size` 实时事件推送。
3. **终端内回溯搜索浮条（`Cmd+F` / `Ctrl+Shift+F`）**：
   - 新增 `apps/desktop/src/lib/terminalSearch.ts` 跨折行/宽字符搜索与 `TerminalSurface` 右上角搜索浮条，支持实时计数定位、上下跳转与 `Esc` 快速关闭并归还终端焦点。
4. **工作区子目录裸文件名智能定位**：
   - 新增 `resolveBareTerminalFileLink` 与工作区有界广度优先后缀匹配，当 CLI 输出仅包含裸文件名（如探索摘要中的 HTML/源码文件）时，先回溯终端邻近上下文，再在工作区子目录内安全匹配真实相对路径并回写标签状态。

## 交互与体验优化

- **对齐 Herdr App 标签与分屏视图**：
  - 接入或演示模式启动时自动选中活跃空间（Space），空间标签采用简洁数字序号（`1` / `2` / `3`）与 `[+]` 最大化角标，支持双击内联重命名、标签栏鼠标滚轮切页及 `Cmd+1..9` / `Ctrl+1..9` 快速跳转。
  - 分屏窗格间隙调整为 `8px`，采用 `30px` 极简顶栏并仅在悬停时浮现视图切换/搜索/分屏/最大化/关闭按钮；非聚焦分屏保持 `100%` 清晰不透明度，支持顶部把手拖拽换位及 `25%` / `50%` 边缘分屏热区。
- **终端输入与剪贴板手感打磨**：
  - 支持 Graphite / Paper 双主题（`minimumContrastRatio: 1` 保持纯正 ANSI 墨色）、`JetBrains Mono` 与 `Pocket Maple Mono` 优先字体栈、选区即复制（copy-on-select）、键入自动清除选区并滚回底部、按住 `Shift` 绕过 TUI 鼠标追踪、替代屏滚轮映射方向键、`?2004h` 括号粘贴及 `OSC 52` 写入剪贴板。
  - 文本类 HTML 预览 `<iframe>` 启用 `allow-scripts` 沙箱，支持本地静态交互文档正常展示。

## 问题修复

- **修复多端共用同一 `hc` 终端时的屏幕错位与重绘覆盖**：当桌面应用处于后台或分屏大小变化时，未持焦点窗格会跟随 `local-term://size` 保持与上游 PTY 一致的网格行列，防止绝对光标定位（CUP）被小窗口行高截断导致界面上移覆盖输出框；切回焦点时自动触发清理重连以夺回 PTY 尺寸并重放重排后的完整屏幕，同时修复 `localTermAttach` 飞行期间尺寸变化的竞态问题。
- **修复 Nerd Font 比例宽度图标与后续字母粘连重叠**：调整 Rust 端 `symbols_font_priority` 与前端字体回退顺序，优先使用单列等宽的 `Symbols Nerd Font Mono` 与 `* Nerd Font Mono`。
- **修复点击终端摘要中的裸文件名误报“文件已删除”**：补齐本地 Tauri 文件读取与 `hostd` `files.read` 的子目录后缀解析（严格排除 `.git`、`node_modules` 及隐私敏感目录），正确打开位于子目录中的目标文件。
- **修复多窗格分屏同步时误保留重复单页标签**：将孤立标签吸收逻辑扩展至多窗格所有 Agent 叶子节点，保留原视图模式与焦点窗格。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并过苹果公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像（可搭配公开部署占位域名 `pocket.example.com` 使用）。
- **协同建议**：本版本包含新增的 `herdr.doc.get` / `herdr.doc.set` 布局同步契约，建议同步升级服务端 Relay、各台电脑上的 Hostd 守护进程与桌面客户端，以获得与电脑端 `Herdr.app` 一致的分屏布局实时同步与双端无错位终端体验；升级命令仍可在电脑上执行 `herdr-pocket update`、服务端执行 `sudo herdr-pocket-relay update` 或直接在桌面端设置中检查更新。
