# Herdr Pocket v0.2.32 更新说明

Herdr Pocket `v0.2.32` 全面升级跨设备自动回传与实时小浮窗体验：无论是外部设备在远端终端中直接敲入 `open` 等打开命令，还是 Agent / 子 Agent 调用脚本、MCP 工具操作浏览器与预览文件，系统均可在当前会话实例内自动识别并实时弹出、流式刷新对应画面小浮窗（支持独立交互、缩放与焦点保护）。

## 更新亮点

- **终端敲击 `open` 自动识别并弹起小浮窗**：实时重建终端原始按键与粘贴命令行，兼容 `open`、`open -R`、`open -a 应用名`、`cd ... && open ...`、`xdg-open` 与 `gio open`；既让宿主机正常拉起目标应用或网页，又自动识别打开的文件、目录、浏览器页面或对应系统窗口，直接在当前端会话内浮窗呈现实景画面。
- **Agent 与纯终端统一的实时浏览器回传**：无论是通过对话调用的 Agent / 子 Agent，还是终端内直接运行的浏览器自动化 CLI（`ego-browser`、`tabbit`、`agent-browser`）或 MCP 浏览器工具，均可自动捕获对应浏览器窗口画面并持续以 6 FPS 流式刷新至小浮窗，并支持同一浏览器任务多次导航自动复用同一浮窗而不重复刷屏。
- **终端与对话双视图不遮挡、不抢焦点的小浮窗**：小浮窗在终端模式下自动锚定右上角（`320×224`，避开底部输入行），支持右键/拖拽移动与八方向缩放；所有点击、拖动与折叠操作均通过事件拦截保持终端输入焦点不丢失。
- **包含 `v0.2.31` 全部桌面端体验增强**：本版本同时涵盖红绿灯动态避让、新版侧边栏、终端直达底部无回放滚动与独立源远端 HTML 预览能力，推荐所有端同步升级至 `v0.2.32`。

## 新增功能

- **引文与 Heredoc 感知的命令行及键击识别引擎**（`apps/hostd/src/portal/shims.ts`）：
  - 新增 `extractAutoPortalIntents`：完整解析引号、转义、多段链式命令（`&&` / `||` / `;`）、工作目录切换（`cd`）与 Heredoc 脚本体，精准识别 `open` 系列、独立 `-a 应用名` 唤醒以及浏览器自动化 CLI 调用（同时跳过注释、`--help`/`skill` 及提交信息中的引号文本误触发）。
  - 新增 `TerminalInputLineTracker`：在 `terminal.input` 通道按终端会话重组用户实时敲击与括号粘贴文本，过滤 ANSI 控制序列并处理退格、`Ctrl+C`、`Ctrl+U` 与 `Ctrl+W`。
- **宿主机全局 Agent / 子 Agent 实时工具调用嗅探**（`apps/hostd/src/uniflo.ts`、`apps/hostd/src/host.ts`、`apps/hostd/src/portal/index.ts`）：
  - `UnifloAdapter` 新增 `parentBySession`、`rootSessionKey` 与 `onLiveToolCall` 全局 SSE 事件钩子：即使当前未打开对话详情页，Agent 或嵌套子 Agent 调用命令、浏览器工具或文件展示工具时也能第一时间触发窗口或文件捕获。
  - 新增 `detectAndOpenWindowPortal` 与应用别名匹配表：按窗口标题/应用名及新出现窗口智能定位系统窗口并预校验可捕获性；当环境无图形桌面或录屏未授权且带有 URL 时自动降级启用无头 CDP 浏览器流式回传。
  - GUI 宿主机上的原生 `open` 垫片回传 `handled: false`，确保识别建窗的同时不阻断宿主机本身真实打开应用或页面。
- **小浮窗原生网页与图片内联预览及智能显隐**（`apps/desktop/src/components/SessionPortalPiP.tsx`、`apps/desktop/src/lib/portalClient.ts`）：
  - 新增 `filterVisiblePortalItems`：在本机桌面端操作本机终端时自动隐藏冗余的自动浮窗（仅保留用户手动发起的回传），而在跨设备控制远端电脑或使用 H5 / 移动终端时自动弹出并激活最新浮窗。
  - 远端 HTML 与图片文件可在浮窗内直接加载缩放预览视图与缩略图，头部新增「在内置浏览器标签打开」快捷按钮。

## 交互与体验优化

- 终端模式下 `SessionPortalPiP` 默认停靠右上角并加宽至 `320×224`，对话模式下保留输入框上方停靠位置；切换最顶层活跃回传项时自动切至最新画面并展开预览。
- 浮窗帧流订阅默认帧率由 `3 FPS` 提升至 `6 FPS`，并在订阅首拍立即主动抓取首帧画面，缩短点击与弹窗后的空白等待。
- `SessionPortalPiP` 根节点阻断鼠标按下转移焦点，点击拖拽小窗时不会中断终端键盘输入或组词状态。

## 问题修复

- 修复纯终端内手工敲击命令（走 `terminal.input` 而非 `terminal.send` 或 Agent 工具调用）及 `open -a 应用名` 无路径参数时无法自动触发跨端回传的问题。
- 修复 `RemoteWindowInfo` 窗口尺寸匹配未读取 `bounds` 嵌套字段导致过滤异常及误匹配全屏屏幕条目（`isScreen`）的隐患。
- 修复本机桌面端控制本机终端时也可能因其他设备在线而误弹出自身窗口小浮窗的问题。

## 多端与升级说明

- **服务端（Relay）**：携带 `v0.2.32` 最新 H5 前端静态资源，升级服务端源码并重启 `herdr-pocket-relay` 即可生效。
- **电脑守护进程（hostd）**：必须升级受控电脑与发起端电脑至 `v0.2.32`（运行 `herdr-pocket update`），方可获得实时命令嗅探、子 Agent 工具钩子及浏览器窗口捕获回传能力。
- **桌面端（macOS / Windows / Linux）**：建议升级至 `v0.2.32`，可在设置 › 更新中一键检查下载，或从 GitHub `Latest` Release 安装对应平台安装包覆盖升级。
- **移动端（Android / iOS / HarmonyOS NEXT）与 H5**：Android（`.apk`）与 iOS（`.ipa`）未包含原生端变更，由本版 `Latest` 自动结转附带经过签名的客户端安装包；HarmonyOS NEXT（`.hap`）随 `v0.2.32` 同步重建打包发布。
