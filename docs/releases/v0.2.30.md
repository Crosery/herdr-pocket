# Herdr Pocket v0.2.30 更新说明

Herdr Pocket `v0.2.30` 彻底根治终端输入丢失、组词与灵动岛浮窗抢焦点或遮挡、未按 `Command` 键却误弹快捷键提示以及界面列表意外跳动问题，并上线完善且脱敏的桌面端用户交互与异常埋点体系。

## 更新亮点

- **终端打字零丢字、告别浮窗遮挡**：移除组词框 `.composition-view` 的粉色卡片边框与阴影，改为与终端基线对齐的无边框内联下划线渲染；同时停止在打字或失焦瞬间清空隐藏输入域 `textarea.value` 或强改输入域尺寸，确保拼音、五笔与语音输入法在连续输入与切焦点时不再丢失任何文字或误发退格键。
- **macOS 顶部浮窗默认关闭且不再抢焦点**：顶部灵动岛提醒窗口默认关闭（可在 设置 › 提醒 中按需手动开启），并将桌面端悬浮提示窗在 macOS 上的显示与隐藏路径改为非激活窗口协议（`orderFrontRegardless` / `orderOut`），彻底消除后台 Agent 提醒刷新时调用 `makeKeyAndOrderFront` 抢走键盘焦点导致打字中断的问题。
- **未按 `Command` 不再误弹快捷键提示**：桌面端快捷键按住提示（`ModifierChordHud`）在触发前与持续显示期间直接校验操作系统底层 HID 修饰键状态（macOS `NSEvent.modifierFlags` / Windows `GetAsyncKeyState`），并在剪贴板粘贴、输入法组合、鼠标移动修饰键不匹配或失焦时立即撤回，杜绝 WKWebView 漏派发 `keyup` 引起的幽灵 `Command` 提示。
- **完善用户交互与界面异常埋点**：新增无隐私明文的桌面端行为与异常遥测（`uiTelemetry.ts`），全面记录修饰键提示误触拦截、窗口高频抢焦点震荡、终端 PTY 异常跳变及标签/分屏/空间切换触发来源，所有事件同步写入本地诊断日志并随授权上报中转服务，便于快速定位偶发交互问题。

## 新增功能

- **原生操作系统修饰键校验与前端桥接**（`apps/desktop/src-tauri`、`apps/desktop`）：
  - 新增桌面原生命令 `query_os_modifiers` 并暴露为 `native.queryOsModifiers()`，支持在弹出与维持快捷键浮层时读取系统真实物理按压状态。
- **全链路用户行为与界面异常埋点**（`apps/desktop/src/lib/uiTelemetry.ts`、`shellStore.ts`、`TerminalSurface.tsx`、`terminalIme.ts`）：
  - 采集 `ui.modifier.show`、`ui.modifier.hide`（附按住时长与关闭原因）、`ui.modifier.ghost_blocked`（记录 DOM 与系统底层修饰键不一致的误弹拦截）。
  - 采集 `ui.window.focus` 与 5 秒内高频焦点抖动告警 `ui.window.rapid_focus_flip`。
  - 为 `ui.tab.focus`、`ui.tab.switch`、`ui.space`、`ui.split.zoom` 与 `ui.split.unsplit` 补充 `trigger` 触发来源（用户点击、快捷键、提醒跳转或自动恢复），区分手动操作与自动状态迁移。
  - 在 `TerminalSurface.tsx` 与 `terminalIme.ts` 接入去敏节流事件 `term.ime.rescue_xpc`、`term.ime.rescue_comp`、`term.ime.paste_dedup` 与 `term.layout.jump`（仅统计字符数与行列差值，绝不记录输入正文或剪贴板内容）。

## 交互与体验优化

- **侧边栏 Agent 列表与顶部标签栏防跳动**：
  - 侧边栏按状态分组模式下新增同组顺序锚定（`stableGroupOrderRef`），后台 Agent 状态刷新与时间戳推进不再导致已有行在光标下方来回换位，仅新进入分组的 Agent 排在组首；悬停时继续冻结当前排列。
  - 顶部标签栏 FLIP 位移动画限制为同一空间内标签增删或拖拽重排时触发，切换空间或更新 Agent 标题不再触发整行标签闪烁滑动。
  - 底部状态栏内联快捷键标签在常态即保留对称内边距与负外边距（`padding: 1px 5px; margin: -1px -5px`），按住 `Command` 高亮时零像素位移。
- **更新检测记忆源独立超时**：`fetchManifestOrSumsFromSource` 在 `RELEASE-MANIFEST.json` 请求超时回退拉取 `SHA256SUMS` 时使用独立的子 `AbortController` 计时器，避免单次冷连接回退因共享剩余计时而提前中止。

## 问题修复

- 修复 `v0.2.29` `terminalIme.ts` 在 `6ms`/`8ms` 定时器内清空 `textarea.value`、`80ms` 失焦清空组词状态及 `MutationObserver` 高频改写 `textarea.style` 与 `xterm.js` `CompositionHelper` 单调下标及 `0ms` 提交定时器竞争，进而导致打字或语音输入内容丢失、偶发误发 `\x7f` 退格的问题；同步修复快速连续两次 `compositionend` 间 `emittedSeq` 被前次提交递增导致后一次兜底跳过的问题。
- 修复 `terminalIme.ts` `clampCompositionOverlayLayout` 默认底部留白 `28px` 造成普通行输入拼音或听写文本时预览条向上跳动并遮挡前序命令行文字的问题。
- 修复 `notch.rs` 与 `voice/hud.rs` 在 macOS 上显示悬浮窗时调用 `w.show()`（`makeKeyAndOrderFront`）意外夺走主窗口键盘焦点的问题。
- 修复 `useModifierHoldHints.ts` 默认等待仅 `260ms` 且未校验系统物理按键状态、在快速按 `⌘C`/`⌘V` 或切换输入法后误弹出快捷键提示并卡在界面上的问题。
- 修复 `FocusFlipTracker` 初始 `lastWarnAt = 0` 导致前 5 秒内的连续焦点抖动告警无法立即触发的边界问题。

## 多端与升级说明

- **服务端（Relay）**：包含 `v0.2.30` 最新 H5 前端静态资源，升级服务端源码并重启 `herdr-pocket-relay` 即可生效。
- **电脑守护进程（hostd）**：版本号同步对齐至 `v0.2.30`，运行 `herdr-pocket update` 即可升级。
- **桌面端（macOS / Windows / Linux）**：推荐所有受输入丢失或误弹快捷键提示影响的桌面端用户立即升级至 `v0.2.30`，可在设置 › 更新中一键检查下载，或从 GitHub `Latest` Release 安装对应平台安装包覆盖升级。
- **移动端（Android / iOS / HarmonyOS NEXT）与 H5**：Android（`.apk`）与 iOS（`.ipa`）未包含原生端变更，由本版 `Latest` 自动结转附带经过签名的 `0.2.28` 客户端安装包；HarmonyOS NEXT（`.hap`）随 `v0.2.30` 同步重建打包发布。
