# Herdr Pocket v0.2.33 更新说明

Herdr Pocket `v0.2.33` 是一次全端体验与底层传输能力大版本更新：彻底重做手机端 H5 与原生客户端的交互一致性，落地基于本机 TCP 隧道的零代理延迟 P2P 直连、Relay 服务端安装包缓存与 4 线程断点并行加速更新，以及高达 1 GiB 的大视频零卡顿分片直传；同时全面修复打断发送重复气泡、语音输入挤开已有文字、快捷键幽灵角标、热键录制卡死、声纹跨设备丢失与跨端小窗断连等关键问题。

## 更新亮点

- **手机 H5 1:1 还原 Android / iOS 原生交互与视觉体验**：保留网页端扫码 / 配对码 / 通行密钥防漂移登录页，登录后默认进入「助理」首页与底部 4 标签导航（`助理`、`Agents`、`设备`、`设置`，54x30 柔和粉色激活胶囊），完整同步左侧滑动筛选抽屉、统计筛选卡、手势终端快捷键盘、卡片式设备页与渐变个人资料设置页。
- **P2P 零延迟直连与跨端窗口秒连**：宿主机自动过滤虚拟网卡假 IP（`198.18.*` / `198.19.*`），桌面端通过 Rust 原生 `127.0.0.1` 隧道直连对端地址并用 120ms Happy Eyeballs 并发竞速，彻底绕开系统 Clash / TUN 代理延迟与断流；`PortalViewerModal` 打开即主动建立直连并在窗口内实时合并帧请求与 macOS CoreGraphics JPEG 原生抓屏，消除重复重连抖动。
- **百兆级大视频零卡顿上传与流式传输**：拖入超过 5 MB、最大 1 GiB 的大视频或大文件时改为瞬时就绪，跳过全量 Base64 常驻内存与整文件预览读取（`pocket-local://` 严格按 2 MB 分片响应 Range 请求）；优先通过 P2P HTTP `POST /v1/direct-put/<token>` 高速流式上传，不可直连时自动降级为 2 MB RPC 分片上传并实时显示百分比进度。
- **Relay 安装包缓存 + 4 线程并发竞速更新 + macOS 权限持久化**：中转服务新增 `GET / HEAD /v1/releases/download/:tag/:asset`（支持 `SHA256SUMS` 自动校验、`Range 206` 与最近 3 个版本自动清理）；桌面端下载器优先竞速中转与高速镜像、大文件启用 4 线程 Range 分片并发下载并在慢速源低于 150 KB/s 时 4 秒自动切换；macOS 覆盖安装改用固定本机签名证书（`Herdr Pocket Local Signer`）与 `rsync -a --delete` 原地替换，更新不再丢失系统权限。

## 新增功能

- **单气泡打断 / 插队发送（`interruptComposerNow`、`injectTerminalQueuedNow`）**：在 Agent 忙碌时触发「打断发送」或点击排队消息「立即注入」，直接合并状态为一条实时发送气泡并将加载指示紧跟其后，彻底消除一问出两条气泡与顶部排队槽重复显示问题。
- **中转服务声纹云端同步与本地音频文件导入**：Relay 新增受令牌保护的 `GET / PUT / DELETE /v1/voiceprint` 接口；桌面端持久化保存 `~/.local/state/herdr-pocket/voiceprint-cache.json`，支持一键从 `.wav`/`.mp3`/`.m4a`/`.aac`/`.flac` 音频文件离线提取声纹、录制后自动同步云端，并在设置行内直接调节「只认我的声音」、「首说话人锁定」与灵敏度档位。
- **桌面端触控键盘核心组件（`apps/desktop/src/mobile/MobileTermPad.tsx`）**：为手机 H5 终端视图提供 5 行紧凑字母/符号切换键盘、快捷指令胶囊与一键切换系统中文键盘入口，点击虚拟按键不触发系统软键盘反复弹起。

## 交互与体验优化

- **侧边栏「空间」分组固定展示**：移除桌面端与手机抽屉里无意义的「空间」标题折叠箭头，`空间` 分组标题始终固定展开。
- **快捷键按住提示去幽灵化与底部精简布局**：macOS 原生检测合并 `CGEventSourceKeyState` 物理按键状态（排除输入法/系统残留修饰键误触），`Hold` 延迟提升至 600ms，禁用角落浮层角标并将组合键提示固定在底部 28px HUD 中；终端有输入动作时自动收起组合键提示。
- **语音输入与组词稳定性全面增强**：
  - 对话框组合输入（`compositionstart`/`update`）期间锁定首字符斜杠状态、防止高度塌陷，并启用 `overflow-wrap: anywhere` 防止长语音文本将输入框挤宽溢出。
  - 终端内有提示符前缀时将组合输入浮层智能换行到光标下一行，避免覆盖行首与挤压现有文字；同时对终端分屏尺寸变化增加 90ms 防抖与最小宽高守卫（`cols < 24 || rows < 6` 跳过无效缩放），消除切换标签或分屏时的闪烁重绘。
- **热键录制器免焦点劫持与语音通话连接超时保护**：`HotkeyRecorder` 改为窗口捕获级 `keydown` / `pointerdown` 监听并在录制期间暂停后台全局快捷键触发，支持随时按 `Esc` 或点击空白退出，不再卡死或被原热键拦截；实时语音 WebSocket 新增 8 秒连接超时提示，不再无限转圈。
- **组件更新报错翻译与去重（`ToolVersions.tsx`、`toolUpdate.ts`）**：将组件英文名称映射为清晰中文（如 `Herdr 桌面版`），为上游请求增加重试与中文超时提示，并按 `jobId` 去重结束通知。

## 问题修复

- 修复 Windows 环境下 `hostd` 测试 `portal.test.ts` 因 8.3 短路径与 `realpath` 不一致导致的失败，以及终端分片上传与超时测试断言边界问题。
- 修复终端内存图片缓存并发单测偶发触发 64 项 LRU 淘汰竞争的问题。
- 修复 `terminal.putBegin` 在只读 `uniflo` 会话上的类型收窄检查，以及 `PortalManager.capabilities` 权限提示调用属性名错误。
- 修复手机 H5 下悬浮「+ 新建」按钮在部分视口与底部导航栏重叠的布局问题。

## 多端与升级说明

- **服务端（Relay）**：包含 `v0.2.33` 全新 H5 前端静态资源、`/v1/releases/download/*` 安装包缓存路由与 `/v1/voiceprint` 声纹同步接口，更新源码并重启 `herdr-pocket-relay` 后即刻生效。
- **电脑守护进程（hostd）**：建议所有托管电脑升级至 `v0.2.33`（运行 `herdr-pocket update`），以启用 P2P 虚拟网卡过滤、大文件分片直传、新版 macOS CoreGraphics 屏幕捕获与组件更新超时处理优化。
- **桌面端（macOS / Windows / Linux）**：推荐在「设置 -> 更新」一键升级至 `v0.2.33`（连接中转服务后自动优先走高速缓存与 4 线程分片下载）；macOS 原地覆盖升级将保留原有辅助功能、麦克风与屏幕录制授权。
- **移动端（Android / iOS / HarmonyOS NEXT）与 H5**：Android（`.apk`）与 iOS（`.ipa`）由本次 Release 流程统一签名与结转；HarmonyOS NEXT（`.hap`）随新版 Web 产出一并打包发布；手机浏览器访问中转服务 `/app/` 刷新即可体验全新移动端 UI。
