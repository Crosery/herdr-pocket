# Herdr Pocket v0.2.55 更新说明

本次 **v0.2.55** 彻底重构了新手引导系统：**全面移除假界面模拟层，改为直接运行在真实工作台与真实手机页面上的实景交互高亮引导**，完整覆盖添加电脑、手机扫码配对、创建空间（Space）、新建 Tab 标签页、Agent 状态管理、对话/终端翻面与分屏，以及右侧工作面板全部核心操作，并同步补齐 Android / iOS / HarmonyOS NEXT / H5 全端一致性体验。

## 更新亮点

- **100% 真实页面 DOM 实景高亮引导（零假界面）**：采用四边挖孔聚光灯遮罩，高亮框精准包裹真实界面按钮、真实设置弹窗、真实二维码弹窗与真实下拉菜单；挖孔区域直接透传点击事件，引导过程中每一步点的都是真实控件、打开的都是真实功能窗口。
- **补齐全部核心高频操作链路**：完整串联「添加新电脑 / 接入设备 → 手机扫码连接设备 → 创建工作空间（Space）→ 新建 Tab（终端 / Agent / 网页 / 本地文件）→ Agent 状态与分组视角 → 对话/终端切换与分屏/监听端口 → 文件 / Git / 浏览器 / 小羊右侧面板」7 步桌面端实景流程。
- **全端同步实景引导与服务端单调状态记录**：H5 / 鸿蒙 NEXT 移动端提供适配手机底栏的 4 步实景引导，Android / iOS 原生端同步补齐实景 Tab 引导浮卡，并与中转服务端 `tutorialStatus`（`0 / 1 / 2`）跨端单调同步，任意端完成或跳过后不会在其他端重复打扰，且随时可在设置中重温。

## 新增功能

- **桌面端 7 步实景交互引导**：
  - **添加电脑与管理设备**：从侧栏底部直达「设置 → 电脑与中继」，自动定位并高亮真实「+ 添加电脑」按钮，点开后高亮真实 `AddDeviceModal`（「接入电脑 (Host)」终端一键安装命令与「接入手机 / 桌面端」二维码配对码）。
  - **手机扫码连接设备**：高亮左下角真实「扫码连接手机」入口，点开后实时跟随真实 `PairPhoneModal` 二维码与复制链接弹窗。
  - **创建空间（Space）**：高亮侧栏「空间 +」入口，点开后跟随真实 `CreateAgentModal`，清晰标注目标电脑选择、项目目录挑选及终端 / AI 工具启动选项。
  - **新建 Tab 标签页**：高亮顶栏 `+` 与 `▾` 下拉按钮，展开后自动聚焦真实新建菜单（新建终端、新建 Agent、打开网页、打开本地文件、浏览工作区文件）。
  - **Agent 列表、主窗格与右侧面板**：实景引导「状态 / 空间 / 最近」视角切换、聚焦窗格右上角工具栏（对话↔终端翻面、跨端回传、向右/向下分屏、监听端口胶囊），以及右上角「文件 / Git / 浏览器 / 小羊」四大面板（面板展开后合并高亮顶部按钮与侧边面板，方便直接切换体验）。
- **H5 / 鸿蒙 NEXT 4 步手机端实景引导**：直接在 `MobileAppShell` 真实底栏与页面上串联「设备（配对手机 + 添加电脑）→ Agents（空间筛选 + 右下角 `+ 新建`）→ 助理（小羊）→ 设置（重温新手引导）」。
- **Android / iOS 原生端实景引导与状态同步**：新增 `MobileWalkthroughOverlay` 与 Relay `welcome.tutorialStatus` / `tutorial_state` / `POST /v1/tutorial` 同步，在设置页新增「重温新手引导」入口，并支持一步直达 `/pair-new` 添加设备页。
- **实景引导自动化回归测试**：新增 `realUiWalkthrough.test.ts`，锁定禁止引入假界面模拟层并校验全部 22 处真实 DOM 锚点及弹窗外部点击保护。

## 交互与体验优化

- **Radix 弹窗与弹出菜单深度兼容**：为 `PocketModal`、`SettingsFrame` 与顶栏新建下拉 `Popup` 增加引导浮层保护，在打开真实设置框、添加设备弹窗、扫码弹窗、新建空间弹窗或下拉菜单时点击引导卡「下一步 / 上一步 / 退出」，不会误关闭当前窗口或被焦点锁死。
- **零滞后实时跟随与智能避让**：移除引导框坐标 CSS 过渡延迟，引入 `ResizeObserver` 与即时可视区滚动定位，在弹窗异步加载二维码/目录高度变化、侧栏展开与窗口缩放时保持聚光灯与提示卡零重叠、不裁切。
- **空态与窄屏自适配**：桌面侧栏处于收起态时自动展开以便看清真实空间与操作按钮（重温结束后自动恢复）；当前暂无打开标签页时自动高亮主工作区空态快捷入口，不卡流程。
- **文案与入口统一**：桌面设置侧栏、关于页、命令面板（`⌘K`）、H5/鸿蒙设置页与原生移动端设置页统一为「重温新手引导」，描述与真实交互完全一致。

## 问题修复

- 修复上一版本新手教程使用独立假界面模拟层、未覆盖真实添加设备/手机扫码/创建空间/新建 Tab 入口的问题。
- 修复引导期间在 `SettingsFrame` 或 `PocketModal` 打开状态下切换标签、调整窗口尺寸或非聚焦标签页内高亮框位置滞后、被遮挡的问题。
- 修复手机/窄屏 H5 打开新手引导时误显示桌面双栏视图的问题。
- 更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v14`），确保浏览器端升级后自动加载最新实景引导资源。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.55.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.55`）。
- **兼容与升级**：无破坏性协议变更；电脑端运行 `herdr-pocket update`，服务端运行 `sudo herdr-pocket-relay update` 或拉取最新容器镜像，桌面端/移动端可直接在设置内检查更新或从 GitHub Releases 下载安装包。
