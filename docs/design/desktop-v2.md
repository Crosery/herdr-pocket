# 桌面端：窗口骨架、设置与新手引导（v3）

范围：`apps/desktop`（macOS / Windows / Linux 桌面端，以及同一份网页包构建出的鸿蒙 NEXT 客户端）的界面结构。原生能力（内嵌浏览器、Cookie 导入、全局快捷键、语音输入、资源占用、日志文件、标题栏）由 `src-tauri` 和 `lib/bridge.ts` 提供；中转服务器和 hostd 的接口以 `packages/protocol` 为准。本文只定界面和交互，不定原生实现。

依据：
- Herdr 默认窗口布局的结构、尺寸、行高和设置组织。herdr.dev 首页的实时演示用的就是这个布局（公开截图 `herdr-live.png`）。
- 2026-11-20 的 v2 基线截图：演示模式，Chrome（近似 Windows WebView2）和 WebKit（近似 macOS WKWebView），420×640 / 860×700 / 1180×780 / 1440×900 / 1920×1080，浅色和暗色。
- Orca 1.4.247 的中文语言包和主进程代码（只读）。
- `apps/relay/src/server.ts` 的 `/v1/pair/codes` 路由。

v2 的外壳（左侧四个页面的导航加浮动圆角卡片）没有照 Herdr 做，已被否决，由第 2 节的 v3 外壳替代。规则：布局、结构、尺寸、密度和设置的组织照 Herdr；颜色（粉色主色，浅色和暗色）、小羊、贴纸、中文文案和“不用 emoji”用 Pocket 自己的。Herdr 和 Orca 的代码和素材都不复制。

## 1. 基线问题（v2 改版前）

| # | 现象 | 原因 |
|---|------|------|
| B1 | 860 px 宽时，桌面侧栏还在，Agent 详情却掉到列表下方，盖住了第二行 | JS 用 `width < 860` 判断窄屏，CSS 却用 `max-width: 860px`，860 px 正好落在两者之间 |
| B2 | 420 px 宽时，设置页的分段标签每个都折成两行（“应用与/外观”“提示/词”），副标题也折行 | 四个分段标签挤在标题右侧，没有换行策略 |
| B3 | 找不到“连接中转服务器”和“扫码连接手机”的入口，只有设备页右上角一个“添加设备” | 没有设计这两个入口 |
| B4 | 首次启动直接是四个输入框的表单；420×640 下“演示模式”在首屏以外 | 没有新手引导 |
| B5 | 本机 herdr-pocket 已登录时仍要手动点“一键连接” | 启动流程没有读取本机配置 |
| B6 | 窗口隐藏时动画和计时器照常运行（小羊浮动、呼吸点、每 20 秒心跳） | 没有节能规则 |

## 2. 窗口骨架（R36，照 Herdr 的默认布局）

│ 空间（按电脑分组）         │ 主体：内边距 8，间距 8                               │
│ ─────                      │ ┌ 窗格：圆角 10，描边 1 ──────┐ ┌ 侧面板 368 ────┐ │
│ Agent（按状态分组）        │ │ 窗格头 30：图标 名称 目录 状态│ │ 文件/浏览器/小羊 │ │
│                            │ │ 内容（对话、终端、文件、网页）│ │ 可拖宽 280–900   │ │

│ 设置 · 连接中转服务器 · 扫码连接手机 │ 状态栏 28：电脑 空间 N 个 Agent …  连接 语音 ⌘P 命令 │

实现在 `src/shell/`（`DesktopShell`、`ShellSidebar`、`ShellWork`、`Palette`、`shellStore`、`shortcuts`），样式在 `styles/shell.css`。上图的数字都是固定像素，不跟文字大小缩放；验收时用 `getBoundingClientRect` 量，误差不超过 1 px。

### 2.1 侧栏

- 品牌行 46 px：20 px 标志和名称（13.5 px），右边是搜索（打开命令面板的“跳转”模式，只列标签和 Agent）和收起侧栏。macOS 应用的标题栏叠在窗口上，红绿灯在品牌行里（x12 y16），所以品牌行左边留 76 px（`<html data-titlebar="overlay">`）。品牌行和标签栏整块都是窗口拖动区（`data-tauri-drag-region="deep"`），里面的按钮和标签照常点击，弹出菜单不会拖动窗口。没有侧栏的画面（启动、860 px 以下的手机布局、手机版引导）顶部有一条 28 px 的拖动条，内容让到它下面。欢迎框盖住了品牌行，所以它的背景和标题栏也能拖动窗口。Windows 保留系统标题栏，品牌行从标志直接开始。
- 空间：标题行右边一个“+”（新建 Agent）。按电脑分组，电脑行 26 px：电脑名、悬停时出现的“+”、在线点、折叠箭头。空间行 28 px：18 px 彩色字母方块、空间名、Agent 数，最右是“需要你”或状态点。点一个空间，下面的 Agent 列表只列这个空间的，再点一次取消。协议里没有分支字段，所以空间行和状态栏都不写分支。
- 没连上中转服务器时，空间区顶部一行提示和一个按钮（连接 / 立即重连 / 重新连接），不放大卡片。
- Agent：标题行有一个历史图标，在“按状态分组”和“按最近排序”之间切换。分组是 需要你、运行中、已完成、空闲、离线，组头可以折叠。每行 30 px：16 px 贴纸、“空间 · 标题”、时间（刚刚 / N分钟 / N小时 / N天，等宽字）、状态（运行中转圈，需要你“!”，已完成实心点，空闲空心圈）。悬停时时间换成“预览”按钮。点一行，把这个 Agent 作为标签打开，已经开着就切过去。
- 底部三行，用 Herdr 的行样式：
  - 设置。有新版本时带一个小圆点。
  - 连接中转服务器，带连接状态点。已连接时这一行显示服务器域名，点开 设置 › 电脑与中继；演示模式下显示“演示模式 · 连接中转服务器”。
  - 扫码连接手机。
- 收起后宽 44 px（macOS 应用 76 px）：空间只剩字母方块，Agent 只剩贴纸（需要你的带红点），底部三行只剩图标，悬停有提示。860–1099 宽时自动收起。

### 2.2 工作区

- 标签栏 42 px：每个标签 29 px，图标、标题（最宽 170 px）、状态点；当前标签和悬停的标签显示 ×，中键关闭，右键菜单有 关闭 / 关闭其他 / 关闭右侧 / 复制路径或网址。“+”打开新建菜单：新建 Agent、打开网页、打开文件。右边三个面板开关：文件、浏览器、小羊。“改动”要等主机支持，现在不显示。
- 标签有三种：Agent（对话和终端）、文件、网页。标签和侧面板的状态存在本机，下次打开还在。第一次收到 Agent 而且没有打开的标签时，自动打开最需要关注的那个；之后把标签全关了，就保持空着，空白处给出 新建 Agent / 打开网页 / 命令面板。
- 窗格头 30 px：图标、名称、目录（等宽淡色，家目录写成 ~）、右边状态；悬停时出现关闭。窗格里有焦点时描边变成粉色。Agent 窗格下面是原来的对话 / 终端工具条，去掉了重复的标题。
- 侧面板 368 px，左边缘可拖宽（280–900，双击复原），一次显示一种：
  - 文件：跟着当前标签的 Agent 走，也可以换一个 Agent；点文件，在主区开成标签。
  - 浏览器：小号网页，右下角“在标签中打开”。
  - 小羊：原来的助理页，不再单独占一页。
- 预览（Herdr 的 peek）：点 Agent 行上的“预览”，这个 Agent 的窗格浮在工作区上面，不开标签；“保留为标签”把它变成标签，Esc 关闭。
- 状态栏 28 px：左边是当前 Agent 所在的电脑、空间、“N 个 Agent · N 个需要你”；右边是连接状态（断开时点一下立即重连）、开启语音输入时的快捷键提示、“⌘P 命令”（Windows 写 Ctrl+P）。
- 去掉了：v2 的四个页面（助理 / Agents / 设备 / 工作台）和漂浮的圆角卡片。设备变成侧栏里的电脑分组加 设置 › 电脑与中继；工作台变成标签加侧面板；助理变成侧面板“小羊”。

### 2.3 颜色和字体

- Herdr 的颜色角色对应到 `tokens.css`，在 `shell.css` 开头统一定义一次：canvas 和 chrome（窗口底色、侧栏、标签栏、状态栏）用 `--page`；窗格用 `--surface`；描边用 `--divider`；焦点和选中用 `--primary` 和 `--accent-soft`；前景、次要、淡色用 `--ink`、`--muted`、`--faint`。
- 不用大面积渐变、光晕和浮动卡片。
- 中文界面用原来的无衬线字体；路径、目录、时间、按键用等宽字体。列表正文 13 px，分组标题 11–11.5 px。
- 运行中的转圈在窗口隐藏、省电模式或系统要求减少动画时停转。

### 2.4 键盘（R31、R32、R36）

快捷键只在 `shell/shortcuts.ts` 定义一次，按键处理、命令面板的按键标记和 设置 › 键盘 都读它。macOS 用 ⌘，Windows 和 Linux 用 Ctrl。

| 快捷键 | 作用 |
|--------|------|
| ⌘P（或 ⌘K） | 命令面板 |
| ⌘, | 设置 |
| ⌘T | 新建 Agent |
| ⌘W | 关闭当前标签 |
| ⌘⇧] / ⌘⇧[ | 下一个 / 上一个标签 |
| ⌘B | 显示或隐藏侧栏 |
| ⌘J | 显示或隐藏文件面板 |
| ⌘⇧A | 打开小羊面板 |

- 命令面板：屏幕上方居中，宽 535 px；输入框左边 ⌘ 标志，右边 Esc；分组是 最近、标签、面板、Agent、操作、设置，每行右边是快捷键。方向键移动高亮，回车执行，输入时高亮回到第一项，Esc 关闭。键盘逻辑在 `lib/usePaletteNav.ts`。
- Windows / Linux 的终端输入框照 Windows Terminal：Ctrl+V 粘贴；Ctrl+C 有选中文字时复制，否则发 ^C；Ctrl+Shift+C / V 总是复制 / 粘贴。焦点在终端里时，Ctrl 开头的窗口快捷键都留给终端，一个按键只做一件事。macOS 保持 ⌘ 的用法不变。
- macOS 应用的默认菜单里“关闭窗口”也是 ⌘W，需要原生层改掉，⌘W 才能用来关标签（已提给原生端）。

## 3. 断点

断点只在 `lib/layout.ts` 定义一次，JS 和 CSS 共用同一组数值（CSS 写成 `max-width: 859.98px`），杜绝 B1 那种错位。

| 宽度 | 外壳 |
|------|------|
| < 860（鸿蒙 NEXT 始终用这一档） | 手机布局：底部标签栏，和手机端一致，不用 v3 外壳 |
| 860–1099 | v3 外壳，侧栏自动收成 44 px（macOS 应用 76 px） |
| ≥ 1100 | v3 外壳，侧栏 268 px，可以手动收起 |

- 所有弹性子元素都要写 `min-width: 0`；长文本（服务器地址、路径、模型名）可折行处用 `overflow-wrap: anywhere`，单行处用 `.truncate` 加悬停提示。
- 文字大小存在 config.json 的 `general.textScale`（整数百分比，80–160）。设置和欢迎框里都是“− N% +”，每次 10。只缩放字号，不缩放第 2 节的骨架尺寸。所有字号写成 `calc(Npx * var(--ts))`，行内样式用 `fs(N)`。
- 滚动条：只让列表和窗格内部滚动，`body` 永不滚动。Windows 上用细滚动条，配色取 `--divider`。
- 字体回退：Windows 在中文前加 `"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei"`。125% / 150% 系统缩放靠 WebView2 的设备像素比处理，界面上不写死像素宽的文字容器。

## 4. 设置（R36，照 Herdr 的设置框）

- 设置是浮在窗口上的一个框，不再是一页。在 1440×900 下约 806×594，居中，圆角 10；宽 `clamp(640px, 56vw, 960px)`，高 `clamp(min(560px, 100vh - 48px), 66vh, 760px)`。⌘, 打开；Esc、点框外或 × 关闭。框打开时内嵌浏览器的原生网页先隐藏。
- 左边是 175 px 的分类列表：标题“设置”，选中项填淡粉色；方向键、Home、End 可以在分类间移动；底部一个描边按钮“导出诊断”。
- 右边是内容：小号分组标题；每行左边名称和一句淡色说明，右边控件；行与行之间细分隔线；多选一用分段控件。改了立即生效，没有“保存”按钮。只有发到服务器的小羊名字、语音服务、提示词保留显式保存；小羊的模型和服务商与手机端一样，改了马上生效（见 4.1）。
- 实现：`views/settings/SettingsFrame.tsx`、`FramePanes.tsx`，样式 `styles/settings-frame.css`（规则都限定在 `.settings-frame` 里，不影响窄屏的设置页）。

| 分类 | 内容 |
|------|------|
| 外观 | 主题（跟随系统 / 浅色 / 暗色）、文字大小（− N% +）、显示普通终端、开机启动、关闭窗口后留在托盘、使用本机 herdr-pocket 的登录 |
| 键盘 | 2.4 节的全部快捷键（按平台写 ⌘ 或 Ctrl）、Esc、语音输入快捷键（“更改”跳到 语音输入）、语音输入需要的权限卡片 |

| 提醒 | 系统通知开关、测试通知、Agent 需要你 / 完成时提醒、通话降噪 |
| 更新 | 当前版本、检查更新、自动检查和间隔、下载来源（见 4.3）、上次用的线路和各线路测速、自定义镜像、更新说明；每台在线电脑装的 hc、Herdr 桌面版、Herdr 终端、uniflo 版本（来自 `host.info` 的 `tools`），右边写“最新”或“可更新到 X”，下面一行“上次检查 …”或“还没检查”，以及开关 `update.checkTools`。只提示，不安装 |
| 隐私 | 上传日志开关、有待上传时“立即上传”，以及什么会离开这台电脑：日志先脱敏再排队、每分钟上传到你的中转服务器；小羊读 Agent 终端（`terminal.read`）并发给你配置的模型服务商；语音输入的录音发到中转服务器的 `/v1/transcribe`；检查更新只读 GitHub 或镜像；没有统计分析 |
| 语音输入 | 识别服务是否可用（`/v1/transcribe`）、开关、快捷键（“按住一个键 / 组合键”，见第 8 节）、按住说话 / 按一下、识别结果怎么放、语言、单次最长、提示音、权限卡片 |
| 小羊助理 | 三个子页：文字模型（正在用的模型、服务商、恢复，见 4.1）、名字与语音、提示词 |

### 4.1 小羊助理：模型管理（R28，与手机端一致）

手机端（apps/mobile 的模型页）和桌面端用同一套结构和说法，改动都直接存到中转服务器，所有手机和电脑同时生效。桌面端全部在设置面板里原地展开，不弹对话框。子页标签“文字模型 / 名字与语音 / 提示词”任何宽度都单行显示，放不下时横向滚动。

**正在用**（模型顺序）
- 一张卡片列出模型，左边是编号竖轨：第 1 个是粉色实心“主”，后面是浅色“2”“3”…，徽标之间用细线连起来，从上往下读就是接替顺序。
- 每行三行字：模型名（测过后最快的标“最快”）；“主模型 / 备用 · 服务商名 · 协议”；上次测速结果（绿色“首字 0.8 秒 · 全部 1.5 秒”，没通时红色“没通：一句人话”，下面小字灰色附服务商原话，最多两行）。没测过显示“点一下测测速度”。
- 点一行就测这个模型。备用行右边只有一个按钮“设为主”；主模型那行不放按钮。
- 标题行右边：“全部测速”（逐个测，测的时候显示“2/3 · 停下”，再点一下就停在当前这个之后）、“调整顺序”（只有一个模型时不显示）。
- “调整顺序”模式：标题按钮变成“完成”，“全部测速”和“添加模型”先藏起来，每行换成上移、下移、去掉三个圆按钮（第一行不能上移，最后一行不能下移，只剩一个模型时不能去掉）。去掉、上下移、设为主之后，面板底部出现提示条，几秒内可以“撤销”。
- 卡片最后一行是“添加模型”，满 12 个时变灰并提示先去掉一个。
- 主模型没通、或者别的模型开口更快时，列表下方出现建议卡：“「X」开口最快，首字 0.8 秒；主模型要 1.8 秒。”和一个“设为主模型”按钮。

**添加模型**（在列表里原地展开，Esc 或“取消”收起）
1. 服务商：一排圆角片，每个前面一个小圆点，绿色是密钥已设或不用密钥，红色是缺密钥；选了缺密钥的会提示“先到服务商里设一下密钥”。
2. 模型名：输入框同时筛下面的列表；已经在用的名字会提示“这个模型已经在列表里了”。
3. 放在哪：分段选择“当备用（第 N 个）| 设为主模型”，下面一句话说明结果。
4. 它列出的模型：一行一个（名字长，不用小圆片），已在用的变灰并标“在用”，最多显示 30 个，其余提示再输几个字筛选；服务商不给列表或报错时直接说明，照填的名字加也行。
5. 主按钮“添加并测速”：加进去后马上测这个模型，结果显示在它那一行。

**服务商**
- 每个服务商一行：图标（服务器上的 / App 里加的）、名字、“协议 · 服务器上的 / App 里加的”、密钥片（绿色“密钥 ··abcd”、红色“缺密钥”、绿色“不用密钥”）、“在用 N 个模型 / 没有模型在用”、地址。
- 点一行在下面原地展开编辑：名字、协议、地址、密钥（只能设不能看，留空保持不变）、更多设置（代号与鉴权头）、选择与扫描模型（填好地址和密钥自动扫描，一行一个可多选，已在用的标“在用”）、手动补充模型名、“保存后设为主模型（第一位使用）”、“测一下”（用一句人话报结果）。
- 最后一行“添加服务商”：原地展开，先选平台预设（也可以选自定义接口），其余同上。
- App 里加的可以删（“删掉这个服务商”→ 原地再确认一次，说明会一起去掉哪些模型；小羊所有模型都在用它时不让删）；服务器上的不能删，改过的可以“恢复此服务商的服务器设置”（同样原地确认）。

**恢复**：一行“恢复成服务器上的设置”，点一下按钮变成“确定恢复”并展开说明，再点才执行；下面一行小字写最后由谁、多久前改过。

**出错时的说法**（两端同一张表：apps/mobile/src/lib/modelErrors.ts，桌面端复制在 apps/desktop/src/lib/modelErrors.ts，改要一起改）
| 情况 | 说法 |
|---|---|
| 401 / 403、密钥无效 | 密钥不对，或这个密钥没有权限 |

| 400、参数不对 | 服务商不接受这个请求，多半是模型名或参数不对 |

### 4.2 配置文件（R20）

- 设置项的名称、类型、范围都从 `packages/protocol` 的 `CLIENT_CONFIG_KEYS` 读，和命令行 `herdr-pocket config` 一致，不在界面里另写一份。
- 设置 › 通用 和 设置 › 关于 都有“配置文件”一块：文件路径（等宽、可折行）、“打开配置文件”（原生 `config_open`；旧版没有这个命令时改为在文件夹里选中它，并提示一句）、“在访达中显示 / 在资源管理器中显示”（`config_reveal`）、“复制路径”。文件读不了时显示原因；某项值不合法时列出是哪一项、为什么。
- 下面固定一段说明，三处各放什么：
  - 存在这个文件里：通用、更新、日志、语音输入、浏览器与文件、性能与资源。只在这台电脑生效，命令行也能改，外部改完立即生效（`config://changed`）。
  - 存在中转服务器上：小羊助理的模型、密钥、提示词和声音，手机和每台电脑看到的是同一份。
  - 只在这个应用里：登录状态、窗口和侧栏的样子、新手引导进度。
- 旧版只存在应用本地的主题、文字大小、显示普通终端、系统通知，第一次读到 config.json 时搬进去一次（文件里已有的不覆盖）；之后两边双向同步。

### 4.3 下载来源（R18）

- 选项：自动 / 镜像优先 / 直连优先。镜像列表、顺序和显示名都来自 protocol 的 `decideRegion`、`sourcePrefixes(region, update.mirrors)`、`sourceLabel`，界面不写死“国内镜像”或某个镜像名。
- 说明里写出现在为什么是这个区域（环境变量 / 你的选择 / 时区 / 时区偏移加系统语言）和测速顺序（“先试 A，再试 B、C”）。
- 检查更新时把 `update.region` 和 `update.mirrors` 交给原生 `checkReleaseUpdate`，测速由原生完成；下载按钮直接用返回的 `downloadUrl`（已经走胜出的线路）。“上次用的线路”显示胜出的来源和响应时间，以及每条线路的测速结果（失败的写“不通”）。
- 更新说明只有 GitHub API 有：最多等 4 秒，拿不到就只给“查看更新说明”链接（`RELEASES_PAGE`）。
- 自定义镜像：一行一个，以 https:// 开头、/ 结尾，排在内置线路前面一起测速。

## 5. 首次启动与新手引导

### 5.1 启动顺序（任何一步都不阻塞界面）

1. 读取保存的会话。有会话：直接进入主界面，在后台连接。
2. 没有会话：并行调用 `getHostdStatus()`。
   - `configured === true`：在后台调用 `pairWithLocalHost()`，界面显示“正在用这台电脑的 herdr-pocket 登录连接…”。成功：进入主界面，toast“已用本机登录连上 <域名>”，引导从“扫码连接手机”继续，可以跳过。失败：打开引导第 3 步，上方用一句话写明原因和下一步（例如“本机登录已失效：在终端运行 herdr-pocket up 重新登录，或在下面手动连接”）。
   - 其他情况：打开新手引导第 1 步。
3. 整个过程设 8 秒超时。超时按失败处理。

### 5.2 引导步骤

桌面端（≥ 860）是浮在窗口上的欢迎框，照 Herdr 的欢迎框：宽 600，圆角 10；头部是标志、“欢迎使用 Herdr Pocket”、BETA 小标签和 ×；中间是本步标题和内容；底部左边进度点，右边深色的“下一步 →”。背后是 v3 外壳：没连中转服务器时也能关掉欢迎框，空间区顶部会提示去连接。窄屏（< 860）和鸿蒙仍是全屏卡片，最宽 560。

每一步都有“上一步”和“跳过”。最后一步之前，关掉引导一律视为“稍后再说”，可以在 设置 › 关于（窄屏是 设置 › 通用）里重新打开，命令面板里也有“重新打开新手引导”。

| 步 | 标题 | 内容 | 出口 |
|----|------|------|------|
| 1 | 欢迎使用 Herdr Pocket（欢迎框里标题是“一个窗口，看住每台电脑上的 Agent”） | 一段话讲清 Agent 在自己的电脑上运行、关掉窗口照常工作；三行功能，每行一个图标方块、粗体标题和一句说明；欢迎框里还有“外观”（跟随系统 / 浅色 / 暗色）和“大小”（− N% +） | 下一步（窄屏是“开始设置”）/ 先随便看看（演示模式） |

| 3 | 连接中转服务器 | 一句话解释：“中转服务器是你自己部署的一个小服务，让手机和各台电脑隔着网络也能互相找到。”三种方式：用本机登录一键连接（有本机登录时放第一位）、粘贴邀请链接、手动填地址和配对码。没有服务器时给部署文档链接 | 连接成功后自动进入下一步 |

## 6. 扫码连接手机

- 入口：侧栏底部“扫码连接手机”、设置 › 电脑与中继、引导第 4 步、命令面板。窄屏在 设置 › 连接。
- 实现：用当前会话的令牌调用 `createPairCode(server, token, "viewer")`。中转服务器的 `/v1/pair/codes` 接受任何设备令牌，包括桌面端这种 viewer 令牌（`apps/relay/src/server.ts:475`），返回 `{ code, expiresAt, link, qrSvg }`。二维码编码 `link`。
- 展示：二维码 200 px（白底，四周留白）、配对码大号等宽字体、“30 分钟内有效 · 还剩 29:12”、换一个码、复制链接。码过期后二维码变灰，上面盖一个“换一个码”按钮。
- 没连上中转服务器时，弹窗只显示一句说明和“先连接中转服务器”按钮。

## 7. 内嵌浏览器和多文件查看

- 位置（v3）：网页和文件都是主区的标签（见 2.2），和 Agent 标签在同一条标签栏里；文件树在侧面板“文件”，网页小窗在侧面板“浏览器”。Agent 工具条上的文件夹按钮打开侧面板“文件”。窄屏没有 v3 外壳，仍用原来的“工作台”页（一条标签栏，右键可关闭其他、关闭全部、复制路径、固定）。
- 文件树：先选电脑和目录（默认用选中 Agent 的 `cwd`），数据来自 hostd 的 `files.list`；点文件后用 `files.read` 打开。文件只读，按扩展名高亮，Markdown 可切换“预览 / 源码”，图片直接显示。大文件只读开头 512 KB，并提示已截断。
- 网页标签：地址栏、后退、前进、刷新、“导入浏览器数据”。网页本身是原生子窗口，叠放在占位区域上，网页层根据占位区域上报的位置和大小定位。打开弹窗或菜单时先隐藏子窗口，避免挡住弹层。地址栏只直接打开 http、https 和 about:blank；javascript:、file:、data: 等其他写法一律当作搜索词，原生层也应只放行这几种。鸿蒙和普通浏览器里没有原生子窗口，显示“内嵌浏览器只在桌面版可用”和“在系统浏览器打开”。
- 导入 Cookie（参照 Orca，按网站导入）：
  1. 选浏览器和配置（Chrome、Edge、Brave、Arc、Chromium、Vivaldi；“Google Chrome · 个人”）。Safari 列出但不能导入，给一句原因和“打开权限设置”（完全磁盘访问）。这一步只读文件夹名，不弹钥匙串。
  2. 选网站：列出这个配置里有 Cookie 的网站和数量（只读主机名），可筛选；默认勾上内置浏览器正在打开的网站。“全部网站…”要再确认一次。可选“也导入会话 Cookie”。
  3. 导入：macOS 弹一次钥匙串授权。结果写成一句话（“已从 Chrome 导入 312 个 Cookie（3 个站点），跳过 4 个”），跳过的原因各写一句：应用绑定加密（Chrome 127 起，不绕过，请在内置浏览器里直接登录）、会话 Cookie、已过期、读不出来。
  - 不支持“从文件…”导入。macOS 11–13 上内置浏览器只能用临时存储，提示“导入的 Cookie 只保留到关闭内置浏览器为止”。
  - 导入前先说明：“只读这台电脑上的浏览器，Cookie 只存在本机，不会上传。”
- 文件树里 `private` 的文件（.env、私钥等）显示锁，点了只提示不能查看；超过 1 MB 的图片不显示，写明原因。

## 8. 语音输入（参照豆包、微信语音输入、Typeless）

- 快捷键分两种，设置和引导里用分段控件切换：
  - 按住一个键说话（推荐）：macOS 右 Option，Windows 右 Ctrl（Windows 上右 Alt 在很多键盘布局里是 AltGr）。也可选右 Control / 右 Command / 右 Shift / Fn。选它才需要“输入监控”权限，这张权限卡片也只在这时出现。选 Fn 且系统里“按下地球仪键时”不是“不执行任何操作”时，提示去改并给“打开键盘设置”。
  - 组合键：默认 `CommandOrControl+Shift+Space`，不需要额外权限；录制控件至少要一个修饰键。
  - 保存前先问原生 `checkHotkey`（写法、被别的应用占用、权限），用不了就不保存并说明原因。
- 两种说话方式：按住说话（默认）、按一下开始再按一下结束。识别结果：粘贴到光标处（需要辅助功能权限）、逐字输入、只复制。
- 识别服务：在设置和引导第 5 步、用户试快捷键之前，先显示中转服务器能不能识别（`/v1/transcribe`），不能时显示服务器给的原因。
- 识别完成时如果焦点在 Herdr Pocket 自己身上（`target: "app"`），文字放进当前聚焦的输入框，绝不自动发送；没有输入框时复制到剪贴板并提示。
- 浮动提示条（HUD）：屏幕底部居中的小胶囊，最宽 360。状态依次为：在听（音量条）→ 识别中 → 已输入（显示前 20 个字，1.5 秒后消失）；出错时用一句话说明原因和下一步。由原生创建置顶、无焦点的小窗口；应用内同时显示同样的状态。
- 权限卡片（设置 › 语音输入，引导第 5 步）。每张卡片写明：状态（已允许 / 未允许 / 不确定）、为什么需要、“去开启”（打开对应的系统设置页）、“我已开启，重新检测”。
  - macOS：麦克风；辅助功能（往别的应用里打字需要）；输入监控（仅当快捷键是“按住一个键”时）。点“我已开启，重新检测”会让原生重新注册快捷键（`voiceReload`）。
  - Windows：麦克风（设置 › 隐私和安全性 › 麦克风 › 允许桌面应用访问）。

## 9. 节能规则

- 窗口隐藏（`document.hidden`）时：给根元素加 `data-idle`，CSS 暂停所有无限循环动画；“几分钟前”这类相对时间停止刷新；资源占用停止采样。实时连接不断开，但助理面板的轮询停止。
- 尊重 `prefers-reduced-motion`：关掉浮动、呼吸、弹簧动效，只保留 120 ms 内的不透明度过渡。
- 设置里的“省电模式”效果等同于始终减少动效，另外把终端轮询放慢到 5 秒。
- 超过 80 行的列表用窗口化渲染（只渲染可见行加上下各 10 行）。**尚未实现**：目前日志最多显示 400 行，文件树靠主机端的条数上限。
- 设置、助理、工作台、二维码库按需加载（`React.lazy`），不打进首屏包。
- 资源占用面板每 5 秒采样一次，面板关闭即停。

## 10. 日志

- 客户端：`lib/log.ts` 在内存里保留最近 2000 条，级别分 调试 / 信息 / 警告 / 错误，记录连接状态的每次变化（`link`，带原因和第几次尝试）、配对（`pair`，只记来源 `via`，不记配对码和令牌）、RPC 错误、更新检查（区域、胜出线路、各线路测速）、配置变更、Cookie 导入结果、首屏耗时；原生端负责写入文件、滚动切分和上传。`installErrorLogging()` 在启动时把未捕获的错误送进日志。
- 过滤：`redact()` 和原生 `src-tauri/src/redact.rs` 用同一组规则、同样的顺序（Bearer/Basic、`hp_`、`sk-`、Cookie / Set-Cookie 整行、查询参数里的 token/key/code/sig/auth 等、JSON 里的 token/apiKey/pairCode/adminToken 等、`/p/` `/j/` 邀请链接、`ABCD-1234` 配对码）。应用内日志、复制、网页版和鸿蒙版也因此看不到这些值。
- 服务器：设置 › 日志与诊断 › 服务器日志，读取 `/v1/logs`。可筛选级别、来源（服务器 / 电脑后台 / 手机和桌面端）、时间范围、文字；“自动跟随”在面板可见时每 5 秒用 `after=<最后一条 id>` 只取新的行。显示前同样过一遍 `redact()`。
- 配对时 `PairRequest.via` 写明码从哪来：`local-login`（本机登录）、`link`（粘贴邀请链接或打开链接）、`typed`（手填）。
- “导出诊断包”：客户端日志、本机 hostd 状态、版本和平台，打成一个文件，导出前先预览内容。

## 10.1 断线重连（R33）

- 中转服务器重启不能让客户端掉线不回来（AGENTS.md）。不只靠 `onclose`：
  - 看门狗每 5 秒检查一次：连接 12 秒还没建立、连上 12 秒还没收到 welcome、开着的连接两个心跳周期（约 45 秒）没有任何消息或 pong、连接卡在“正在关闭”，都直接换一个新连接。
  - 每 20 秒发一次 ping，8 秒内没有 pong 就重连。
  - 定时器被系统暂停后恢复（窗口隐藏、App Nap）时，先发一个 ping 验证，不凭沉默判断。
  - 窗口重新可见、获得焦点、系统网络恢复（`online`），以及原生的唤醒事件（程序坞重新打开、网络变化），都立即检查：连接开着就 ping 一下，没开就马上重连，不等退避时间。
  - 下一次重试总是先排好再通知界面，保证重试链不会断；退避从 1 秒翻倍到最多 15 秒，连上后归零。
- 每次重连都写一条带原因的 `link` 日志。
