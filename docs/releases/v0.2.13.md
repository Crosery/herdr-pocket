# Herdr Pocket v0.2.13 更新公告

## 更新亮点

- **全 Harness 动态思考等级与 OMP 深度适配**：桌面端与移动端模型切换全面升级为按具体模型动态解析可用思考等级，支持 `antigravity` 同族后缀变体分组与模型/思考双胶囊原子联动；专为 `oh-my-pi`（OMP）带来 `<10 ms` 本地配置与数据库直读目录、`/switch` 会话模型切换及 `/model` 角色槽位（`default` / `smol` / `slow` / `plan` / `commit`）即时编辑。
- **本机终端 `<5 ms` 零拷贝图片渲染与 Kitty Unicode 占位符**：Rust 本地终端内核流式拦截 Kitty 图形控制序列与探针，通过零压缩 32-bit BGRA BMPv4 与自定义协议瞬时渲染、DOM 节点复用及 `U=1` + `U+10EEEE` 虚拟占位符完整呈现 `fastfetch`、`/swarm board` 等终端图形界面。
- **本地开源 SOTA 语音降噪、声纹锁与 macOS 权限体验升级**：集成 DPDFNet + Silero VAD v4 + ERes2NetV2 + VoxLock v2 本地声纹识别与降噪管线，配合录入实时测听仪、`560px` 快速说话浮窗及全宽逐项可操作 macOS 权限清单，进一步打磨语音与桌宠互动流畅度。
- **小羊右侧窄栏通话卡片重构与标签/旁路对话体验对齐**：基于 CSS Container Queries 重构窄抽屉下的通话浮条与作用域遮罩；修复 `/btw` 流式首字截断，补充 Herdr-App 对齐的空闲标签页真删除及全屏 TUI 子界面自动 `Esc` 投递。

## 新增功能

1. **OMP 模型角色切换与毫秒级本地目录发现**：
   - 输入 `/model` 时自动打开 **角色模型（`/model`）** 标签页，直接在界面中查看与修改 `modelRoles`（`default` / `smol` / `slow` / `plan` / `commit`），同时保留 **会话模型（`/switch`）** 标签页，无需等待慢速 CLI 子进程探测。
   - 新增 Tauri 本地回退命令 `local_agent_models` 与 `local_set_omp_role_model`，自动探测并补全 `off` 与按模型家族推断的思考等级；兼容未提供 `.harness` 或每模型 `thinkingLevels` 的旧版 `hostd`。
2. **`antigravity` 同族思考变体分组与双胶囊原子同步**：
   - 按 `effortModelMap` 将同族后缀模型（如 `low` / `medium` / `high` / `xhigh`）自动聚合展示，并同步提供模型与思考等级两个胶囊按钮；切换任一胶囊时两侧状态及思考可选列表即时原子同步。
   - 明确识别非推理模型（如 `gemini-1.5-pro`、`gpt-4o`），即使历史会话中曾出现 `reasoning` 事件也不会错误恢复思考切换开关。
3. **本机终端零拷贝 Kitty 图形与像素坐标协议**：
   - Rust `ChannelApcStream` 流式拦截 `a=q,t=t` 探针与帧块上传至零拷贝内存缓存，前端通过同步 `BITMAPV4HEADER` 生成与 `term.onRender` `<img>` 节点复用消除重绘闪烁，支持 `fastfetch` 图文混排、`x`/`y`/`w`/`h`/`X`/`Y` 裁剪偏移、`U=1` / `U+10EEEE` 297 音调符与 CSI `14t`/`16t`/`18t` 尺寸查询。
4. **本地开源 SOTA 声纹识别与降噪管线**：
   - 新增 DPDFNet 语音增强、Silero VAD v4 端点检测与 ERes2NetV2 + VoxLock v2 声纹校验链路，并新增 `VoiceprintModal` 声纹录入测听仪与实时音量波形反馈，移除旧版冗余实验项，聚焦高准确度本地语音预处理。
5. **macOS 权限引导与 Herdr-App 对齐的标签页关闭**：
   - 桌面端「设置 › 语音输入」采用全宽纵向权限清单与语义化状态图标，调用 `CGRequestListenEventAccess` 触发输入监控系统授权，提供三步修复弹窗、严格白名单受限 `tccutil reset` 缓存重置及一键重启生效。
   - 关闭已空闲或完成的 Agent 标签页时直接调用 `terminal.kill`，同步清理桌面端标签与侧栏记录，并对运行中会话弹出确认框（支持仅收起标签或彻底结束）。

## 交互与体验优化

- **小羊窄抽屉通话卡片自适应**：`AssistantView` 新增 `@container assistant-pane` 容器查询规则；收起后的 `.call-mini-bar` 由臃肿胶囊重构为 `16px` 圆角双行紧凑卡片（极窄 `260px` 下自动折叠挂断按钮文字为纯图标、两行任务摘要省略裁剪），展开的 `CallOverlay` 严格限定在右侧小羊抽屉内展示且不再重复顶部主标题。
- **`/btw` 融合斜杠胶囊与清晰耗时**：输入 `/btw` 呈现平铺柔粉 `24px` 首行对齐斜杠胶囊（无多余圆点或嵌套外框），流式抽屉计时统一显示清晰秒数（如 `5.9s`），消除重复毫秒后缀。
- **ChatUI 退出全屏 TUI 与顶部栏防遮挡**：向停留在 `/swarm board` 等全屏子界面中的空闲 Agent 从 ChatUI 发消息时自动投递 `Esc` 退出子界面后再输入；设置面板关闭按钮迁移至独立不滚动顶栏，`560px` 语音浮窗 `voice-hud.html` 加宽至完整容纳状态与提示文案且不再误切右侧小羊面板；「快速说话」快捷键点击不切主视图，访达文件夹拖入零报错。

## 问题修复

- **修复 `/btw` 流式首字截断与回复竞争丢失**：修正只读助手流式拼接偏移与 `assistant_busy: false` 边沿到达时的竞态条件，保障完整回复与代码块稳定落盘展示。
- **修复历史 `reasoning` 事件误覆盖非推理模型的问题**：会话曾使用推理模型后切换至 `gemini-1.5-pro` 等明确非推理模型时，正确隐藏/禁用思考开关而不再回落至 Harness 默认级别。
- **修复旧版 Host 返回缺失 `harness` 字段时前端崩溃**：补齐协议归一化与各客户端降级兜底，防止 `normalizeSwitchHarness` 触发运行时异常。
- **修复测试/工作区潜在稳定性细节**：统一桌面与移动端模型思考等级推断逻辑、补齐多端构建与回归单元测试覆盖。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：建议同步升级电脑端 **Herdr Pocket Hostd** 与桌面/移动客户端，以获得完整 OMP 角色配置、本机终端毫秒级 Kitty 图片渲染、非推理模型思考开关精准识别与 macOS 输入监控引导；macOS 用户可在「设置 › 更新」使用测速最快镜像升级，或下载已签名公证的 `.dmg` 覆盖安装 `/Applications/Herdr Pocket.app`。
