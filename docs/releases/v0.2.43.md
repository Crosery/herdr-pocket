# Herdr Pocket v0.2.43 更新说明

本次 **v0.2.43** 全面重铸 **RustDesk 风格二进制 P2P 实时远程与全窗口自动悬浮**、完成 **ChatUI `/` 与 `\`（反斜杠）双触发及 CLI 面板命令全量同步**、彻底根治 **终端 WebGL 字体纹理图集（Glyph Atlas）错位花屏**，并升级 **Relay 小羊模型 `429` 自动冷却退避与热备用兜底**。

## 更新亮点

- **RustDesk 级二进制 P2P 远程链路与低延迟 `<canvas>` 渲染舞台**：打通 UDP/QUIC `PKF1`/`PKB1` 与 WebRTC `hp-portal` 专属 DataChannel 原始二进制传输，配合接收端 `ack` 滑动窗口流控、RTT 动态自适应码率与 `createImageBitmap` `<canvas>` 绘制，告别 Base64 JSON 膨胀与低帧卡顿。
- **全窗口变化瞬时捕获与跨工作区全局悬浮小窗**：新打开或标题变更的本地窗口、终端 `open` 文件/网址及工具调用打开的浏览器，可在不切出当前终端、分屏或聊天视图的情况下自动悬浮于左上角/右上方并支持缩放、拖拽、滚轮及多指手势交互。
- **彻底修复终端 WebGL 字体纹理图集跨终端错位花屏**：定位并加固 `@xterm/addon-webgl` 在共享图集缓存、纹理页合并与字体动态注册时的四重同步缺陷，根除多标签与频繁切换后字符被采样为 4x4/8x8 微缩乱码块的严重问题。
- **ChatUI `/` 与 `\` 双触发 + CLI 命令面板深度同步**：桌面端与手机端聊天输入框均支持输入 `/` 或 `\`（反斜杠）弹出命令面板，内置与本地 `Antigravity`、`Claude Code`、`Codex`、`omp` CLI 实机一致的面板命令，并在发送前自动识别 `/thinking`、`/effort`、`/reasoning`、`/swarm`、`/switch` 等交互面板。
- **小羊助手模型 `429` 熔断冷却与服务端备用链路兜底**：当手机端覆写的某个模型触发额度耗尽（`429` / `quota exhausted`）或限流时，自动进入 5 分钟冷却并无缝切换至服务端健康备用模型链，避免连续报错阻塞。

## 新增功能

- **二进制帧封装与传输探测（`packages/protocol` / `hostd` / `desktop` / `mobile`）**：
  - 协议新增 `PKF1`/`PKB1` 二进制分包协议与 `DirectCipher.sealBytes`/`openBytes`，桌面端与手机端 P2P 链路不再经过 JSON Base64 二次编解码。
  - 新增 `WebRTC` 独立远程视窗数据通道 `hp-portal`、接收端 `{ type: "ack", seq }` 拥塞反馈、`portal_heartbeat` 静止保活 telemetry（`静止省流`），以及直连 / TURN 中继如实识别与实时 HUD（FPS、KBps、RTT、P2P/中继状态）。
- **全局悬浮预览小窗与瞬时 CDP 浏览器（`ShellWork` / `PortalManager`）**：
  - 桌面端在工作区顶层容器接入 `WorkspacePortalOverlay`，无论焦点位于终端窗格、分屏还是对话流，均可保持小窗悬浮预览与一键接管；默认采用自适应码率与 60 FPS 上限档位。
  - 针对终端 `open <url>` 及代理工具调用即时拉起 headless/CDP 浏览器并推送首帧，不再等待慢速窗口列表轮询；`run_command` 传入 JSON 字符串参数或 `ppid=1` 脱离父进程的 GUI 窗口也能正确归属并悬浮回传。
- **终端 WebGL 运行时图集保护层（`terminalWebglPatch.ts`）**：
  - 为 `TextureAtlas` 与 `WebglRenderer` 建立基于纪元版本号（`__pocketEpoch`）的全局协同校验机制，捕捉图集清空、纹理页合并与超限页回收事件并同步刷新兄弟终端顶点缓存，严格限定单张溢出纹理上限为 `4096x4096`。
  - 结合 `getLoadedFontFaceEpoch`，仅当字体字节或 CSS 签名真正变化时触发安全重绘。
- **双前缀斜杠命令与面板同步**：
  - 桌面端与手机端同步补全 `/swarm`、`/tasks`、`/bashes`、`/ps`、`/thinking`、`/reasoning`、`/fast`、`/sandbox`、`/skills`、`/diff` 等 CLI 常用命令；输入 `\swarm`、`\btw` 等反斜杠形式可即时匹配并在提交时规范化为 `/command`。
  - `hostd` 终端命令捕获分类（`slashCapture`）同步识别 `/swarm [board|status]`、`/bashes`、`/ps`、`/diff`、`/reasoning`、`/sandbox` 等只读视图与交互选择器。

## 交互与体验优化

- **桌面端冷启动优先水合当前标签**：`ShellMain` 在启动前 `1200ms` 优先挂载并渲染当前激活标签页，延后后台标签页与预热任务挂载，显著降低启动、`Cmd+D` / `Cmd+T` 切换与点击主线程掉帧（`slow click paint`）。
- **`hostd` 模型与中断 RPC 提速**：本地模型配置解析新增 `15s` 缓存，CLI 冷启动探测等待阈值由 `600ms` 降至 `250ms`；`terminal.interrupt` CLI 等待超时从 `5s` 收紧至 `1s`，大幅减少 `slow rpc` 告警。
- **手机端统一远程舞台与手势交互**：移动端远程窗口弹窗对齐 `ack` 流控、滚轮/指针/拖拽节流合并、实时码率统计与清晰的 P2P/中继连接徽标；对话流与 `t3code` 风格极简布局保持统一，步骤状态更紧凑柔和。
- **静态画面静止省流与帧刷新协调**：延长完全静态画面的关键帧重发周期至 `2.8s` 并优化 `400ms` 周期静止心跳判定，避免静态画面重复推流与心跳漏报。
- **切换标签页零残影瞬时清晰**：后台休眠终端重新激活前自动失效陈旧 GL 纹理映射并即时重建，消除切屏残留错位帧。

## 问题修复

- **修复窗口变化未能触发悬浮小窗的多重断点**：补全首个远端观看者接入前 `knownWindows` 基线采集，解除 `ensureWindowDeltaWatcher` 仅在已有流观看者时才运行的限制（调整为连续 `850ms` 轻量轮询并在命令提交 `250ms` / `800ms` / `1800ms` 后追加探测），修复窗口新建或改名被漏检的问题。
- **修复 P2P 状态误判与卡顿源**：移除基于 `transportHint` 直接假定为 P2P 的逻辑，改为根据真实活跃链路与候选类型判定；修复多指针移动与滚轮事件高频塞满输入通道导致的画面停顿。
- **修复小羊模型配额耗尽后整条链路持续 `429` 失败**：在 `ConfigStore.effective()` 中保留服务端健康备用模型链（`fallbackTargets`）作为手机端覆写模型的自动兜底，并在 `makeLlm` 中增加 `429` / 配额错误 5 分钟冷却跳板机制，避免反复重试已耗尽模型。
- **修复 macOS 终端初始化必清共享图集与页残留状态**：去除默认字体回退栈中的无效跨平台检查，修补共享 `clearTexture()` 遗漏兄弟终端 `_model` 及合并前 `_glyphs` 残留、同帧页合并 `_requestClearModel` 滞后等缺陷。

## 多端与升级说明

- **涵盖平台与 Harness**：本次发布覆盖 macOS（正式签名与公证 `arm64`/`x64` `.dmg`）、Windows、Linux 桌面端（Tauri v2）、`hostd` 主机守护进程、Relay 服务端、H5 网页端、Android 与 HarmonyOS NEXT 端；全面兼容 OpenClaw、Claude Code、Codex、omp、OpenCode、Gemini CLI 与 Antigravity 会话。
- **升级建议**：建议桌面端、手机端、`hostd` 与 Relay 服务端同步升级至 **v0.2.43**；此前曾在手机端手动指定已失效或限流小羊模型的环境，升级后亦将自动回退至服务端配置的健康高速模型链。
