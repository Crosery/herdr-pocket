# Herdr Pocket v0.2.36 更新说明

Herdr Pocket `v0.2.36` 恢复长按 `Command`（`⌘`）快捷键角标与组合键提示，并修复切换窗口或标签页时终端与对话视口偶发回到顶部的问题。

## 更新亮点

- **恢复长按 `Command`（`⌘`）快捷键提示与角标（含鼠标悬停终端区域）**：
  - 修复 `useModifierHoldHints` 在鼠标指针停留在终端视口上方时误取消提示的问题，同时保留实体键盘 OS HID 状态校验，避免切换输入法或跨窗口切焦时误弹；调整触发延迟为 `450 ms`，并在按下 `⌘+数字` 等快捷操作后保持 `⌘` 继续按住时可重新唤起提示。
  - 恢复各功能按钮、标签页与分屏面板上的 `SpatialHint` 上下文角标（`1..9`、`T`、`B`、`J`、`D`、`W` 等），按住 `⌘`、`⌘⇧`、`⌘⌥` 时逐层收窄展示，并与底部单行状态栏导览协同配合、互不遮挡。
- **彻底修复跨窗口与切标签时视图回到顶部的问题**：
  - 针对隐身/后台标签层在 `xterm.js` 与 WebGL 切换期间 `canvas.height` / `cell.height` 归零导致内部 `SmoothScrollableElement.scrollTop` 被夹断为 `0` 的问题，新增 `snapTerminalViewportImmediate` 与渲染器就绪探测：在切回标签、首次历史流写入及每次解析写入（紧随底部状态时）立即同步真实滚动尺寸与位置，且未就绪时在首帧渲染 `onRender` 完成无动画瞬时定位，同时保留用户主动上翻的滚动偏移。
  - 修复对话模式（`AgentsView`）在隐藏标签层与切回可见瞬间可能未重新对齐底部或误覆写滚动状态的问题。

## 新增功能

- **终端滚动立即同步工具（`terminalScroll`）**：提供渲染器就绪判断 `isTerminalRendererReady` 与无动画立即锚定方法 `snapTerminalViewportImmediate` 及单元测试。

## 交互与体验优化

- **分屏邻接角标避让**：为标签整页关闭与分屏下分/最大化等 `⌘⇧` 组合按钮补充 `hide-on-bare-mod` 规则，仅按住 `⌘` 时不与邻近基础按钮角标重叠。
- **Service Worker 壳缓存升级**：将 H5 离线壳缓存版本号更新至 `herdr-pocket-shell-v3`，确保 Web/H5 端及时生效最新更新。
- **本地终端首屏缓冲微调**：延长本地终端空缓冲就绪兜底窗口至 `650 ms`，避免长历史滚动数据尚未落盘完就提前解除隐身态。

## 问题修复

- **修复按住 `Command` 无快捷键角标提示**：移除过严的终端悬停屏蔽并解除 CSS 对 `.v3-spatial-hint` 的全局隐藏，同时为 `.v3-brand` 与 `.v3-pane-head` 补足层级以防按钮角标被下方内容遮挡。
- **修复窗口/标签切换后需手动下滑才能看最新内容**：消除后台 `xterm` 渲染器暂停导致的视口夹断归零及延迟平滑滚动滞后。

## 多端与升级说明

- **桌面端与 Web/H5**：升级至 `v0.2.36` 即可获得完整的 `Command` 键提示体验及稳定的切页滚动位置保持；H5 端刷新后会自动激活新 Service Worker。
- **服务端（Relay）与电脑守护进程（hostd）**：建议随发布包一并保持在 `v0.2.36` 版本以维持全端版本一致；移动端无需额外迁移步骤。
