# Herdr Pocket v0.2.37 更新说明

本次 **v0.2.37** 聚焦桌面端与 H5 端点击响应性能治理，系统性消除切换 Space、Agent 与分屏标签页时的主线程同步阻塞，让常规点击操作回到单帧（16 ms 内）完成状态切换与视觉反馈。

## 更新亮点

- **终端 WebGL2 温热 LRU 复用池（`MAX_WEBGL_POOL = 8`）**：切换 Space、Agent 或分屏窗格时不再同步销毁/重建 `@xterm/addon-webgl` 与回退 DOM 渲染器，消除切窗时的百毫秒级卡顿。
- **两阶段终端激活与极速首屏**：激活瞬间仅在同步阶段恢复真实滚动视口、按需跳过未改尺寸的 `fitAddon.fit()` 全量重排；WebGL 升格与失活期间的缓冲补绘延后至下一动画帧（`requestAnimationFrame`）执行，并复用模块级本地终端事件通道，显著缩短首次亮屏等待。
- **Shell 状态持久化防抖与引用保真**：`shellStore` 对重复聚焦操作保持分屏/标签引用稳定，跳过无效的 Herdr 布局同步；状态写回 `localStorage` 改为 120 ms 防抖并在页面隐藏/卸载时立即落盘。
- **终端模式后台请求抑制与 Portal 10 秒宽限窗口**：停留在终端视图且尚未打开对话页前，不再触发隐藏的模型/会话轮询；离开标签后保留 Portal 监听 10 秒宽限期，来回切换免去重复握手。

## 新增功能

- **点击绘制耗时可观测遥测**：在交互与性能遥测中新增从点击触发到下一动画帧绘制完成的耗时统计（`perf.click` 超过 80 ms 触发告警，`perf.fps` 周期聚合点击次数、P50 与最大耗时及已挂载标签计数），便于持续定位跨端界面卡顿。
- **有界终端 WebGL2 资源池管理**：提供按标签窗格粒度分配、失活标记与异步逐出的有界 WebGL2 上下文管理机制，在流畅切窗与显卡上下文数量上限之间取得平衡。

## 交互与体验优化

- **侧边栏 Space 与 Agent 秒级响应**：拆分记忆化 `SidebarSpaceRow` / `SidebarAgentRow` 组件并预计算元数据映射；Space 主行支持 `pointerdown` 即时激活切换，并补充零过渡延迟的 `:active` 按压态反馈。
- **标签栏、分屏主体与面板按需渲染**：`TabChip`、`ShellTabs` 与 `ShellMain` 全链路记忆化并优化标签拖拽重排布局；右侧文件/Git 面板在收起时不挂载底层目标监控；命令面板仅在展开时订阅与计算候选项。
- **本地/远端终端首帧显现提速**：压缩本地与远端终端附着后的隐身防闪窗口，并去除重复的 Tauri 事件监听器注册等待。

## 问题修复

- **修复频繁切窗导致 300–700+ ms 主线程冻结的问题**：消除多窗格同步卸载 WebGL、无差别 `fitAddon.fit()`、`localStorage.setItem` 同步序列化以及全树重渲染叠加造成的掉帧。
- **修复终端模式切出后又切回时的隐藏 RPC 竞态**：未进入对话面板期间阻止冗余模型元数据请求与自动切换同步，避免与当前终端交互争抢主线程及通道带宽。
- **修复来回切换标签页时 Portal 画面反复断连重建的问题**：通过 10 秒宽限回收计时器保留近期使用的 Portal 订阅通道，并在全局状态重置时正确清理定时器。
- **修复焦点未变化时反复触发布局同步的问题**：点击已聚焦标签页与窗格时保留原有对象引用，避免驱动无关副作用。

## 多端与升级说明

- **涵盖平台与 Harness**：本次优化覆盖 macOS / Windows / Linux 桌面客户端（Tauri v2）、H5 网页端与 HarmonyOS NEXT 端；兼容 OpenClaw、Claude Code、Codex、omp、OpenCode、Gemini CLI 与 Antigravity 等接入会话的终端及对话管理。
- **H5 缓存更新**：H5 Service Worker 缓存版本已升级至 `herdr-pocket-shell-v4`，首次访问或刷新后将自动清理旧壳层缓存。
- **升级建议**：建议桌面端（本地与远端主机）同步升级至 **v0.2.37** 以获得一致的秒级切窗体验；本次版本不涉及协议破坏性变更，移动端二进制维持现有版本即可正常协同。
