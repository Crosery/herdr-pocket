# Herdr Pocket v0.2.31 更新说明

Herdr Pocket `v0.2.31` 重点解决 macOS 大圆角窗口红绿灯遮挡、桌面端侧边栏可读性与布局挤压、切换终端时从顶部重新滚动回放以及跨设备访问动态 HTML 网页空白四个核心体验问题，进一步提升多设备协同与日常开发效率。

## 更新亮点

- **macOS 红绿灯动态避让与一体化顶栏**：在桌面端运行时精确测量窗口最大化按钮右缘坐标并监听全屏切换事件，同步设定更自然的红绿灯位置与 `--tl-safe-left`、`--safe-top` 安全边距；统一侧栏品牌行 `.v3-brand` 与标签栏 `.v3-tabs` 为单条 `42px` 连续底边顶栏，彻底消除展开态、收起窄栏以及设置弹窗左上角的红绿灯压字压线问题。
- **桌面端侧边栏全面改版，信息一目了然**：侧栏默认宽度由 `236px` 拓宽至 `268px`（自动迁移旧版默认宽度且保留用户自定义宽度的记忆），Agent 列表升级为「主标题 + 空间 · 设备」双行高可读排版，完整保留任务标题而不再被电脑名称挤断；空间区新增可折叠标题、可拖拽调节比例的分界条与列表底缘渐隐遮罩，配合 `3px` 主题色选中竖条，彻底告别文字被腰斩的挤压感。
- **切换终端直达最新进度，不再从头滚到底**：修复初次挂载与切换标签时 `.xterm` 在历史数据尚未收齐前提前亮屏、随后流式写入长历史日志导致画面从旧时间戳一路向下滚动回放的问题；历史记录在隐藏态合并解析并直接定位至末尾后一次性显影，常驻保活标签上限同步扩充至 `16` 个。
- **跨设备 HTML 动态网页与内置浏览器完整可用**：修复中继模式下使用 `<iframe srcdoc>` 预览远端 HTML 时因继承主窗口 `script-src` CSP 限制导致内联脚本渲染画布空白的问题，转为通过独立内存预览源加载并在工作区范围内自动打包关联静态资源，同时支持远端 HTML 一键在内置浏览器标签页打开。

## 新增功能

- **macOS 窗口红绿灯实时几何测量与全屏感知**（`apps/desktop/src-tauri`、`apps/desktop`）：
  - 新增原生命令 `query_traffic_light_metrics` 与 `app://traffic-lights` 状态事件，根据缩放按钮物理位置与系统全屏通知动态更新安全区变量与 `data-fullscreen` 属性，兼容较宽按钮间距的新版 macOS 窗口样式。
- **内存态独立源 HTML 能力预览通道**（`apps/desktop/src-tauri`、`apps/desktop`）：
  - 新增原生命令 `register_mem_html_preview` 与 `pocket-local://localhost/cap/mem-*` 内存路由（带容量上限与队列淘汰机制），使中继拉取的远端 bundled HTML 拥有独立文档源以正常运行页内脚本与图表渲染，无需放宽主应用窗口的 `script-src` 安全策略。
- **跨目录 HTML 资源打包与远端内置浏览器入口**（`apps/hostd`、`apps/desktop`）：
  - `portal.bundleHtml` 支持以工作区根目录为界解析 `../` 跨子目录相对脚本、样式表、`<script type="module" src="...">` 模块与 CSS `url(...)` 本地字体/图片（总包上限提升至 `12 MB`，单资源上限 `4 MB`）。
  - 远端文件预览顶部工具栏与右侧栏均开放「用内置浏览器打开」入口。

## 交互与体验优化

- **侧边栏视觉细节打磨**（`apps/desktop/src/shell/ShellSidebar.tsx`、`sidebarAgentRow.ts`、`shell.css`、`store.ts`）：
  - 引入 `formatSidebarAgentRow` 统一整理标题与上下文副标题（`空间 · 设备`），避免重复前缀并保留重要任务名称。
  - 将空间与 Agent 列表由固定 50/50 高度改为「可折叠空间区 + `.v3-lists-sash` 横向拖拽分隔条」，底部滚动区域增加 10px 渐隐遮罩。
  - 移除 `.v3-row` 的背景色过渡延迟，切换浅色与暗色主题时选中行背景与文字颜色零延迟同步更新。
- **终端保活与对话/终端双视图无缝切换**（`TerminalSurface.tsx`、`ShellWork.tsx`、`AgentsView.tsx`）：
  - `MAX_KEPT_AGENT_TABS` 从 `6` 提升至 `16`，覆盖常规多空间高频切换需求。
  - 处于对话视图时改用 `visibility: hidden` 与绝对定位层叠保活后台终端实例，避免 `display: none` 导致 `.xterm` 尺寸归零并丢失滚动定位；在 `useLayoutEffect` 与下一帧同步恢复到底部或用户原滚动位置。
  - 守护进程 `hcscreen.watchRaw` 首帧突发历史输出合并打包（`18ms` 窗口、最高 `512 KB`），加快远端终端首屏呈现。

## 问题修复

- 修复 macOS 桌面端 `.v3-brand` 固定 `66px` 左内边距在宽红绿灯间距系统下与绿色缩放按钮重叠，以及收起侧栏为窄栏后垂直分割线穿过红绿灯底部的问题。
- 修复 `TerminalSurface.tsx` 挂载即执行空写入触发 `markHostReady` 亮屏、随后异步写入 `history` 长日志引起从顶部历史记录一路滚动到底部的缺陷。
- 修复跨设备打开以 `<script>` 动态绘制节点/流程图的远端 HTML 文件时，P2P 直连未先探测可达性且 `<iframe srcdoc>` 继承主窗口 `script-src` 策略导致仅见标题与背景栅格而画布空白的问题；同时补充 Tauri CSP 对扩展 `http:`/`https:` 媒体、图片与内嵌框架的白名单及直连失败自动回退路径。
- 修复 `.workbench` 头部在部分场景下未透传 `openInBrowserUrl`、导致远端 HTML 缺少「内置浏览器」快捷按钮的问题。

## 多端与升级说明

- **服务端（Relay）**：包含 `v0.2.31` 最新 H5 前端静态资源，升级服务端源码并重启 `herdr-pocket-relay` 即可生效。
- **电脑守护进程（hostd）**：建议所有受控电脑同步升级至 `v0.2.31`（运行 `herdr-pocket update`），以获得首帧原始终端历史合并与新版 `portal.bundleHtml` 跨目录 HTML 资源打包能力。
- **桌面端（macOS / Windows / Linux）**：建议升级至 `v0.2.31`，可在设置 › 更新中检查并安装，或从 GitHub `Latest` Release 下载对应平台安装包覆盖升级。
- **移动端（Android / iOS / HarmonyOS NEXT）与 H5**：Android（`.apk`）与 iOS（`.ipa`）未包含原生端变更，由本版 `Latest` 自动结转附带经过签名的客户端安装包；HarmonyOS NEXT（`.hap`）随 `v0.2.31` 同步重建打包发布。
