# Herdr Pocket v0.2.57 发布说明

本次 **v0.2.57** 聚焦对话稳定性与状态准确度，重点根治了三个高频体验痛点：**空闲 Agent 误判「运行中」导致消息被迫排队与手动「打断」**、**「需要你」等待操作提醒误报**，以及**空白聊天输入框偶发被撑高至最大高度**，同步覆盖电脑守护进程（`hostd`）、中转服务端（`relay`）、桌面端、H5/鸿蒙 NEXT 与 Android / iOS 原生端。

## 更新亮点

- **根治空闲 Agent 误触发消息排队与被迫「打断」**：当 Antigravity CLI 终端页脚仅挂有后台命令或 Swarm 子任务、实际主会话已处于 `· idle / · done / · reviewing` 空闲态时，主机端自动降级伪 `working` 状态；同时全端客户端新增基于真实对话流 `turn_end` 的陈旧 `working` 防护，即使连接旧版 `hostd` 也能直接发送消息并自动排空积压队列，不再频繁弹出「排队中 / 打断」。
- **三层根治「需要你」提醒误报**：打通协议层选项识别、主机端终端实屏核验与中转端小羊助理复核三条链路，彻底消除 Antigravity `· reviewing` 残影、后台任务圆点列表以及已完成的旧工具调用被误判为「等你审批/回答」的干扰弹窗与推送。
- **彻底修复空白聊天输入框突然被撑大**：在桌面端、H5 与鸿蒙 NEXT 输入框中建立空文本高度硬不变式与 `ResizeObserver` 生命周期自愈，解决中文输入法取消/失焦、隐藏态挂载及 `终端 → 对话` 切回时空白输入框被锁死在 `200px` 高度的问题。

## 新增功能

- **Antigravity 终端实屏状态交叉校验（`hostd`）**：
  - 新增 `isFalseAntigravityWorkingState` 与 `isFalseAntigravityReviewBlock` 实屏核验器：针对 `antigravity` 会话，当终端页脚明确显示 `· idle` / `· done` / `· reviewing`、输入提示符 `>` 处于空闲框内且上方无活跃前景 spinner / `● Running` / `esc to interrupt` 提示时，自动将伪 `working` 或伪 `"Approve plan"` 阻塞状态降级为空闲，并同步清理关联的终端排队标记。
  - 发送新消息触发真实新一轮执行时，立即解除降级标记并恢复正常状态流转，不影响真正的审批弹窗与执行中轮次。
- **跨端对话流 `turn_end` 陈旧运行态防护（`protocol` / 桌面 / H5 / 鸿蒙 / 原生移动端）**：
  - 在 `@herdr-pocket/protocol` 新增共享判定函数 `isStaleWorkingAfterTurnEnd`：当状态仍停留 `working` 但 `statusSince` 早于最新 `turn_end`、该轮结束已超过 5 秒、之后无新轮次事件且本端无刚发出的待回显消息时，识别为陈旧运行态。
  - 桌面端、H5/鸿蒙与 Android / iOS 原生端同步接入该判定，在发送消息、切换模型与自动排空排队消息时跳过虚假占用，直接下发并自动排空残留队列。
- **小羊助理阻塞告警二次复核（`relay`）**：
  - 新增 `findPendingBlockedToolCall` 严格过滤：仅把未收到 `tool_result` 且之后无后续回复或 `turn_end` 的提问工具调用视为待回答阻塞，不再拿历史已结束的工具调用触发提醒。
  - 优化小羊阻塞唤醒提示词与决策处理，支持先结合终端快照核验是否为假阻塞，确认属正常推进或空闲误报时静默抑制「等你」提醒推送。

## 交互与体验优化

- **聊天输入框尺寸自适应与自愈**：
  - `composerKeys` 改为回调 Ref 管理 `ResizeObserver`，无论组件从 `终端` 视图切换进入 `对话` 视图，还是窗口缩放、输入法合成取消与失焦，都会即时重新校准高度。
  - 针对 macOS WebKit / Safari 增加单行 placeholder 防折行样式约束，避免空输入框因占位符测高抖动出现额外留白。
- **孤立运行态工具卡片自动过期**：
  - 当 Agent 已处于 `idle` / `done` 或 `blocked` 状态、但对话流中因中断遗留了未配对的 `running` 工具行时，超过 12 秒自动不再将其视为进行中轮次，避免聊天框被卡死在排队模式。
- **队列自动排空体验提升**：
  - 桌面端、H5/鸿蒙与原生移动端在检测到陈旧 `working` 状态且队列中有待发消息时，会自动触发无感排空并隐藏多余的「打断」按钮，减少不必要的打断操作。

## 问题修复

- **修复空闲 Agent 误入排队并要求手动点击「打断」的问题**：解决终端后台任务/子任务页脚导致 `hc` 长时间停留在 `working` 状态、进而引发客户端误拦截发送与主机端误写入等待队列的连锁问题。
- **修复「需要你」误判与重复推送的问题**：
  - 扩展 `@herdr-pocket/protocol` 中 `askQuestion` 选项解析器的非选项排除规则（过滤带时间戳后台任务 `● [HH:MM:SS]`、工具活动前缀、`N artifact · /artifact to review` 与 `ctx · reviewing` 状态行），并拒绝无光标指针且无未选圆圈（`○`/`◯`）的纯实心圆点（`●`）摘要列表。
  - 修复 `hostd` 在 `collect()` 与 `terminal.send` 中对降级状态的同步顺序，确保降级后的空闲 Agent 不会携带过期 `queued` 计数。
- **修复空白聊天输入框偶发撑高至 `200px` 的问题**：消除 IME 组合输入期间只增不减逻辑及 `value` 保持空串时未触发重新测高导致的输入框撑大缺陷，并补充桌面单测与真实 WebKit 回归验证。
- **更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v16`）**：确保网页端与 PWA 升级后自动拉取最新前端构建产物。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.57.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.57`）。
- **兼容与升级**：无破坏性协议变更；客户端单边升级即可立即享受基于对话流的陈旧 `working` 防护与输入框修复，建议同步升级电脑端 `hostd`（`herdr-pocket update`）与中转服务端 `relay`（`sudo herdr-pocket-relay update` 或更新容器镜像）以启用完整的服务端/主机端状态降级与小羊误报拦截能力。桌面端与移动端可直接在设置中检查更新或从 GitHub Releases 下载安装包。
