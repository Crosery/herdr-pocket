# Herdr Pocket v0.2.51 更新说明

本次 **v0.2.51** 围绕**侧边栏多套展示方案（A / B / C）与「设置 › 外观」实时预览切换、对话流与上下文监控低延迟同步、上下文窗口卡片精简**，以及**无感滚动条、失焦弹窗显隐与纯附件发送队列状态修复**进行集中优化，提升跨设备多窗格协同下的可读性与跟手度。

## 更新亮点

- **侧边栏方案 A / B / C 与实时微缩预览**：默认启用**方案 A**（状态流内按同空间、同页分屏聚簇展示圆角卡片），使用 `本机` / 远端设备标签与 `第N页`、`N分屏`、`1/N`、`独立页`、`后台` 等自然中文位置标识替代抽象页码代号，同时保留**方案 B**（各状态分组内按受控电脑二次归类）与**方案 C**（迷你分屏几何图标高密度展示），支持在「设置 › 外观」一键切换并实时预览。
- **对话消息与上下文用量低延迟同步**：`hostd` 缩短快照发布防抖（`100ms`）并在收到用户消息、助手消息、回合结束与用量事件后 `80–300ms` 触发增量刷新，桌面端与 H5 对话流首帧事件 `0ms` 即刻上屏，大幅减少回复上屏与上下文占用百分比更新的感知延迟。
- **上下文窗口卡片精简与一致只读展示**：默认常驻展示 `CTX` 液位试管，去掉冗余开关按钮；桌面端、H5 与移动端「当前模型」统一调整为只读信息行并修复长模型名右侧裁切。
- **无感滚动条与无干扰列表视觉**：全面清理触发 WebKit/Safari 回退系统深色粗滚动槽的样式属性，并移除侧边栏条目及分屏行左侧竖线标记，保持界面轻量通透。

## 新增功能

- **侧边栏展示方案持久化与切换（`sidebarStyleScheme`）**：
  - 在配置中心新增 `sidebarStyleScheme` 偏好项，支持 `"a"`（默认）、`"b"`、`"c"` 三套样式方案持久化存储（移除旧版方案 D）。
  - 在「设置 › 外观」（及通用设置入口）新增三张带实时微缩预览效果的方案选择卡片，切换后侧边栏与预览区域即时联动刷新。
- **自然语义设备芯片与分屏聚簇拓扑（`apps/desktop/src/shell/sidebarTopology.ts`）**：
  - 为**状态**、**空间**、**最近**三个视图的所有单个标签页补充紧凑设备标签（`本机` 与远端主机短名，保留完整中文地理位置名称）。
  - 在空间页数抽屉中展示 `第N页`、`N分屏`、`独立页`、`后台` 等中文空间位置信息，方案 A/C 自动将同电脑、同空间、同页的分屏兄弟标签收纳于 `.v3-split-cluster` 共享聚簇卡内，方案 B 在状态分组内按电脑小标题二次归类。
- **后台工作流休眠解耦与用量自动追平**：
  - `AgentsView` 将「隐藏 2.5s 后休眠时间线 DOM（`chatDomHibernated`）」与「会话流订阅（`streamHibernated`）」解耦：切换标签不再中断实时流订阅，任务处于 `working` 运行态时保持实时流常连；收到新消息回合后自动触发防抖后的 `agent.usage` 后台刷新，并优先使用最新的 `agent.contextTokens` 重算上下文百分比。

## 交互与体验优化

- **无感悬浮细滚动条统一**：移除侧边栏列表、日志面板、欢迎页及设置窗口内导致系统渲染深色粗滚动槽的 `scrollbar-width: thin` 与 `scrollbar-gutter: stable` 声明，统一为半透明悬浮细滚动条样式。
- **侧边栏左侧竖线清理**：去掉 `.v3-row.selected::before` 与 `.v3-row.in-split` / `.split-*::before` 左侧竖条伪元素，同窗分屏改由方案 A/C 圆角聚簇卡及悬停兄弟联动高光体现层级。
- **上下文窗口（`CTX`）卡片与移动端同步精简**：
  - 桌面端与 H5 `AgentUsageCard` 移除 `实体试管` 切换按钮，`hasContext` 存在时常驻展示 `CTX` 液位试管；底部的「当前模型」改为纯展示行并完善 `width: 100%` / `min-width: 0` / `overflow: hidden` 约束，避免长模型名及 `(XHigh)` 等推理后缀被裁切。
  - 移动端上下文弹窗同步将「当前模型」由可点击按钮改为只读展示容器，保持三端交互一致。
- **H5 PWA 静默更新缓存升级**：升级 Service Worker 缓存版本至 `herdr-pocket-shell-v10`，确保线上 PWA 用户重连或切回前台时顺滑淘汰旧版静态资源并同步新前端。

## 问题修复

- **修复长对话切换标签与首帧上屏卡顿**：`createBufferedEventMerger` 仅在 `24ms` 内连续突发来帧时按 `16ms` 节流合批，空闲首帧 `0ms` 直接合入队列并上屏；补齐 `hostd` Uniflo 短会话前缀监听器匹配，消除跨前缀订阅漏帧。
- **修复仅发送图片或附件时乐观队列滞留「等待会话同步…」**：`reconcileOutgoingSends` 现支持将纯附件（无正文）发送记录匹配到空文本的已入库 `user` 消息行，并在后续事件（`ts >= send.ts - 1000`）抵达时自动收起过期等待提示，避免队列气泡长期挂起。
- **修复窗口失焦/静置态导致设置与浮层弹窗透明不可见**：在 `html[data-app-focused="false"]`、`:root[data-idle]` 与 `:root[data-calm]` 暂停非活跃动画时，排除 `.settings-frame[data-state="open"]`、`.v3-droplet`、`.v3-chord-hud` 与 `.update-toast-card` 并直接关闭入场关键帧动画，避免弹窗卡在 `opacity: 0` 的起始帧。

## 多端与升级说明

- **支持平台**：中转服务端与电脑端守护进程 `hostd`（`herdr-pocket update`）、桌面端（macOS `arm64`/`x64`、Windows `x64`、Linux `x64`）、Android（`.apk`）、iOS（`.ipa`）、HarmonyOS NEXT（`.hap`）及网页 H5 / PWA（`/app/`）。
- **升级建议**：推荐同步将服务端中转与受控电脑 `hostd` 升级至 **v0.2.51**，以获得完整的 Uniflo 短前缀匹配、`100ms` 快照防抖推送、侧边栏 A/B/C 三方案实时切换及低延迟对话与用量同步体验。
