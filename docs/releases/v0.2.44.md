# Herdr Pocket v0.2.44 更新说明

本次 **v0.2.44** 彻底解决工作区悬浮小窗位置漂移与多窗口切换闪烁问题，重构为 **固定右上角的多窗口立体叠放与一键叠列交互形态**，同步加固 Release 发布流水线接口容错。

## 更新亮点

- **固定工作区右上角定位，告别切屏跑到右下角**：无论当前处于对话视图、终端分屏、文件或 Diff 窗格，悬浮预览窗口统一锚定在工作区右上角（`top: 14px; right: 16px`），切换焦点不再上下跳变。
- **GPT 风格多窗口立体叠放（`叠放` / `叠列` 双视图）**：支持多个并发打开的网页、应用窗口、目录定位与文档在右上角叠放共处——顶部胶囊切换栏与实体错位后层卡片让多个活动窗口一目了然，也可一键展开至多 `3` 路同屏实时叠列视图。
- **零闪烁多窗口保序与位图缓存**：重构跨端流状态与 `hostd` 窗口增量事件语义，彻底消除高频视频帧刷新与窗口改名引发的排序抖动、白屏闪烁与窗格焦点误过滤。

## 新增功能

- **多窗口立体叠放与叠列视图（`SessionPortalPiP`）**：
  - **顶栏窗口胶囊切换与快速关闭**：存在 `2` 个及以上活动窗口时，主卡上方显示精致可滚动胶囊栏（`.session-portal-stack-bar`），支持点击快速切换置顶及单个窗口独立关闭。
  - **后层卡片实体叠放视觉**：主卡后方呈现最多 `2` 张错位磨砂背卡（`.session-portal-deck-back`），透出标题并支持直接点击翻到最前。
  - **一键展开多窗口实时叠列**：点击顶部 `叠列 N` 按钮即可在右上角纵列同时查看至多 `3` 张实时画布窗口（`312x184`），支持独立直控、放大与关闭，或一键 `叠放收起`。
  - **右上角折叠胶囊计数徽标**：收起状态固定在右上角显示当前窗口标题与 `+N` 余量徽标，轻点即可重新展开叠放。
- **Per-Portal 解码位图缓存（零黑屏切换）**：维护最近 `6` 个窗口的 `ImageBitmap` 内存缓存，切换堆叠窗口时立即同步重绘上一帧缓存画面，消除切换瞬间的占位空白闪烁。
- **工作区全主机视野聚合**：`WorkspacePortalOverlay` 按工作区活跃标签及在线主机聚合可见窗口，不再因点击分屏窗格导致其他窗格触发的悬浮窗口突然消失或闪烁重载。

## 交互与体验优化

- **仅在真正新开窗口时自动置顶**：引入 `openSeqById` 序列追踪，只有当确实打开新窗口（`action: "opened"`）时才将其置顶展开；后台窗口改名或流帧推送不再打断用户当前正在操作或查看的窗口。
- **收紧非目标浏览器误触发与掉帧误关闭阈值**：`hostd` 在捕获到已开启窗口标题更新时改为发送 `updated` 事件，避免闲置私人浏览器因标签页标题抖动误开浮窗，并将窗口瞬时列表缺失自动关闭阈值由 `2` 次放宽至 `4` 次。
- **发布工作流抗 `503` 重试保护**：为 GitHub Release 上传与发布步骤增加 `retry_gh` 自动退避重试，提升自动化发版稳定性。

## 问题修复

- **修复聊天视图悬浮窗定位落入右下角**：移除 `.session-portal-pip` 默认 `bottom: 108px` 及 `currentAnchorRect()` 中随 `mode` 改变初始纵坐标的逻辑。
- **修复高频推流与改名导致多窗口互相抢焦点闪烁**：修复 `portalClient.ts` 在每帧 `portal_frame` 到来时覆写 `itemsById.updatedAt`、以及 `hostd` 对已开启窗口的 `pushWindowPortalUpdate` 误发 `"opened"` 事件并刷新 `updatedAt` 造成的排序反复倒挂问题。
- **修复分屏切换时悬浮窗反复挂载与消失**：解除工作区级浮层对当前聚焦 `agentKey` 的窄过滤限制。

## 多端与升级说明

- **涵盖平台与 Harness**：本次更新涵盖 macOS（正式签名与公证 `arm64`/`x64` `.dmg`）、Windows、Linux 桌面端（Tauri v2）、`hostd` 主机守护进程、Relay 服务端、H5 网页端，并包含 **v0.2.43** 全部二进制 P2P 远程、ChatUI `/` 与 `\` 命令同步、终端 WebGL 图集保护及小羊模型 `429` 退避兜底能力。
- **升级建议**：建议桌面端用户、`hostd` 与 Relay 服务端同步更新至 **v0.2.44**，即可体验固定右上角且零闪烁的 GPT 风格多窗口叠放悬浮体验。
