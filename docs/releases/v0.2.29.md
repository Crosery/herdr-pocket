# Herdr Pocket v0.2.29 更新说明

Herdr Pocket `v0.2.29` 专注终端语音输入法显示与粘贴稳定性修复，并结合实机桌面端、守护进程与中转服务端运行日志的系统性排查，一并清理更新检查误报、多标签并发探测超时、画面回传卡顿及异常唤醒重刷问题。

## 更新亮点

- **终端语音输入法预览恢复清晰完整**：修复 `.xterm-helpers` 零尺寸容器把 `.composition-view` 组词浮层挤扁为细条、语音听写文字被完全裁切遮挡的问题，支持在光标接近底部状态栏时自动上移避让。
- **终端复制粘贴只发送一次**：修复 macOS WKWebView 下 `⌘V` 或菜单栏粘贴后 `inputType: "insertFromPaste"` 兜底重发导致的双倍粘贴问题，并保持长文本 Bracketed Paste 与分片写入一致。
- **软件更新检测告别误报与短超时**：桌面端原生清单下载白名单放行 `RELEASE-MANIFEST.json`，并将线路竞速与记住线路复检超时从 `4000ms` / `2500ms` 放宽至 `8000ms` / `6000ms`，消除国内网络下频繁误报「GitHub 与镜像线路均未响应」。
- **模型列表探测摆脱 `12s–30s` 并发阻塞**：为守护进程与桌面本地目录探测器补全单飞去重、后台非阻塞刷新、60 秒失败冷却以及 Uniflo 最近模型 `30s` 缓存，多标签同时刷新不再触发进程风暴或 RPC 超时掉线。

## 新增功能

- **多层级浏览器引擎与更新线路韧性增强**（`apps/hostd`、`apps/desktop`、`apps/relay`）：
  - 终端 IME 桥接新增原生粘贴 `preventDefault()` 与 `60ms` 粘贴抑制窗口，结合剥离 `\x1b[200~` / `\x1b[201~` 及换行归一化的回显匹配（`unwrapTerminalCommitText`），在各平台 WebView 下均防止重复落键。
  - 组词预览层新增 `.xterm-screen` 祖先查找、`MutationObserver` 样式监听以及 `0ms`/`16ms` 重排锁定，确保 `xterm.js` 重绘时不覆盖已修正的换行宽度与避让坐标。
  - 客户端 WebSocket `hello` 握手补充携带 `appVersion` 字段，便于多端设备状态页与服务端日志识别具体客户端版本。
  - Relay 助理唤醒流程新增模型配额/限流（HTTP `429` / `quota exhausted` / `rate limit`）自动 `5` 分钟冷却开关，配额耗尽期间直接走确定性兜底通知文案，避免连续告警刷屏。

## 交互与体验优化

- **隐藏后台终端延迟挂载**：桌面端未激活或宽度不足 `60px` / 高度不足 `40px` 的后台终端标签页不再在挂载瞬间抢先以 `20×25` 等极小尺寸建立本地 `localTermAttach` 或占用主线程字体布局，改为在 `ResizeObserver` 或切换到前景标签时再按真实视口尺寸平滑挂载，并在 `local_term_attach` 上同步传递真实初始焦点状态。
- **桌面工作区与画面回传提速**：
  - 桌面端窗口或屏幕回传 `portal.frame` 在采集主屏幕（`screen:0`）时跳过窗口列表枚举，抓取指定窗口时复用 `5s` 窗口缓存与单飞去重，消除每帧重复拉起进程造成的 `~2s` 延迟。
  - 守护进程读取桌面应用空间目录 `HerdrApp.ls()` 引入每实例 `1.5s` 短缓存、`4s` 关闭冷却与单飞去重，并将超时缩至 `2.5s`，窗口未开启时 `spaces.list` 迅速回退本地持久化清单。
- **重复日志降噪**：macOS 单键全局快捷键权限缺失告警（`modifier hotkey unavailable`）增加同键值去重，配置刷新时不再重复输出警告日志。

## 问题修复

- 修复 `.tp-term-host .xterm .xterm-helpers` 未显式撑满父容器导致的 `0×0` 百分比参照基准失效（使 `.composition-view` `max-width: calc(100% - 8px)` 坍缩至纯内边距宽度、输入法流式文字全被裁切看不见）的问题，同步增强浅色与深色终端主题下的组词卡片对比度。
- 修复 `terminalIme.ts` 将 `"insertFromPaste"` 纳入兜底提交集合并因 Bracketed Paste 转义包装无法匹配回显序列号而在 macOS WebKit 下将同一剪贴板内容发送两次的问题。
- 修复桌面端 Rust 原生白名单 `is_sums_url` 遗漏 `RELEASE-MANIFEST.json`、无法在原生层拉取分端发布清单的缺陷。
- 修复桌面端 Tauri `frame-src` CSP 未包含 `data:` 与 `about:` 导致沙盒 HTML 预览产生拦截报错的问题。
- 修复 `findSessionJsonlPath` / `find_session_jsonl` 对已知非 Antigravity 类型会话以及二次兜底重复全量扫描大脑日志目录导致的额外磁盘遍历开销。

## 多端与升级说明

- **服务端（Relay）**：包含 `v0.2.29` H5 静态资源及 `429` 唤醒限流冷却逻辑；使用 `sudo herdr-pocket-relay update` 或同步源码重启服务即可更新。
- **电脑守护进程（hostd）**：在已接入电脑运行 `herdr-pocket update` 即可升级至 `v0.2.29`（涵盖 `agent.models` 单飞并发缓存、`portal.frame` 提速与 `spaces.list` 防卡顿修复）。
- **桌面端（macOS / Windows / Linux）**：支持在设置页检测并升级至 `v0.2.29`，或前往 GitHub `Latest` Release 页面直接下载对应桌面安装包覆盖升级。
- **移动端（Android / iOS / HarmonyOS NEXT）与 H5**：Android（`.apk`）与 iOS（`.ipa`）未含原生代码变更，由本版 `Latest` 自动结转附带经签名的 `0.2.28` 安装包；HarmonyOS NEXT（`.hap`）随 `v0.2.29` 同步重建提供最新前端资源包。
