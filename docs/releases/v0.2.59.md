# Herdr Pocket v0.2.59 发布说明

本次 **v0.2.59** 围绕**直连消息送达可靠性、冷启动建连速度、「电脑与中继」实时延迟可视化、真模型实时耳返降噪试听、以及 Agent 监听端口发现**完成一次全链路稳定性与体验升级。

## 更新亮点

- **彻底修复 WebRTC 僵尸直连导致消息超时与发送失败**：分离双向活性心跳与单向流事件，连续超时、心跳失联或发送队列积压时自动剔除故障直连并安全回退中继补发；WebRTC 直连发送大于 64 KB 的图片或附件改走独立二进制上传通道，避免堵塞指令通道。
- **修复冷启动长时间卡在「正在连接服务器…」**：窗口聚焦或切回前景不再掐断正在握手中的 WebSocket，并消除连接首包到达前恢复标签误显「已结束的 Agent」的闪屏。
- **重做「电脑与中继」页面，全链路毫秒级延迟一目了然**：新增顶部实时概览卡（中继延迟 ms + 流畅/良好/偏高分级、建连耗时、直连通道比例、设备与 Agent 统计）、一键测速，以及每台电脑的传输方式胶囊（本地直连 / 局域网直连 / VPN 直连 / WebRTC P2P / 中继转发）、单机测速与失败原因诊断。
- **语音降噪与声纹试听接入本地真模型实时耳返**：桌面端试听室接入与实时语音同源的 Rust/ONNX 处理器（DPDFNet 神经降噪 + Silero VAD + ERes2NetV2 / VoxLock 声纹），耳返可即时听出模型处理差异，同时修复纯 Rust 基础 DSP 在未下载模型时的滤噪与增强路径。
- **完善 Agent 监听端口发现（支持后台守护/脱离进程树的服务）**：除进程树匹配外，新增基于项目工作目录（CWD）的精确兜底识别，让 `nohup`、`next-server`、`vite`、后台 Python / Nginx 等脱离终端父进程的本地服务也能准确归属到对应 Agent 并在面板直接展示。

## 新增功能

- **「电脑与中继」实时链路测速与诊断面板**：
  - 打开设置页自动探测中继与各在线主机延迟，中继建连后 120 ms 内即返回首包 RTT，不再等待 20 秒心跳周期。
  - 每台主机卡片展示实时延迟（ms）、当前通道类型、单机「测速」与「尝试直连」按钮、简明直连失败原因提示，以及旧版本 `hostd` 的「可升级」标记。
  - 独立「设备」视图同步补齐通道胶囊、实时延迟与快捷测速入口。
- **桌面端真模型实时耳返试听接口（`voice_ai_preview_live_*`）**：
  - 在佩戴耳机状态下，实时将麦克风 16 kHz PCM 流送入原生 Rust `LiveCallProcessor` 并回放处理后音频，切换降噪/声纹开关即可实时对比。
  - 明确区分「DPDFNet 神经模型」「仅基础静态去噪」与「浏览器基础试听」，并在缺少模型时提供一键后台下载入口。
- **脱离父进程的本地服务端口归属（`apps/hostd/src/ports.ts`）**：
  - 进程树未直接命中时，批量查询监听进程工作目录并与 Agent 项目根目录（含 Git 边界保护）精确匹配，过滤系统/编辑器等无关进程后按最深匹配项目归属端口。

## 交互与体验优化

- **冷启动建连态提示更清晰**：中继首包快照到达前，恢复出来的标签显示「正在连接…」，空面板展示「正在连接服务器并同步 Agent 列表…」与「立即重连」按钮，不再闪烁「已结束的 Agent / 电脑离线」。
- **端口浮层智能刷新与旧主机兼容**：点开无缓存端口的实例浮层时静默触发一次实时端口查询；遇到不支持 `agent.ports` 的旧版 `hostd` 时优雅降级展示提示，不再弹出报错 Toast。
- **「电脑与中继」信息层级重构**：桌面端与移动端设备列表升级为统一信息卡布局，清晰区分本机服务、中转服务器、远程执行主机与控制端，浅色与深色主题均经过实机核对。

## 问题修复

- **修复 WebRTC 直连队头阻塞与 9 分钟僵尸链路未剔除**：
  - 桌面端与移动端统一采用 `lastBidirectionalRxAt` 仅由 `pong` / `rpc_result` 刷新活性；连续 2 次超时、心跳等待超 10 秒或 WebRTC 缓冲区超过 64 KB 即自动关闭直连。
  - 发送前被本地缓冲拦下的请求标记 `uncertain = false` 并纳入中继安全补发；将 `terminal.put`、`terminal.putBegin`、`terminal.putAbort`、`terminal.resize`、`agent.ports` 加入 `SAFE_AGAIN`。
- **修复窗口聚焦打断建连与直连探测风暴**：
  - 建连超时放宽至 20 秒，窗口聚焦/显示防抖 1.5 秒且绝不中止正在 `CONNECTING` 的连接；连接断开仅在鉴权拒绝（`1008`）或连续失败 3 次后才复验设备列表。
  - 聚焦唤醒不再强制绕过直连退避；自动直连探测增加 15 秒最小冷却并将远端退避上限提至 60 秒，避免反复堆起大量探测线程与 WebRTC Peer。
- **修复冷启动阶段远程文件图片误走 `pocket-local://` 报错**：文件预览器与传送门文件预览在 `agent` 快照到达前改由 `agentKey` / `deviceId` 推断归属主机，不再把远程路径当本机路径加载。
- **修复语音试听听不出降噪处理效果的问题**：替换此前无效的浏览器直通耳返路径，接通真实原生神经降噪与纯 Rust DSP（80 Hz 高通 + 谱减降噪门控 + 人声存在感增强 + 峰值限幅）链路。
- **修复 Web 端取消注册日志上传器时的定时器泄漏**：`registerWebLogUploader(null)` 现会正确清理 5 秒定时轮询。
- **更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v18`）**：确保网页端与 PWA 升级后即时拉取最新前端产物。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.59.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.59`）。
- **兼容与升级**：无破坏性协议变更；桌面端与移动端可直接在设置中检查更新或从 GitHub Releases 下载安装包。为启用新的脱离进程树端口发现与最新版直连优化，建议各电脑端同步运行 `herdr-pocket update` 升级 `hostd`，服务端运行 `sudo herdr-pocket-relay update` 或拉取最新容器镜像。
