# Herdr Pocket v0.2.17 更新公告

## 更新亮点

- **桌面端与 `Herdr.app` 空间、会话状态 1:1 精准同步**：同步读取 `Herdr.app` 实时标签元数据与本地 `docs.json` 兜底，自动隐藏已关闭标签残留的幽灵终端、保留 CLI 退出回 Shell 的 Agent 所属空间与类型、修复同工作目录多实例（如 `Antigravity`）进程与会话转录串台问题，并确保桌面端新建终端直接并入所属 `Herdr.app` 空间。
- **跨设备终端极速渲染、文本复制与链接/文件跳转**：宿主机侧新增流式 Kitty 图形协议加速与 `AUTOMATIC_INPUT` 自动应答，毫秒级回应 `a=q` 探测并将 `t=f` / `t=t` 本地图像安全内联为 `t=d` 流；前端重构为线性时间 $O(N)$ APC 切分、10×13-bit 无分配 Poly1305 直连解密与 Tauri 本地帧合并；补齐代理 TUI 鼠标模式下的划选复制、`Cmd+C` 系统拷贝及中英文混排 URL / 文件路径跳转。
- **小羊助理实时语音与对话低延迟优化**：OpenAI Realtime 新增服务端静音门控与 `server_vad` 阈值调优（搭配 12 秒卡死自动提交保护），消除环境底噪导致的长时间挂起不收尾与播报自打断；对话主链路优化首包超时、`80 ms` 流式草稿刷新、思考状态实时反馈及总结轮免思考直出。
- **会话消息稳定排序、时间戳序号与单会话隔离智能切模型**：双端会话时间线采用确定性事件排序与缓冲队列合并，彻底解决弱网及首次进入时消息闪烁与发送错位；支持忙时待切换模型槽位、内联切换结果胶囊与无侵入单会话模型切换。
- **iOS 前后台切换键盘高度精准对账**：重构 `PocketKeyboardAvoidingView` 窗口高度测量与前后台恢复校准，修复切屏返回后底部输入栏与对话区域错位问题。

## 新增功能

1. **桌面终端选中复制与智能链接 / 文件跳转**：
   - 支持捕获 macOS 原生「编辑 -> 拷贝」（`Cmd+C`）DOM `copy` 事件，且在 `Claude Code`、`Antigravity`、`omp`、`Codex`、`OpenCode` 等开启鼠标追踪的 TUI 中可直接拖拽划选文本、双击选词、三击选行，并在复制后保留选区高亮。
   - 新增 OSC 8 超链接处理器与跨软换行逻辑段扫描引擎，精准识别中文与全角标点夹杂的网页链接、本地路径（含 `:行号` / `#L行号`），左键点击或右键菜单可一键在系统浏览器、内置浏览器打开，或直接在标签页打开对应代码/图片文件（亦支持一键复制链接与当前行）。
2. **宿主机侧 Kitty 图形与 `AUTOMATIC_INPUT` 加速**：
   - `hostd` 在原始 PTY 流上即时拦截 `a=q` 能力查询并优先通过 `hc` 的 `AUTOMATIC_INPUT` 通道就地应答，避免终端内诸如 `fastfetch` 等工具因跨公网等待回包阻塞数秒；对位于受允许目录且通过文件头校验的 `t=f` / `t=t` 图片就地安全内联为 `t=d` 分片，同步保留原始宽高与行列排版。
3. **会谈消息排队交错、序号展示与单会话隔离切模型**：
   - 桌面端与移动端时间线统一展示消息时间戳与 `#序号`；优化离线/弱网乐观发送排队交错（`interleaveOptimisticSends`）与历史分页 + Live SSE 缓冲合并。
   - 新增对话过程中 `PendingModelSwitch` 待切换状态与折叠切换提示胶囊（`model_switch`），在不打断当前输出或污染其他窗口默认配置的前提下，待回合结束自动完成模型或思考等级切换。

## 交互与体验优化

- **终端浅色模式与首屏加载优化**：浅色主题（`#ffffff`）自动关闭绕过对比度检测的 `customGlyphs` 程序化制表符路径，确保淡粉色框线字符稳定满足 4.5:1 对比度不再发白隐身；消除远程终端订阅初始阶段的 `150 ms` 二次 `term.reset()` 重绘闪烁与重复快照请求，并将初始历史拉取收敛为更轻量的 800 行。
- **空间与标签页实时联动**：`hostd` 缩短 `Herdr.app` 状态轮询间隔至 4 秒并在窗口关闭时自动回退本地文档索引；桌面端在窗口可见时定期刷新空间计数，收到未知空间前缀即刻对齐侧边栏。
- **小羊思考状态与流式响应提速**：当思维链模型先输出推理分片时，小羊状态及时更新为「在思考 / 在汇总」，文本草稿节流收紧至 `80 ms`，工具轮次用尽后的总结调用自动禁用多余思考（`tool_choice: "none"`）实现秒级收尾。

## 问题修复

- **修复桌面端空间与 `Herdr.app` 状态错乱**：清理已关闭标签页在 `hc` 中遗留的孤立终端计数，保留已停止回到 Shell 的 Agent 原属身份与所在空间/标签名，并通过终端创建时间（`created_ms`）、Uniflo 会话起始时间与实时状态摘要精准配对同目录并发会话。
- **修复远程 `fastfetch` 阻塞与图片错位、大报文卡顿**：对不完整或不支持的 Kitty 图像请求兜底返回 `ENOENT`，消除因未收到应答导致的光标上移错位；将 `KittyApcSplitter` 从 $O(N^2)$ 逐字符重扫升级为基于原生 `indexOf` 的 $O(N)$ 流式切分，直连 Poly1305 校验改写为零分配 10×13-bit 运算，Rust 本地 Reader 连续合并同一通道的缓冲 `KIND_DATA` 帧（最高 `256 KB`），显著降低 CPU 与 IPC 负载。
- **修复小羊实时语音挂起与播报自打断**：OpenAI Realtime 新增 `-42 dBFS`（空闲）/ `-33 dBFS`（播报期间）服务端 PCM 静音门控与 `360 ms` 尾音保持，并调优 `server_vad` 灵敏度（`threshold: 0.65`、`silence_duration_ms: 520`）与 `12 秒`卡死自动提交保护；桌面端通话回声门控同步纳入 `this.speaking` 状态，杜绝语音刚起步即被底噪误打断。
- **修复 iOS 切屏回 app 键盘布局塌陷**：通过瞬时高度防抖与窗口几何对账，消除 iOS 切换多任务返回时输入框悬空或被键盘遮挡的问题。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：推荐将 Relay 服务端、本机/远端 `Hostd` 及桌面端、移动端同步升级至 `v0.2.17`：更新 `Hostd` 后即可获得空间/会话 1:1 同步与跨机 Kitty 图像流式加速；更新 Relay 后即时生效新版小羊语音静音门控与低延迟流式总结；桌面端可直接体验代理终端复制与链接文件点击跳转。
