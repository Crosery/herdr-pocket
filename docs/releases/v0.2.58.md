# Herdr Pocket v0.2.58 发布说明

本次 **v0.2.58** 将本地声纹与人声分离模型的下载体验升级为**全端默认后台下载**：无论在桌面端、H5/鸿蒙 NEXT 还是 Android / iOS 原生端，开始下载模型后关闭弹窗、切换设置页或返回其他界面都不会中断下载，随时重新打开即可无感接回实时进度，完成后自动弹出提醒。

## 更新亮点

- **声纹模型默认后台下载（关闭弹窗 / 切换页面不中断）**：将声纹模型下载生命周期从弹窗和单页组件中彻底解耦，提升为应用级后台下载管理器。点击「后台下载」、右上角 `×`、`Esc`、遮罩或移动端返回按钮时，下载持续在后台推进，仅在显式点击「取消下载」时才会真正中止。
- **全端进度实时同步与完成提醒**：桌面端设置页与移动端设置入口实时展示「后台下载中 XX%」徽章与内联进度条；即使已离开设置页继续与 Agent 对话，后台下载完成后仍会弹出全局完成通知。
- **后台防误开麦克风保护**：若用户发起「录制声纹 / 实时测试」后将下载切到后台并关闭弹窗或离开页面，模型下载完成时仅更新就绪状态与提醒，绝不会在后台静默开启麦克风。

## 新增功能

- **桌面端 / H5 / 鸿蒙应用级模型下载控制器（`voiceAiDownloadStore`）**：
  - 统一接管「声纹弹窗」「设置页切换档位」「导入音频提取声纹」三条下载入口，自动复用进行中的下载任务，消除重开弹窗或重复触发时的「正在下载语音模型」并发报错。
  - 支持对已启动的原生 Rust 后台下载任务自动重连进度，并在 `App` 顶层监听全局完成与错误事件弹出 Toast 提醒。
- **Android / iOS 原生端后台下载状态管理（`useMobileVoiceModelDownload`）**：
  - 将 `PocketNative` 模型下载与进度监听提升为应用级 Zustand Store，退出声纹设置页不再触发 `cancelVoiceModel`。
  - 移动端「设置 → 只认我的声音」与「小羊语音设置 → 这台手机的降噪与声纹」副标题实时同步后台下载百分比。

## 交互与体验优化

- **声纹弹窗下载态升级**：
  - 弹窗下载区域明确标注「正在后台下载」与「默认在后台下载，关闭此弹窗不会中断进度，完成后会自动提醒你」，并提供「取消下载」与「后台下载」双按钮。
  - 关闭正在下载的弹窗时自动弹出轻提示确认任务已转入后台继续，随时点击设置页的「下载进度 XX%」即可重开弹窗查看实时进度。
- **设置页内联进度与状态反馈**：
  - 桌面端「语音唤醒与声纹」页在后台下载期间展示 `后台下载中 XX%` 徽章、进度条与快捷「取消下载」按钮，同时保持主操作按钮可点击以重新打开进度弹窗。

## 问题修复

- **修复关闭声纹弹窗或退出声纹设置页导致模型下载被强制取消的问题**：移除 `VoiceprintModal` 关闭回调中的 `voiceAiCancelDownload` 与移动端 `VoiceprintScreen` 卸载清理中的 `cancelVoiceModel`，仅保留麦克风录制/测试采集的自动释放。
- **修复 Rust 端取消 ONNX Runtime 推理库下载时残留误报错误的问题**：在 `voice_ai::download_tier` 中统一过滤用户主动取消（`已取消下载`），避免取消下载后设置页显示多余报错文案。
- **更新 H5 Service Worker 缓存版本（`herdr-pocket-shell-v17`）**：确保网页端与 PWA 升级后即时拉取最新前端产物。

## 多端与升级说明

- **支持平台**：macOS（Apple Silicon / Intel `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`arm64 .apk`）、iOS（`arm64 .ipa`）、HarmonyOS NEXT（`arm64 .hap`）、Relay H5 网页端与中转/主机守护进程（`herdr-pocket-0.2.58.tar.gz` / `ghcr.io/crosery/herdr-pocket-relay:0.2.58`）。
- **兼容与升级**：无破坏性协议变更；桌面端与移动端可直接在设置中检查更新或从 GitHub Releases 下载安装包，电脑端运行 `herdr-pocket update`，服务端运行 `sudo herdr-pocket-relay update` 或拉取最新容器镜像即可升级。
