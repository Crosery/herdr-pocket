# Herdr Pocket v0.2.8 更新公告

## 更新亮点

- **全量 Agent 模型与思考等级切换**：全面打通主流 Agent 的模型切换与思考深度（`思考等级` / Reasoning Effort）调节，支持内置搜索与最近使用置顶。
- **内置终端 `Shift+Enter` 换行修复**：彻底解决内置终端按 `Shift+Enter` 误触直接回车发送的问题，跨模式稳定输入多行命令与提示词。
- **输入框草稿与待发附件持久保持**：切换对话、标签页或重启页面后，未发送的文本与附件不会丢失。
- **支持关闭与清理工作空间**：侧边栏新增空间关闭入口与安全确认弹窗，清理关联运行中终端的同时完整保留磁盘文件夹与代码文件。
- **P2P 文件与图片预览修复**：放行本地生成的合法产物图片与临时文件 P2P 读取，同步维持敏感凭据目录严格拦截。
- **镜像加速更新公告展示**：发布流程强制随版附带 `RELEASE-NOTES.md`，中国大陆镜像线路无需直连 GitHub API 即可在客户端更新弹窗直接阅读完整更新说明。

## 新增功能

1. **全量 Harness 思考等级与模型调节**：
   - 修复 `omp` 模型目录发现与内置扩展/自定义 Provider（`--json` 全量提取 + `/switch` 与 `/effort` 内联指令）并扩充列表上限，支持切换不同模型及其支持的思考等级（`off` / `minimal` / `low` / `medium` / `high` / `xhigh` / `max` 等）。
   - 统一适配 `Claude Code`、`Codex`、`Gemini CLI`、`OpenCode`、`Pi`、`Antigravity`、`Hermes`、`Aider`、`Factory Droid`、`Grok` 与 `DSH` 等 Harness 的模型发现、思考等级切换、内联指令与交互面板自动化收尾。
   - 输入框顶部新增独立模型下拉框与 `思考等级` 快捷入口，移动端同步支持模型与思考等级下拉选择。
2. **输入草稿与附件跨会话缓存**：
   - 按 Agent 会话维度自动保存尚未发送的输入内容（持久化至本地存储）与已选待发图片/文件附件（内存保持，不再在切换标签时被提前释放），回到原对话时即时恢复。
   - 桌面端、HarmonyOS NEXT 与移动端均已同步接入。
3. **空间关闭与安全确认**：
   - 对齐 Herdr 桌面端关闭逻辑：可在桌面端侧边栏点击空间右侧关闭按钮或右键菜单触发关闭，或在移动端空间列表中操作关闭空间。
   - 通过 `PocketModal` 二次确认，明确提示运行中的终端数量并保证磁盘上的项目文件夹不会被删除；关闭时同步清除标签并结束相关子 Agent，防止空间被自动重建。
4. **发布公告随版下发**：
   - 每个版本固定产出 `docs/releases/vX.Y.Z.md` 与 `RELEASE-NOTES.md` 发布资产（纳入 `SHA256SUMS` 校验），桌面端优先通过已测速的镜像源拉取当前版本的详细更新日志。

## 交互与体验优化

- **模型下拉框操作更稳**：支持点击面板内思考等级胶囊直接切换，保留焦点不意外失焦关闭，同时完整遵循 Pocket 统一粉红无 Emoji 组件规范。
- **移动端终端软键盘新增 `换行` 键**：手机端在终端视图可直接点按发送 `Shift+Enter` 换行序列，输入长提示词或分段命令更顺手。
- **更新弹窗展示版本要点**：发现新版本时，更新提示卡片将分条展示当前版本的详细更新要点。

## 问题修复

- **修复内置终端 `Shift+Enter` 无法换行**：修正 `xterm.js` 在自定义按键拦截后仍透传 `keypress` `\r` 的问题；为未开启 Kitty 键盘协议的终端补齐 `\x1b[27;2;13~` 编码，并兼容 Kitty `CSI u`、`modifyOtherKeys` 与 Windows ConPTY `?9001h`（`win32-input-mode`）模式；保留 `Alt+Enter` 发送 `\x1b\r`。
- **修复 P2P 读取产物图片误报敏感密钥拦截**：调整 `files.read` 默认允许根目录，允许读取用户目录或临时目录中由 Agent 生成的图片与预览文件，同时继续严格拦截 `.env`、SSH 私钥、系统钥匙串及凭据目录（如 `Library/Keychains`、`credentials`）。
- **修复部分环境下 `agent.models` 与切换命令错配**：修正无内置预设时错误混入其他 Harness 预设模型的问题，并统一协议层与中转层的 `agent.setModel` / `space.delete` 校验。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：
  - 电脑端可通过桌面应用右上角 / 设置页“检查更新”一键升级，或执行 `herdr-pocket update`。
  - 使用 P2P 预览图片或切换 `omp` / `思考等级` 时，建议同步将本机 `hostd` 升级至 `0.2.8` 以获得完整服务端支持。
