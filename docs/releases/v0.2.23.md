# Herdr Pocket v0.2.23 更新说明

Herdr Pocket `v0.2.23` 聚焦工作区终端与对话的日常高频稳定性问题，全面消除切换标签、分屏与字体加载时的闪屏、花字与白屏问题，补齐多 Agent 终端排队消息进对话流与已读状态同步，并打磨文件链接安全点击、HTML 预览滚动定位、空空间建终端、空间右键重命名以及侧栏单一焦点等细节体验。

## 更新亮点

- 彻底解决终端乱码、花字、闪屏与白屏问题：桌面端终端改用 xterm DOM 渲染器与图片叠加层，移除 WKWebView 下易触发纹理图集错位和隐藏标签上下文丢失的 WebGL2 路径，并通过同步 `useLayoutEffect` 重绘与就地适配消除了切页空白（需滚动才恢复）、分屏重挂载与连接尺寸漂移重置。
- 全 Harness 终端排队消息直达对话流（桌面端与移动端同步）：支持自动提取用户在终端内直接排队的待处理指令（覆盖 `Antigravity`、`Claude Code`、`Codex`、`OMP`、`Pi` 与 `OpenCode` 的屏幕排队提示及 `Claude Code` 会话 `queue-operation` 记录），与客户端待发队列去重后以用户气泡形态展示在对话流与发送队列栏，并支持一键「立即注入」。
- 「已完成」点进即清零为「空闲」：修正保持挂载标签与缓存状态导致已读回执未触发的问题，`hostd` 接收 `agent.seen` 时先刷新列表、写入 `herdr.seen` 标签并立即广播最新状态，桌面端与移动端在打开或切到已完成 Agent 时同步乐观切换为空闲。
- 侧栏唯一焦点与窗格顶栏交互不漂移：修正分屏场景下侧栏同时高亮两行粉色背景的视觉混淆（未聚焦分屏改为左侧极简竖线提示并按当前空间过滤焦点），且鼠标悬停窗格顶栏时右侧工具按钮保持布局占位，不再水平推挤状态图标与子 Agent 目录触发器。
- 空空间建终端、空间锁焦与右键重命名全部对齐桌面版习惯：支持在 0 标签空空间以及 `Herdr.app` 窗口关闭状态下创建终端并写入布局文档；新建空间自动锁定焦点并默认优先打开「终端」；右键空间名支持快捷新建、重命名（留空即恢复目录名）与关闭。

## 新增功能

- 协议层与 `hostd` 守护进程新增 `Agent.queuedItems` 字段及 `extractTerminalQueuedMessages` 多工具解析器，在 Agent 运行/等待状态每 2.5 秒增量比对屏幕队列并与 JSONL `queue-operation` 事件、客户端等待队列合并去重。
- 侧栏空间行新增完整右键菜单与模态重命名框（使用内置 `PocketModal`，支持 `Enter` 确认与留空恢复工作目录默认名），并兼容桌面主程序窗口关闭时的布局文档回退写入。
- 独立文件、差异对比、HTML 与媒体预览支持按 `Escape` 单级关闭并返回上一级标签。

## 交互与体验优化

- 文件链接防误触改为 `Ctrl` + 左键（macOS 兼容 `Cmd` + 左键）跳转：无论在对话 Markdown 芯片/链接，还是终端识别路径与 OSC 链接中，普通左键点击与拖拽均仅用于选中与复制文本；悬停并按住修饰键时实时切换指针光标。
- 优化 HTML 本地预览阅读体验：避免随 Agent 心跳状态刷新重建 `iframe` 或二次 `srcDoc -> src` 切换导致页面回跳顶部，并收紧外层滚动为单一画布内滚动。
- 调整窗格顶栏右区元素顺序为状态标记在前、子 Agent 目录入口在后，并将分屏顶栏拖拽手柄高度收窄，减少与工作路径文本重叠。
- 终端内联非原始流模式的首屏回退读取等待时间从 `1000ms` 缩短至 `150ms`，新标签与空空间新建终端首屏渲染更快响应。

## 问题修复

- 修复 `0` 标签空空间或主程序窗口未开启时点击「新建终端」失败，以及 `hc` 管道断开时未捕获 `EPIPE` 导致 `hostd` 异常退出的问题。
- 修复创建新空间后焦点漂移回旧空间或默认打开非终端模式的问题，以及分屏瞬间既有终端窗格因节点键变化销毁重挂载引起的闪烁。
- 修复从对话流连续点开图片或文件预览关闭时跨级跳转的问题，恢复 `navHistoryBySpace` 严格逐级回退。
- 修复分屏标签下非活跃分屏在侧栏展示半透明粉色整行底色导致双焦点错觉的问题。
- 增强本地预览能力令牌复用机制，同一文件多次请求不再签发新令牌导致预览框架重新加载。

## 多端与升级说明

- 本次发布包含桌面端（macOS / Windows / Linux）、中转服务 `relay`、电脑守护进程 `hostd`、Android / iOS 客户端及 HarmonyOS NEXT 产物。
- 建议先将中转服务与各接入电脑的 `hostd` 守护进程升级至 `v0.2.23`，再升级桌面端与移动端客户端；macOS 提供已签名并经 Apple 公证的 `arm64` / `x64` 镜像包，可直接覆盖安装并保留现有空间布局、配置与运行中的会话。
