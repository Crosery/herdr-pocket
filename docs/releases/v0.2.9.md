# Herdr Pocket v0.2.9 更新公告

## 更新亮点

- **系统权限直达跳转与交互式授权引导弹窗**：全面升级语音输入与隐私设置中的权限引导卡片，点击路径或按钮即可直达系统设置的对应子页面（麦克风、辅助功能、输入监控、完全磁盘访问权限、Fn 地球仪键设置）。
- **macOS 应用图标原生拖拽授权**：在引导弹窗内按住「Herdr Pocket.app」卡片即可直接拖入 macOS 系统设置列表，一步完成添加条目、重签匹配更新与权限开启。
- **权限状态实时自动轮检生效**：打开授权引导弹窗后每 0.9 秒自动检测权限变化，开关打开后自动重载全局语音快捷键监听并即时反馈「已允许 · 已生效」，无需反复手动重检。
- **多设置入口与移动端一致体验**：同步接入「设置 › 隐私」、Safari Cookie 导入「完全磁盘访问权限」与移动端系统设置直达跳转。

## 新增功能

1. **交互式权限引导弹窗（`PermissionGuideModal`）**：
   - 展示清晰的三段式系统路径面包屑（例如 `系统设置 › 隐私与安全性 › 辅助功能`）与分步引导说明。
   - 接入 `/usr/bin/open` 系统深链接直达与 macOS TCC 自动注册，跳转时自动定位到精准页面并确保应用出现在授权列表中（键盘页面自动兼容旧版 macOS URL 回退）。
   - 提供实时自动检测横幅与「在 Finder 中定位应用」「重新检测」辅助操作。
2. **macOS 原生 `.app` 拖拽会话（`NSDraggingSession`）**：
   - 基于 AppKit 原生拖拽接口将当前运行的应用包直接封装为可拖出窗口的 `NSURL` 拖拽会话，配合指引动画示意图，方便直接拖入系统设置列表完成授权。
   - 弹窗内清晰说明了「列表中找不到应用」或「升级版本后开关已开仍不生效」的常见处理办法。
3. **多入口权限统一管理**：
   - 「设置 › 语音输入」「设置 › 键盘」「设置 › 隐私」以及 Safari Cookie 导入的「完全磁盘访问权限」提示统一接入同一套直达与拖拽引导弹窗。
   - 移动端扫码相机权限与声纹录音麦克风权限在受阻时新增一键「打开系统设置」入口。

## 交互与体验优化

- **全量权限可见、已授权也可重配**：macOS 下默认展示麦克风、辅助功能、输入监控卡片（组合键模式附带按需开启提示）；已授权项右侧提供管理入口，方便升级重签后重新定位或拖拽覆盖。
- **卡片路径可点击直达**：权限卡片内的系统路径芯片支持直接点击跳转对应系统设置页面，不再只是纯静态文本。
- **保持零 Emoji 粉红设计语言与明暗双主题**：弹窗、面包屑、拖拽卡片与状态徽章均基于 `PocketModal` / `PocketButton` / `PocketBadge` 与语义图标构建，浅色与暗色模式下对比度清晰一致。

## 问题修复

- **修复设置权限必须手动反复点重检的问题**：打开引导弹窗期间自动轮询系统权限，授权完成后自动触发 `voiceReload` 并切换为就绪状态。
- **修复部分 macOS 环境下仅打开系统设置首页未定位到对应子页的问题**：统一改为直接拉起精确隐私/键盘子面板并主动触发列表注册。

## 多端与升级说明

- **涵盖平台**：macOS（Apple Silicon `arm64` / Intel `x64` 已签名并公证 `.dmg`）、Windows（`-setup.exe` / `.msi`）、Linux（`.AppImage` / `.deb`）、Android（`.apk`）、iOS（未签名侧载 `.ipa`）、HarmonyOS NEXT（`.hap`）以及 Relay / Hostd Node 发布包与容器镜像。
- **升级建议**：macOS 桌面端覆盖更新后若遇辅助功能或输入监控旧签名残留，可直接在新版本的「设置 › 语音输入 › 去开启 / 拖拽引导」中将应用卡片拖入系统设置列表完成一键适配。
