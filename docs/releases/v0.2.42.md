# Herdr Pocket v0.2.42 更新说明

本次 **v0.2.42** 带来三项核心升级：**UU 远程级低延迟完整桌面/窗口远控**、**任意新窗口/标题变化与 `open` 命令全自动悬浮小窗回传**，以及 **0.9:1 对标 `t3code` 极简居中对话流与去卡片化 UI 重构（融合 Herdr Pocket 柔和粉色视觉识别）**，全面提升跨设备操控响应速度与日常 AI 协作阅读体验。

## 更新亮点

- **全链路常驻低延迟捕获与完整鼠标键盘控制（UU 远程级体验）**：macOS 与 Windows 捕获及输入驱动升级为双常驻 `serve` 子进程与 keep-alive 长连接本地桥接套接字（区分捕获与控制双通道，消除每次抓帧和键鼠注入的进程冷启动开销）；macOS 端接入持久 `SCStream` 帧泵与共享内容缓存，支持最高 60 FPS 画质热切换、多显示器真实物理坐标映射、`move`/`down`/`drag`/`up`/`click`/`dblclick` 左中右键轨迹、`Cmd/Ctrl/Opt/Shift` 修饰快捷键、虚拟触控板模式与跨端剪贴板双向同步。
- **任意新窗口、窗口标题变化与终端 `open` 全自动悬浮回传**：彻底打通 macOS/桌面窗口生命周期与终端指令感知。无论是启动全新桌面应用、旧浏览器打开新页签或发生页面标题/URL 变化，还是在终端执行 `open CLAUDE.md`（含 Starship / Oh-My-Zsh / Powerlevel10k / zsh 多行提示符及 Tab 补全前缀匹配），系统均自动将其弹入右上角悬浮小窗实时回传预览（含文本文件前瞻片段），即使此前手工折叠或关闭也会在新打开或标题变化时重新弹出。
- **0.9:1 对标 `t3code` 极简居中对话流重构**：桌面端与手机端对话流全面重构为居中 `48rem` 阅读与输入列——移除每条助手回复的外层灰框改为直接铺陈高可读 Markdown 正文（悬浮显示时间与一键复制），将思考链与多步工具调用压平为 26px 紧凑工作日志行（展开带左侧引导竖线，运行中带平滑文字微光），用户消息升级为柔和浅粉渐变气泡，并彻底**移除底部臃肿的「正在思考与处理」大卡片**，改为单行紧凑运行计时提示与输入框内嵌圆形停止按钮。

## 新增功能

- **多端远控舞台、画质热切换与背压流控（`PortalRemoteStage` / `MobilePortalModal` / `portal.input`）**：
  - 协议新增 `pointer`（`move`/`drag`/`down`/`up`/`click`/`dblclick` + `modifiers`）、`wheel`（二维滚轮 + `modifiers`）、`key`（`press`/`down`/`up`）、`clipboard`（`get`/`set`）、`config`（在线调整 `fps`/`maxWidth`/`quality`/`showCursor`）与 `promptPermission`（`accessibility`/`screenRecording`）指令；帧载荷新增 `cursorX`/`cursorY`/`cursorVisible`/`captureMs` 遥测字段。
  - 桌面与 H5 端通过 `Canvas` / `ImageBitmap` 异步解码零闪烁渲染，内置基于 `requestAnimationFrame` 的指针与拖拽聚合、矢量化光标叠加、点击波纹反馈与截图保存；手机端同步支持多屏/窗口横滑切换、虚拟触控板 `PanResponder` 相对光标操控（拖动时自动锁定外层滚动）、`1x`/`2x` 缩放与 `expo-clipboard` 双向剪贴板同步。
  - `DirectServer` / `WebRtcDirectServer` 在发送积压超过 256 KB 时自动跳过中间过时 `portal_frame`，并对 900 ms 内无变化画面自动去重。
- **全局窗口增量监听与终端提示符命令提取（`pollWindowDeltas` / `extractPromptCommandFromXterm` / `extractCommandFromTerminalScreenLine`）**：
  - `PortalManager` 新增每 1.6 秒运行的跨平台活跃窗口增量巡检（`pollWindowDeltas`）：自动捕获绕过终端父子进程树（`ppid=1` LaunchServices 拉起）的新建 GUI 窗口以及已有浏览器/应用窗口标题切换事件，即使用户暂未打开全屏放大视图也会在宿主后台提前就绪；若 macOS 屏幕录制受限则显式携带 `streamError` 提示与一键授权入口而非静默丢弃。
  - `TerminalSurface` 与 `Host` 在回车提交前从 xterm 活动缓冲区及宿主屏幕行中实时还原逻辑命令行（兼容 Starship、Oh-My-Zsh `git:(...)` 与多行折行），同时解除仅在远端已有观看者时才解析指令的限制；`SessionPortalPiP` 默认预览流畅度提升至 12 FPS / 960px，并对 Markdown 等文本目标内联展示文件首屏预览片段。
- **`t3code` 风格工作日志与极简交互组件（`AgentsView` / `ChatTimeline` / `apps/mobile/src/components/chat.tsx`）**：
  - 新增 `48rem` 居中阅读与输入框容器（`.t3-chat-column` / `.t3-composer-shell`）、26px 扁平工作日志行（`.t3-work-row` / `.t3-work-children` 竖线缩进子项 / `.t3-live-shine` 动态微光）、单行运行态指示（`.t3-working-row`）、紧凑阻塞提示条（`.t3-blocked-bar`）与圆形停止按钮（`.composer-stop-btn`）。
  - 手机端对话流同步去除了笨重的吉祥物运行大卡片与助手外框卡片，保持双端一致的极简信息密度与柔和粉色点缀。
- **macOS「辅助功能」权限感知与并排修复向导（`perms.rs` / `portal_bridge.rs` / `VoiceInput.tsx`）**：desktop 桥接服务新增 `check`（`bridgeVersion: 2` + `accessibility` 状态）及 `open_accessibility` / `open_screen_recording` 子命令，在设置隐私页与远控横幅中按需一键跳转系统设置。

## 交互与体验优化

- **对话阅读区减噪与焦点收束**：去除助手正文外框与冗余装饰边框后，长篇代码审查与多轮工具调用在居中窄栏内阅读负担显著下降；长条用户提问默认柔和渐隐折叠，保持上下文连贯。
- **悬浮小窗按次序自动展开**：为每个回传条目维护递增打开序列号 `openSeqById`，即便用户在之前手动收起或关闭了浮窗，一旦终端再次执行 `open` 或外部浏览器导航触发标题变更，小窗会自动清除忽略标记并重新展开置顶。
- **桌面端远控工作台与沉浸全屏**：`PortalViewerModal` 工具栏集成显示器/窗口选择器、操控模式分段器（指针 / 触控板 / 只读）、画质帧率切换与实时状态胶囊，支持 `98vw x 96vh` 沉浸全屏；H5 Service Worker 静态缓存同步升级至 `herdr-pocket-shell-v8`。

## 问题修复

- **修复真实多屏点击偏移与窗口桥接半关闭竞态**：全面采用真实屏幕物理边界与多显示器绝对坐标映射替代旧版 `1280x800` 默认兜底；捕获与控制双长连接按显式 `keepAlive` 协议分离复用，消除点击阻塞与写入竞态。
- **修复终端 `open CLAUDE.md` 与外部老旧浏览器操作未回传小窗的问题**：修复此前远端中继传输路径未同步读取渲染提示符行、`.md` 文件跳过 GUI 窗口追踪、`ppid=1` 脱离终端进程树窗口漏检，以及 `hasRemoteViewers()` 判断导致首帧自动回传被跳过的问题。
- **修复无法按住拖拽与组合快捷键缺失**：补齐 `down`/`drag`/`up` 状态机与完整修饰键位映射，解决窗口边缘拖拽、文本拖选与跨系统快捷键失效问题。

## 多端与升级说明

- **涵盖平台与 Harness**：本次更新覆盖 macOS（正式签名与公证 `arm64`/`x64` `.dmg`）、Windows、Linux 桌面端（Tauri v2）、`hostd` 主机守护进程、Relay 服务端、H5 网页端、Android 与 HarmonyOS NEXT 端；全面兼容 OpenClaw、Claude Code、Codex、omp、OpenCode、Gemini CLI 与 Antigravity 会话。
- **权限说明**：在 macOS 端远程桌面点击、拖拽与组合快捷键输入需要系统「辅助功能」权限（与「屏幕录制」一同在「设置 › 隐私 › 系统权限」内展示）；请将桌面应用替换为最新 **v0.2.42** 后按界面提示完成一次授权即可。
- **升级建议**：建议同步更新 Relay、`hostd` 主机守护进程与桌面/移动端客户端至 **v0.2.42**，以完整启用全局窗口动态回传、60 FPS 远控流控与新版极简对话界面。
